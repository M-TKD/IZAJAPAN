## 1. 30秒サマリー

| 項目 | 決定案 |
|------|--------|
| キャンペーンの目的 | **リード獲得（インスタントフォーム）** |
| 送客先 | Meta内の申込フォーム → 完了画面でLINE公式へ誘導 |
| 総予算 | **30,000円**（配信 8/7〜8/30 の24日間） |
| 集客目標 | **30名（男性20名 / 女性10名）** |
| 広告の担当範囲 | そのうち **11〜15名**。残り15〜19名はツテ・オーガニック（5-4参照） |
| 広告セット構成 | **男性セット / 女性セットの2本**（性別で分ける。理由は下記） |
| 予算配分 | 男性 約9,000円 / 女性 約17,000円 / リターゲ 約3,000円 |
| ターゲット | 港区・千代田区・中央区・渋谷区 ／ 男性30〜45歳・女性25〜40歳 |
| A/Bテスト | 第1週=クリエイティブ3案（男女セット内で比較）、第2週=広告文、第4週=リターゲ |
| 使うツール | Meta広告マネージャ（「投稿を宣伝」ボタンは使わない） |

**なぜ「リード獲得」なのか。** 今回はLPがなく、LINE公式も準備中です。この状態でLINEのURLに直接飛ばすと、Metaは「誰が登録したか」を一切受け取れないため、配信の自動最適化が効きません。Meta内で完結するインスタントフォームなら、送信数がそのままMetaに返るので、少ない予算でも「反応する人」に配信が寄っていきます。フォームの完了画面にLINEの友だち追加ボタンを置けば、運用マニュアル9-3で確定した「LINEに貯める」導線も同時に満たせます。

### なぜ性別で広告セットを分けるのか【今回の設計の核】

**混合1セットでは、男女比 20:10 を作れないからです。**

Metaのアルゴリズムは、獲得単価の安いほうへ自動的に予算を寄せます。有料の交流イベントは一般に男性の反応が大きく上回るため、性別を「すべて」にした1セットで配信すると、**「男性リード35件・女性リード3件」のような偏り方をします。しかも配信中にこれを止める手段がありません。**

比率を設計どおりに作るには、最初から性別ごとにセットを分け、予算を別々に持つしかありません。これが今回、セット構成を性別で切る唯一かつ最大の理由です。

なお、**性別で広告セットを分けること自体は、Metaの規約上まったく問題ありません。** 制限がかかるのは「特別な広告カテゴリ」（信用・雇用・住宅・社会問題／選挙）に該当する広告だけで、飲食イベントは非該当です（11章）。審査で問題になるのは設定ではなく文言のほうです（10章のNG表現）。

### なぜ女性側に予算を厚く配分するのか

**ボトルネックは女性10名であって、男性20名ではありません。**

- 男性：ツテで5〜10名が確定的に見込める。加えて広告でも安く取れる
- 女性：この種のイベントで女性1名あたりの広告獲得コストは、男性の**2〜4倍**が相場

したがって、目標人数が 20:10 だからといって予算を 2:1 にすると失敗します。**人数比とは逆に、予算は女性へ厚く配分します（およそ 1:2）。**

さらに、男性は反応が速く後半の短期集中でも積み上がるのに対し、女性は検討期間が長く助走が要ります。そこで **前半〜中盤は女性に寄せ、男性は後半に取りにいく**「女性ファースト」の配分にしています（5-1）。

**運用マニュアルとの関係。** マニュアル9-5は「オーガニックで勝ちパターンが見えてから（目安3ヶ月後）広告」としています。今回はそれに反しているように見えますが、狙いが違います。マニュアルが想定しているのは"継続的な集客チャネルとしての広告"で、今回は"8/31という締切がある単発イベントの席を埋めるための小規模テスト"です。総額3万円に上限を切り、ここで得た「どのクリエイティブ・どの層が反応するか」のデータを、3ヶ月後の本格出稿にそのまま持ち込みます。マニュアル側を書き換える必要はありません。

## 2. 明日のMTGで決めること（7項目）

この7つが決まらないと入稿できません。所要20分を想定しています。

| # | 決めること | 推奨案 | 決まらないと |
|---|-----------|-------|-------------|
| 1 | 送客先をどれにするか | リード獲得フォーム＋完了画面でLINE | 入稿できない |
| 2 | 予算配分 | 総額30,000円 / 男性9,000・女性17,000・リターゲ3,000 | 予算入力ができない |
| 3 | **イベント終了時刻** | **20:30（要確定）** | 広告文が書けない（下記） |
| 4 | LINE公式の準備担当と期限 | 高橋 / **8月7日(金)まで** | 完了画面が空になる |
| 5 | 動画クリエイティブを使うか | 文字を直して使う（3章参照） | 動画枠が埋まらない |
| 6 | 会場写真が無いことへの対応 | 過去開催の実写を「過去の開催の様子」と明記して使う（3-2で確定済み） | 会場に見える生成画像を出してしまう |
| 7 | 広告アカウントの名義と支払い方法 | IZA株式会社名義 / 法人クレカ | 配信が始まらない |

**3の終了時刻について。** 運用マニュアル4-1に記載があるのは「19:00 START」までで、終了時刻が未確定です。本ガイドの広告文は暫定的に **20:30終了** で書いています。終了時刻の明記は、とくに**女性の申込判断に強く効きます**（終わりが見えない会は敬遠されます）。実際の終了時刻が異なる場合は、10章の広告文を該当箇所すべて差し替えてください。

### ツテ発動ライン（この場で決めておくこと）

今回は**広告だけでは30名に届かない見込み**です（5-4に計算）。ツテを「足りなかったときの保険」ではなく、**最初から集客チャネルの一つとして日付を切って組み込みます。** 直前に慌てても人は集まりません。

| 判定日 | 条件 | 発動すること |
|--------|------|-------------|
| 8/12（水） | 女性リードが5件未満 | **女性側のツテに声かけ開始**。ここが最重要 |
| 8/17（月） | 申込合計が10名未満 | 男女ともツテ本格発動 |
| 8/20（木） | 申込合計が15名未満 | 追加予算+20,000円を投下し、許容CPAを5,000円に引き上げ |
| 8/25（月） | 女性が7名未満 | 男性セットを停止し、**残予算を全額女性に振る** |

**優先順位は「女性を守る」です。** 男女比が 18:10 になっても会は成立しますが、20:5 になると会の性格そのものが変わります。人数が不足したときに削るのは男性側の広告費であって、女性側ではありません。

増額の判断根拠：初回参加者は2回目・3回目の可能性があるため、初回単体の粗利だけで判断しません（マニュアル9-5の採算の考え方に準拠）。

## 3. クリエイティブの確認結果（要対応あり）

いただいた素材3点（静止画2枚 / 動画1本）を確認しました。**そのままでは出稿できない箇所が2つ**あります。

### 3-1. 必ず直すもの

**（A）動画のフッター文字が破損している【最優先】**

動画（5秒 / 720×1280 / 9:16）の終盤に表示される2行目のテロップが、日本語として成立していない文字列になっています。

```
実際に表示されている文字：
「全員品限定  ※腓をあるのがら会城場はごご願いくだます。」
```

意図されていたのは「※定員○名限定」「※お一人参加も歓迎です」のような注記だと思われますが、生成の過程で文字が崩れたまま残っています。この状態で配信すると、ブランドの信頼を落とすだけでなく、広告審査でも引っかかる可能性があります。

対応：**そのテロップ行を削除するか、下記に差し替えてください。**

```
定員30名 / お一人参加・ワイン初心者歓迎
```

なお「限定」という語を使う場合は、実際に定員を設けていることが前提です（景品表示法）。定員30名は事実なので「定員30名」と書くのは問題ありません。

**（B）静止画①の日本語が不自然**

- 静止画①：「ワイン不慣れな方も、これから**は**親しみたい方も。」
- 静止画②：「ワイン不慣れな方も、これから親しみたい方も。」

②が正しい表現です。①の「これからは」を「これから」に直してください。広告文の細部の粗さは、そのまま「この会、大丈夫かな」という不安につながります。

### 3-2. 会場写真の扱い（確定）

**（C）会場の写真は今回使いません。過去開催の写真を「過去の事例」として使います**

確認の結果、次の2点が確定しました。

- **会場（六本木一丁目「経営者の部室」）の写真素材は存在しません。** 撮影の予定もないため、当日の会場を写した画は今回の配信では使いません。
- **共有いただいた写真は過去開催の様子**であって、8/31の会場ではありません。**8/31当日の様子を見せる必要はない**ため、これらは「過去の開催事例」として使います。

この2つを混同しないことが、今回のクリエイティブ運用のルールです。

| 素材 | 使い方 | やってはいけないこと |
|------|--------|---------------------|
| 過去開催の写真（実写） | 会の雰囲気を伝える主素材。キャプションまたはテロップに **「過去の開催の様子」** を必ず明記 | 8/31の会場・当日の様子として出す |
| 生成画像3点 | 世界観の演出のみ。**会場が写らない画**（グラス・ボトル・注ぐ手元の寄り）に差し替えて使う | 会場や参加者に見える画のまま出す |
| 会場写真 | — | 素材が無いので今回は登場させない |

運用マニュアル10-3の自社ルールは次のとおりで、上記はこれに沿った運用です。

> やってはいけない：生成画像を「当日の様子」として出すこと。世界観の演出には使ってよいですが、実際の会場・実際の参加者に見えるものを生成で作らないでください。参加した人が「写真と違う」と感じた時点で信頼を失います。

**実写のほうが強い素材です。** 生成画像は「きれいだが誰の会でもない」画になりがちで、初参加の不安（どんな人が来るのか／浮かないか）を潰す力がありません。過去開催の実写は、多少画質が粗くてもそこが伝わるため、静止画①を実写に差し替えるのが第一手です。

**明記の仕方（そのまま使えます）：**

```
画像内テロップ（右下・小さめ）：過去の開催の様子
広告文の末尾：※写真は過去の開催の様子です。
```

「※画像はイメージです」ではなく「**過去の開催の様子です**」と書いてください。前者は生成画像用の逃げ文言で、実写に使うと逆に「作り物なのか」と読まれて損をします。

なお、当初案として挙げていた「会場に行って撮影して差し替える」は、撮影素材が用意できないため**取り下げ**ます。

### 3-3. 追加で作ると効くもの

現状の3点は「タイトル＋日時＋金額」だけで、**場所と申込理由が入っていません**。以下を追記した版を1本作ると、地域ターゲティングとの相性が上がります。

- 「六本木一丁目駅すぐ」（場所の明示。マニュアル4-2の"どこでやってるの？"という不安を潰す）
- 「お一人参加歓迎 / ワイン初心者歓迎」（同じく"ぼっちで浮きそう"を潰す）

**バナーに載せる文言そのものは10-6にまとめました。** 結論だけ先に書くと、**バナーの見出しは「ハンガリーワイン会」ではなく「ワイン会」**にします。理由と文言案は10-6を参照してください。

また、Instagramのフィード面では **4:5（1080×1350）** が最も面積を取ります。現状の静止画は9:16（ストーリーズ/リール向け）なので、**4:5版も書き出しておく**と配置の自動最適化が活きます。9:16のままでもフィードには配信されますが、上下がトリミングされてタイトルや金額が切れる恐れがあります。

**セーフゾーンの注意：** 9:16素材をストーリーズ/リールに配信すると、上14%・下20%にUI（プロフィール名、CTAボタン）が重なります。現在の素材は日時・金額が下端に寄っているため、**下から250px以内には文字を置かない**よう修正してください。ここが隠れると、広告として最も伝えたい情報が消えます。

## 4. ターゲット設定

運用マニュアル4-2のペルソナを、男女比 20:10 の目標に合わせて広告の設定値に落としたものです。

### 4-1. 設定値（そのまま入力してください）

**2つの広告セットで共通の設定：**

| 項目 | 設定値 | 理由 |
|------|--------|------|
| 地域 | **港区・千代田区・中央区・渋谷区**（区指定） | 下記参照 |
| 地域の条件 | 「**この地域に住んでいる人、または最近この地域にいた人**」 | 「住んでいる人」だけにすると、都心に通勤しているだけの人が外れます。今回はここが主戦力なので必ずこの設定に |
| 言語 | 指定しない | 日本語話者は地域設定でほぼ拾えます |
| 詳細ターゲット | 4-2のとおり（両セット共通） | |
| **詳細ターゲット設定を拡大**<br>（Advantage+ オーディエンス） | **必ずオフ** | **オンにすると性別の指定が外れます。今回は絶対にオフ**（下記の警告） |
| 配置 | **Advantage+ 配置（自動）** | 手動で絞ると単価が上がります。配置の自動化は性別設定に影響しません |

**セットごとに変える設定：**

| 項目 | 男性セット | 女性セット |
|------|-----------|-----------|
| 性別 | **男性** | **女性** |
| 年齢 | **30〜45歳** | **25〜40歳** |

年齢の下限はいずれも20歳以上です（**アルコール広告の必須要件**、11章）。性別ごとにセットを分けたことで、年齢レンジもそれぞれの実態に寄せられるようになりました。

> ### ⚠️ Advantage+ オーディエンスを必ずオフにしてください
>
> 「詳細ターゲット設定を拡大」（Advantage+ オーディエンス）をオンにすると、Metaは**指定した年齢・性別の範囲を超えて配信を広げます**。設定した性別が「絞り込み条件」ではなく「参考情報」として扱われるためです。
>
> オンのまま配信すると、**女性セットの広告が男性に配信され、男女比のコントロールが完全に崩壊します。** 今回の設計はここが崩れると成立しません。両セットとも必ずオフにしてください。
>
> なお、**アルコール広告の最低年齢（日本＝20歳）だけは法令要件のため、この設定に関わらず維持されます。** 年齢下限が破られる心配はありません。

**地域を「区指定」に変える理由。** 当初案の「六本木一丁目から半径5km」を、港区・千代田区・中央区・渋谷区の区指定に変更しました。

半径指定は、平日19時に六本木へ向かう動機の薄いエリアまで含みます。一方でこの4区は、**「年収」ターゲティングの代替として機能します。** Metaの世帯収入ターゲティングは米国のZIPコード単位のものだけで、日本では提供されていません。しかし「この4区に在住または在勤で、平日月曜19時に六本木へ来られる」という条件は、実質的にかなり強い所得フィルターとして働きます。収入軸をわざわざ探す必要はありません。

配信量が足りない場合は、新宿区・品川区・目黒区を追加して広げます（12章の判断表参照）。

### 4-2. 詳細ターゲット（両セット共通）

Metaの「詳細ターゲット設定」で以下を **OR条件（いずれかに該当）** で入れます。候補が見つからない場合は、近い名称のものを選んでください（Metaは項目名を頻繁に変更します）。

- ワイン
- ワインテイスティング
- ソムリエ
- レストラン / 食通（グルメ）
- 料理
- バー / ナイトライフ

**「ターゲットを絞り込む」（AND条件）は使わないでください。** 予算3万円の規模で条件を重ねると、配信対象が数万人まで縮んで単価が跳ね上がります。

**男女で興味関心を変えないでください。** 「男性にはゴルフ・投資、女性には美容・コスメ」といった出し分けをしたくなりますが、今回はやりません。理由は2つあります。第一に、変数が増えて第1週のクリエイティブ比較が読めなくなります。第二に、これらは「ワインに関心がある」より相関の弱い代理指標で、母数を狭めるだけの結果になりがちです。**男女差はターゲティングではなく、広告文（10章）で作ります。**

### 4-3. 指定できないもの（検討済み・不採用）

検討に上がった軸のうち、Metaの仕様上そもそも設定できないものを記録しておきます。次回同じ検討を繰り返さないためのメモです。

| 希望した軸 | 可否 | 実情 |
|-----------|------|------|
| 年収500万円以上 | **不可** | 世帯収入ターゲティングは米国のZIPコード単位のみで、日本では提供されていません。→ 地域（4区）で代替 |
| 職業（アパレル / 歯科衛生士 / OL など） | **実質不可** | 「役職」「勤務先」でのターゲティングは2022年以降に段階的に削除されました。現存するのは「業界」の粗い区分のみで、自己申告のプロフィール依存のため精度も低い |
| 見た目・雰囲気 | **不可** | Metaにそのような軸は存在しません |

**「マナーがよく、落ち着いた振る舞いの人に来てほしい」という要件は、ターゲティング設定では達成できません。** これは広告文とクリエイティブで自己選択してもらう領域です（10章）。会費7,000円が固定である以上、価格によるフィルターも使えないため、**文面とビジュアルが唯一の質のフィルター**になります。

### 4-4. リターゲティング用オーディエンス（第4週で使う）

配信開始と同時に、以下の「カスタムオーディエンス」を作っておいてください。作成した瞬間から蓄積が始まるので、**早く作るほど第4週の在庫が増えます**。

## 5. 予算と目標数値

### 5-1. 予算配分（女性ファースト）

総額 **30,000円**、配信期間 8/7（金）〜8/30（日）の24日間。

| 期間 | フェーズ | 男性セット | 女性セット | リターゲ | 日計 | 日数 | 小計 |
|------|---------|-----------|-----------|---------|------|------|------|
| 8/7〜8/12 | 第1週：クリエイティブ検証＋**単価の実測** | 500円 | 500円 | — | 1,000円 | 6日 | 6,000円 |
| 8/13〜8/23 | 第2〜3週：**女性に寄せる** | 300円 | 1,000円 | — | 1,300円 | 11日 | 14,300円 |
| 8/24〜8/30 | 第4週：充足状況で再配分＋締切訴求 | 300円 | 600円 | 400円 | 1,300円 | 7日 | 9,100円 |
| | | **約9,000円** | **約17,000円** | **約3,000円** | | **合計** | **29,400円** |

**第1週を男女同額にする理由。** 前半6日間は「配信」であると同時に「**女性の獲得単価が男性の何倍か**を実測する」ためのフェーズです。相場では2〜4倍ですが、実際の倍率はアカウントとクリエイティブで変わります。8/12にこの実測値を見て、第2週以降の配分を確定します。上の表の 300:1,000 は、倍率が想定どおり（約3倍）だった場合の既定値です。

**第2〜3週で女性に寄せる理由。** 男性は反応が速く、後半の短期集中でも積み上がります。一方で女性は検討期間が長く、助走が必要です。そのため**走る距離が必要な女性に前半〜中盤を割き、男性は後半に取りにいく**構成にしています。

**キャンペーン全体の上限（通算予算）を30,000円で設定しておくこと。** 日予算だけだと、止め忘れたときに上限なく消化されます。広告マネージャのキャンペーン設定で「キャンペーンの支出限度額」を30,000円に入れてください。これが初心者にとって最大の保険です。

### 5-2. 目標数値と、そこに至る計算

男女で獲得単価が大きく違うため、**必ず男女別に逆算します**。数字は東京都心・日本語・夜のイベント系の一般的な相場を前提にしています。

**男性セット（予算 約9,000円）**

```
広告費 9,000円
  ÷ CPL 700円（男性のリード単価。反応が良いぶん安い）
  = リード 約13件
  × 申込・来場率 45%
  = 参加者 約6名
```

**女性セット（予算 約17,000円）**

```
広告費 17,000円
  ÷ CPL 1,400円（女性のリード単価。男性の約2倍）
  = リード 約12件
  × 申込・来場率 45%
  = 参加者 約5名
```

**リターゲティング（予算 約3,000円）**

```
広告費 3,000円 ÷ CPL 500円（既接触層なので安い）
  = リード 約6件 × 50% = 参加者 約3名
```

| KPI | 男性セット | 女性セット | 判断ライン |
|-----|-----------|-----------|-----------|
| CPM | 1,500円以下 | 2,000円以下 | 2,500円超でターゲットが狭すぎる |
| CTR | 1.0%以上 | 1.0%以上 | 0.7%未満のクリエイティブは止める |
| リード単価（CPL） | 700円以下 | **1,400円以下** | 女性は2,000円超で要見直し |
| リード数 | 13件 | 12件 | |
| 広告経由の参加者 | 6名 | 5名 | |

**広告経由の合計見込み：11〜15名。**

**この数字に届かなくても失敗ではありません。** 広告アカウントを新規に作った直後は、Metaが「誰に出せばいいか」を学習していないため、最初の3〜5日は単価が高く出ます。判断は第1週の終わり（8/12）にまとめて行ってください。

### 5-3. チャネル別の担当人数【重要】

**上の計算が示すとおり、広告だけでは30名に届きません。** これは想定内として、最初からチャネルごとの担当人数を切っておきます。

| | 目標 | 広告 | ツテ・オーガニック |
|---|------|------|-------------------|
| 男性 | 20名 | 6〜8名 | **12〜14名** |
| 女性 | 10名 | 5〜7名 | **3〜5名** |
| **計** | **30名** | **11〜15名** | **15〜19名** |

**ツテは保険ではなく、半分以上を担う主力チャネルです。** 男性はツテで5〜10名が固い見込みとのことなので、そこからさらに数名の上積みが必要になります。8/12・8/17・8/20の判定日（2章のツテ発動ライン）を待たず、**声かけは配信開始と同時に始めておくのが安全**です。早く動いて埋まりすぎたぶんには、広告を止めれば済みます。

### 5-4. 採算の考え方

会費7,000円に対して参加者1名あたりの粗利を3,000円と仮定すると、CPAが3,000円を超えた時点で単発では赤字です。ただしマニュアル9-5にあるとおり、一度来た人は2回目以降も来る可能性があります。年2回来ると仮定すれば許容CPAは6,000円になります。

初回である今回は、**「3,000円を基準線、5,000円を許容上限、それを超えたら停止」**という3段構えで運用します。

**ただし女性については、この基準を機械的に適用しません。** 女性のCPAが5,000円を超えても、男女比が崩れるほうが会にとっての損失は大きいためです。女性側の停止判断は、CPA単体ではなく「残り日数」と「充足人数」で行ってください（12章）。

## 9. A/Bテストの設計と読み方

### 9-1. 3週間で3つのことを順に検証する

一度に複数を変えると、何が効いたのか永遠に分かりません。**1週間に1変数**です。

| 週 | 検証する変数 | 方法 | 固定するもの |
|----|------------|------|-------------|
| 第1週<br>8/7〜8/12 | **クリエイティブ**（画像2案＋動画1案）<br>＋**男女のCPL倍率の実測** | 男女2セットを同額で並走、各セットに3広告 | 広告文・ターゲティング・配置 |
| 第2週<br>8/13〜8/19 | **広告文**（男女それぞれ2案） | 各セット内で、同じクリエイティブ・文違いを2本 | クリエイティブ・ターゲティング |
| 第3〜4週<br>8/20〜8/30 | **リターゲ vs 新規** | 勝ち組み合わせ＋リターゲセットを追加 | クリエイティブ・広告文 |

> **男女セットの並走は「A/Bテスト」ではありません。**
>
> 前バージョンでは「興味関心セット vs おまかせセット」というオーディエンス比較を第1週に組んでいましたが、**男女比 20:10 という目標が確定したため、この比較は取りやめました。**
>
> 男性セットと女性セットは、勝ち負けを決めて一本化するための2案ではありません。**両方を最後まで走らせる、目的の違う2つの配信**です。「男性のほうがCPLが安いから男性に一本化する」という判断は絶対にしないでください。それをやると男女比が崩れ、会そのものが成立しなくなります。
>
> 第1週に男女で測るのは優劣ではなく、**「女性のCPLは男性の何倍か」という倍率**です。この倍率が、第2週以降の予算配分（5-1）を決めます。

第1週はクリエイティブと男女を同時に見ていますが、**広告セット単位とその中の広告単位で階層が分かれている**ため混ざりません。男女のCPL倍率はセット間の比較で、クリエイティブの優劣は各セット内の3広告の比較で読めます。

### 9-2. Metaの「A/Bテスト」機能を今回オフにする理由

広告マネージャには公式のA/Bテスト機能があり、オーディエンスを重複なく分割して厳密に比較できます。統計的にはこちらが正しいのですが、今回は使いません。

- 予算3万円では、どちらの結果も「統計的に有意」にはなりません。厳密さにコストを払う意味が薄い
- テスト終了まで負けている側にも配信し続けるため、限られた予算が無駄になる
- 期間中に設定を触れないため、8/12の判断で機動的に絞り込めない
- そもそも今回のセット分割は性別による配信の切り分けであって、勝敗を判定する比較ではありません

**代わりにやること：** 男女2セットを同額の日予算で並走させ（8-3の設定）、6日後に数字を比べます。男女で配信対象が重複しないため、オーディエンスの重複を気にする必要もありません。

### 9-3. 8/12レビューでの読み方

広告マネージャの列を「パフォーマンス」→「カスタム列」に変更し、**表示回数 / クリック / CTR / CPM / リード / リード単価** を並べてください。

**① 男女のCPL倍率を出す（最重要）**

```
女性CPL ÷ 男性CPL = 倍率
```

| 倍率 | 第2週以降の日予算 | 考え方 |
|------|------------------|--------|
| 2倍未満 | 男性400円 / 女性900円 | 想定より女性が安い。男性にも余裕を持たせる |
| 2〜3倍（想定） | **男性300円 / 女性1,000円** | 5-1の既定値どおり |
| 3〜5倍 | 男性200円 / 女性1,100円 | 女性に寄せる。男性はツテ比重を上げる |
| 5倍超 | 男性0円（停止）/ 女性1,300円 | **広告は全額女性へ。男性はツテとオーガニックに全面移行** |

女性リードが0〜1件で倍率が計算できない場合は、倍率ではなく「女性側のクリエイティブと広告文が機能していない」と判断してください。予算を増やす前に、10章の別案に差し替えるのが先です。

**② クリエイティブ（各セット3本）の判定**

男女それぞれ独立に判定します。**男女で勝ちクリエイティブが違っても構いません**（むしろ違うのが普通です）。

| 状況 | 判断 |
|------|------|
| 1本に配信が集中している | それが勝ちです。Metaの判断を信じて他をオフに |
| CTRが0.7%未満の広告がある | オフにする |
| 動画のCTRが静止画より低い | 動画をオフ。ただし「動画25%視聴」オーディエンスの蓄積には貢献しているので、リターゲ用の資産としては価値があります |

**③ 女性リード数の判定（ツテ発動）**

| 女性リード数 | 判断 |
|-------------|------|
| 5件以上 | 順調。予定どおり進める |
| **5件未満** | **女性側のツテを発動**（2章）。同時に女性の広告文を10章の案F2に差し替え |
| 0件 | 設定ミスを疑う。「詳細ターゲット設定を拡大」がオンになっていないか、性別が「女性」になっているかを8-3の確認手順で点検 |

**判断の原則：** クリエイティブの数字が僅差のときは、悩まずに「配信量が多いほう」を選んでください。Metaは自動で成果の出ているほうに寄せるので、配信量そのものが投票結果です。

### 9-4. 第2週：広告文のテスト

## 10. 広告文（コピー）案

すべて運用マニュアル4-4のトンマナ（一人称「私たち」／です・ます調／絵文字は控えめ／煽らない／「出会い」ではなく「交流」）に準拠しています。

Metaの表示仕様：メインテキストはスマホで**2行程度**しか表示されず、続きは「…続きを読む」に隠れます。**最初の40文字が勝負**です。見出しは20文字前後で切れます。

**終了時刻について：** 以下の文面は **20:30終了** を前提にしています。2章の項目3で確定させ、異なる場合は該当箇所をすべて差し替えてください。

### 10-1. 広告文が、今回唯一の「質のフィルター」です

4-3のとおり、ターゲティング設定では「マナーがよく落ち着いた人」を選べません。会費7,000円も固定なので、価格によるスクリーニングも使えません。**残された手段は文面とビジュアルだけです。**

やることは絞り込みではなく、**自己選択（セルフセレクション）を促すこと**です。合わない層が自分から降りるように書きます。

| 入れる語 | 降りてもらえる層 |
|---------|----------------|
| 「静かに」「落ち着いて話せる」 | 賑やかな飲み会を求める層 |
| 「お仕事帰りに」 | 平日夜に都心にいない層 |
| 「30名ほどの」 | 大人数のイベントを求める層 |
| 「20:30には終わります」 | 深夜まで飲みたい層 |

逆に、**「ワイワイ」「飲み放題」「たくさんの方と」は絶対に書かないでください。** 一語入るだけで、集まる層が変わります。

**クリエイティブも同じ働きをします。** 現在の素材（ラウンジ・落ち着いた服装・夜景）は、この狙いによく合っています。むしろ画づくりのほうが広告文より強く層を選びます。

### 10-6. 打ち出しの方針：バナーは「ワイン会」で入る

**結論：バナー（画像内の文字）は「ワイン会」で入り、「ハンガリー」は広告文の中と当日に出します。** 消すのではなく、置く場所を変えます。

#### なぜそうするのか（東京のワイン会30件前後のリサーチから）

**1. 初心者向けの会は、ほぼ例外なく一般名詞で入っています。**

東京で継続的に集客できている会は、看板がすべて「ワイン会」です——TOKYO WINE PARTY（独身ワイン会）、CAMOS TOKYO（東京ワイン会）、おとなじかんのワイン会、ソレイユのワイン会、AND WINE CLUB、ワイン会navi。産地や品種を冠したタイトルはワイン愛好家向けの会に集中しており、たとえばジョージアワインの会は「世界最古のワイン生産地ジョージアの美酒と文化に出会う夕べ」「8000年の歴史を紐解き、古代製法を紡ぐ」といった文体です。**明らかに、すでにワインに関心がある層に向けて書かれています。**

今回のターゲットはワイン初心者です。層が違います。

**2. 産地を冠する会は「一言で通じる看板」を持っています。**

ジョージアには「世界最古」「8000年」という、説明が要らない一言があります。ハンガリーの一般認知はトカイ（＝貴腐ワイン＝甘口）に偏っていて、日本ではハンガリーワインの流通量そのものが少ないため、**初心者にとっては「知らない国」＋「知らないワイン」という二重のハードル**になります。1秒で読まれるバナーに置く言葉としては重すぎます。

**3. 各社が紙面を割いているのは、産地ではなく「不安の除去」でした。**

繰り返し出てきたのは次の4点です。これが初心者向けワイン会の実質的な標準装備です。

| 訴求 | 実例 |
|------|------|
| 知識は要らない | 産地・品種・味わいの説明つきワインリストを用意していることを明記 |
| 一人参加が多数派 | CAMOS TOKYOは「参加者の約8割が一人参加」と数字で明示 |
| 立食で動ける | 席を離れるきっかけがあるので会話が固定されない、と説明 |
| 参加者の属性 | 20代後半〜30代中心、男女比3:7〜5:5などを明記（※今回は男女比は書きません。10-5参照） |

**4. 数字が訴求の中心です。** 「レストランで4,000〜8,000円クラスのワインを厳選」「◯種類飲み比べ」など、価格・種類数で価値を示すのが定石でした。**会費7,000円に対して「何が飲めるのか」が、参加判断の最大の材料です。** ここが今の素材にはまったく入っていません（3-3の指摘と同じ問題です）。

**5. ただし「出会い」軸には寄せません。** 東京のワイン会の多くは独身限定・出会い訴求で集客していますが、今回は採用しません。マニュアル4-4の「『出会い』ではなく『交流』」という方針に反するうえ、Metaの出会い系ポリシーに触れます（10-5）。**集客効率だけを見れば有利な軸ですが、ここは踏みません。**

#### 3層に分ける

| 層 | 何を言うか | ハンガリー |
|----|-----------|-----------|
| **バナー**（1秒で読まれる） | ワイン会 ／ 初心者歓迎 ／ お一人参加OK ／ 日時・場所・会費 | **出さない** |
| **広告文**（読む人だけが読む） | 上記＋「今回はハンガリーのワインです」を1行 | **1行だけ出す** |
| **当日・LINE・Instagram** | ハンガリーの物語をすべて | **主役** |

**ブランドの方針は変えていません。** マニュアル4-1のコンセプトは「ハンガリーワインを、あなたの普段の一本に。」であって、主語は「普段の一本」、ハンガリーは手段です。バナーで「ワイン会」と言うのは、このコンセプトにむしろ忠実です。長期ゴール（ハンガリーワインを気軽に飲む風習を日本につくる）も変わりません。

> **広告文からハンガリーを完全に消してはいけません。**
> 当日出るのがハンガリーワインである以上、「知らずに申し込んだ」状態を作ると期待値のズレになります。景品表示法の観点でも、申込フォームまでの導線のどこかには必ず明記が必要です。**バナーに載せないだけで、広告文とフォームには残します。**

#### バナー文言案（画像内テロップ）

いずれも 4:5 と 9:16 の2サイズで書き出し、**日時・場所・会費は下から250px以内に置かない**でください（3-3）。

**案B1：不安の除去（女性セットの本命）**

```
主：ワイン会、はじめてでも。
副：ワインに詳しくなくて大丈夫です
帯：8/31(月) 19:00–20:30 ／ 六本木一丁目駅すぐ ／ 7,000円
隅：お一人参加歓迎 ／ 20歳以上
```

**案B2：中身の価値（男性セットの本命。数字で価値を出す）**

```

副：解説つき。詳しくなくて大丈夫です
```

種類数が確定したら、副を「**◯種類の飲み比べ**」に差し替えてください。**数字が入った瞬間にこの案は強くなります。** 会費7,000円の納得感を作れるのはここだけです。

**案B3：場面（第2週の比較用）**

月曜開催は不利な条件に見えますが、「月曜の夜」は他社の告知にほとんど出てこない切り口です。**弱点を看板にしている**ぶん、記憶に残ります。

#### 「ハンガリー」を出す版も1本だけ走らせます

第1週は男女それぞれクリエイティブ3案を比較する設計です（9-1）。その**3本目を「産地明記版」に充ててください。** 男性セットの案M1（10-3）がそのまま使えます。

意見で決める必要はありません。**同じ予算・同じターゲットで並走させ、CTRとCPLの実測で決めます。**

| 結果 | 判断 |
|------|------|
| 産地明記版のCPLが他の2案と同等かそれ以下 | ハンガリーを前に出してよい。以降のバナーに戻す |
| 産地明記版のCPLが明らかに高い | 本方針どおり「ワイン会」で通す。ハンガリーは広告文の1行に留める |

**この検証は今回かぎりの意味を超えます。** 「ハンガリーを名乗ると獲得コストがどれだけ上がるのか」は、3ヶ月後の本格出稿（マニュアル9-5）でも、Instagramの投稿設計でも効いてくる数字です。3万円で買える情報としては、いちばん価値があります。

#### Instagram側はハンガリーを出したまま

広告バナーの話であって、オーガニック投稿の話ではありません。Instagramではハッシュタグ `#ハンガリーワイン` を含め、産地を前に出す運用を続けてください（マニュアル6章・7章）。**広告は「知らない人に届ける」、投稿は「知った人を深める」で役割が違います。**

## 11. お酒の広告の審査対策

### 11-1. 必ず守る設定

| 項目 | 設定 | 根拠 |
|------|------|------|
| **年齢の下限を20歳に** | 広告セットの年齢を「20〜45」に | Metaのアルコールポリシーは国ごとに最低年齢を定めており、日本は20歳。**これを外すと即審査落ちします** |
| 配信国を日本に限定 | 地域設定が日本国内のみになっていることを確認 | 国によってアルコール広告が全面禁止です |
| クリエイティブに年齢注記 | 広告文に「※20歳以上の方が対象です」 | 必須ではありませんが、審査を通りやすくします |

**「特別な広告カテゴリ」には該当しません。** 特別な広告カテゴリは「信用」「雇用」「住宅」「社会問題・選挙・政治」の4つで、アルコールは含まれません。ここを「該当あり」にしてしまうと詳細ターゲティングが制限され、配信効率が大きく落ちます。**「該当なし」で正しいです。**

### 11-2. クリエイティブで避けること

Metaのアルコールポリシーで問題になりやすいのは以下です。

- 未成年に見える人物が写っている（今回の素材は問題ありません）
- 泥酔・イッキ・大量飲酒を想起させる描写
- 飲酒と運転・機械操作・危険な行為の組み合わせ
- 飲酒が成功や社会的地位、性的魅力をもたらすという示唆
- アルコール度数の強さを売りにする表現

今回の素材は乾杯・グラスを傾ける程度の描写なので、通常は問題ありません。ただし**「口をつけて飲んでいる」カットは国によって厳しく見られる**ため、審査に落ちた場合は乾杯シーン（口をつけていない）中心の版に差し替えてください。動画であれば冒頭の乾杯カットがそれにあたります。

### 11-3. 審査に落ちたときの手順

1. 広告マネージャで拒否理由を確認する（広告名の横に表示されます）
2. 理由が「アルコール」関連なら、**年齢設定が20歳以上になっているかをまず確認**（原因の大半がこれです）
3. クリエイティブが原因なら、11-2に沿って差し替える
4. 理由に納得できない場合は「再審査をリクエスト」を押す。誤判定は珍しくなく、再審査で通ることがよくあります
5. **同じ広告で再審査を3回以上繰り返さない。** アカウント自体に制限がかかることがあります。2回落ちたら別の素材に切り替えてください

**保険として、静止画①②と動画の3本を同時に入稿しておくこと**をおすすめします。1本落ちても配信が止まりません。

## 12. 日々の運用ルールと判断表

### 12-1. 初心者が最も失敗する3つ

1. **配信開始から3日間は絶対に触らない。** Metaは配信開始後、最適な配信先を探す「学習期間」に入ります。ここで予算やターゲットを変えると学習がリセットされ、それまでの費用が無駄になります。数字が悪くても3日は我慢してください。
2. **予算変更は1日1回・20%以内。** 500円 → 600円はOK、500円 → 1,000円は学習リセットです。**8/13の女性セット増額（500円→1,000円）は、8/13に600円、8/14に720円、8/15に860円、8/16に1,000円と4日かけて上げてください。** 一気に倍にすると学習がリセットされ、それまでの6日間が無駄になります。
3. **広告のON/OFFを頻繁にしない。** 1つオフにするたびに、その広告セットの学習がやり直しになる場合があります。判断は週1回のレビューでまとめて行ってください。

### 12-2. 毎日3分のチェック

見るのは4つの数字だけです。広告マネージャのアプリでも確認できます。

- **消化金額**（想定どおりに使えているか）
- **CTR**（クリエイティブが刺さっているか）
- **リード数**（成果が出ているか）
- **リードの男女内訳**（比率が設計どおりか。**今回はこれが最重要**）

スプレッドシートに毎日転記してください。列は13章のとおりです。

### 12-3. 症状別の判断表

| 症状 | 原因 | 対処 |
|------|------|------|
| 配信量がほぼゼロ | 審査落ち / 支払い方法エラー / 日予算が低すぎる | まず審査ステータスと支払い方法を確認 |
| **女性セットに男性のリードが混ざる** | **「詳細ターゲット設定を拡大」がオンになっている** | **即オフに。8-3の確認手順で両セットを点検**（4-1の警告） |
| CPMが2,500円を超える | オーディエンスが狭すぎる | 新宿区・品川区・目黒区を追加して広げる |
| 女性セットのCPMだけ高い | 女性は競合が多く単価が上がりやすい | 2,500円までは許容。それ以上ならクリエイティブを差し替える |
| CTRが0.7%未満 | クリエイティブか広告文が刺さっていない | クリエイティブを差し替える。ここが最も効きます |
| CTRは1%超だがリードが少ない | フォームで離脱している | 質問が4問を超えていないか確認。見出しと広告文の内容が食い違っていないか確認 |
| リードは来るが申込にならない | LINE誘導かフォロー体制の問題 | 完了画面のLINEボタン、LINEのあいさつ文、返信の速さ（マニュアル8-3） |
| 数日で急に成果が落ちた | フリークエンシーが上がりすぎ | 「フリークエンシー」列を確認。2.5を超えたらクリエイティブを差し替える |
| 男性のリード単価が3日連続で1,200円超 | 構成の問題 | 男性セットを一度止め、ツテ比重を上げる |
| 女性のリード単価が3日連続で2,500円超 | 女性側の文面が機能していない | 予算を増やす前に案F2へ差し替え（10章）。それでも改善しなければツテへ |

### 12-4. 撤退ラインと、その使い分け

**男性セットの撤退ライン**（該当したら止めて、残予算を女性セットへ）

- 8/17時点で男性リードが5件未満
- 男性のリード単価が1,500円を3日連続で超えている
- **男性の充足が20名に達した**（ツテ含む）

**女性セットは、原則として最後まで止めません。** CPAが5,000円を超えても、男女比が崩れるほうが会にとっての損失は大きいためです（5-4）。女性側を止めるのは、以下の場合だけです。

- 8/17時点で女性リードが2件未満（**配信の仕組み自体が機能していない**。設定ミスを疑ってください）
- 女性が10名充足した

**キャンペーン全体の撤退ライン**

- 累計消化が25,000円を超え、かつ申込が合計5名未満

止めた場合は、残予算をリターゲティング（4-4）とストーリーズでのオーガニック告知に回してください。

### 12-5. 受付段階での男女比の管理

**広告で作れるのは「リードの比率」までで、「参加者の比率」ではありません。** 最終的な20:10は、受付側で管理します。

1. **リードの男女内訳を毎日記録する**（フォームの性別質問から。8-1）
2. **LINEに来た人の性別も記録する**（あいさつ文で聞くか、やり取りの中で把握する）
3. **申込確定の順序を調整する。** 男性が先に20名に達した場合、以降の男性は「キャンセル待ち」として受け、女性の枠を残してください。ここで先着順のまま受け続けると、比率が崩れたまま当日を迎えます。

**男性がキャンセル待ちになった場合の伝え方：**

```
ありがとうございます。8/31の会はおかげさまで多くのお申込みをいただいており、
現在キャンセル待ちでのご案内となります。

空きが出次第すぐにご連絡いたします。
また、次回以降の会もLINEでご案内しておりますので、ぜひお待ちください。
```

**「男性が定員に達したため」とは書かないでください。** 男女別に枠を設けていることが伝わると、10章の警告と同じ問題（出会い系としての読み替え）が起きます。単に「多くのお申込みをいただいており」で十分です。
