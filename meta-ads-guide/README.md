## 1. 30秒サマリー

| 項目 | 決定案 |
|------|--------|
| キャンペーンの目的 | **リード獲得（インスタントフォーム）** |
| 送客先 | Meta内の申込フォーム → 完了画面でLINE公式へ誘導 |
| 総予算 | **30,000円**（配信 8/6〜8/30 の25日間） |
| 許容CPA | 1件 3,000円（LTVを見込む場合の上限 5,000円） |
| 目標 | 広告経由の申込 **10名** / リード（フォーム送信）30〜40件 |
| ターゲット | 六本木一丁目から半径5km・20〜45歳・全性別 |
| A/Bテスト | 第1週=クリエイティブ3案、第2週=オーディエンス2案、第3週=広告文2案 |
| 使うツール | Meta広告マネージャ（「投稿を宣伝」ボタンは使わない） |

**なぜ「リード獲得」なのか。** 今回はLPがなく、LINE公式も準備中です。この状態でLINEのURLに直接飛ばすと、Metaは「誰が登録したか」を一切受け取れないため、配信の自動最適化が効きません。Meta内で完結するインスタントフォームなら、送信数がそのままMetaに返るので、少ない予算でも「反応する人」に配信が寄っていきます。フォームの完了画面にLINEの友だち追加ボタンを置けば、運用マニュアル9-3で確定した「LINEに貯める」導線も同時に満たせます。

**運用マニュアルとの関係。** マニュアル9-5は「オーガニックで勝ちパターンが見えてから（目安3ヶ月後）広告」としています。今回はそれに反しているように見えますが、狙いが違います。マニュアルが想定しているのは"継続的な集客チャネルとしての広告"で、今回は"8/31という締切がある単発イベントの席を埋めるための小規模テスト"です。総額3万円に上限を切り、ここで得た「どのクリエイティブ・どの層が反応するか」のデータを、3ヶ月後の本格出稿にそのまま持ち込みます。マニュアル側を書き換える必要はありません。

## 2. 明日のMTGで決めること（6項目）

この6つが決まらないと入稿できません。所要15分を想定しています。

| # | 決めること | 推奨案 | 決まらないと |
|---|-----------|-------|-------------|
| 1 | 送客先をどれにするか | リード獲得フォーム＋完了画面でLINE | 入稿できない |
| 2 | 総予算と許容CPA | 30,000円 / CPA 3,000円 | 予算入力ができない |
| 3 | LINE公式の準備担当と期限 | 高橋 / **8月7日(金)まで** | 完了画面が空になる |
| 4 | 動画クリエイティブを使うか | 文字を直して使う（3章参照） | 動画枠が埋まらない |
| 5 | 生成画像であることの扱い | 画像下部に「※イメージ」を追加（3章参照） | 景表法・期待値ギャップのリスク |

## 3. クリエイティブの確認結果（要対応あり）

いただいた素材3点（静止画2枚 / 動画1本）を確認しました。**そのままでは出稿できない箇所が2つ**あります。

### 3-1. 必ず直すもの

**（A）動画のフッター文字が破損している【最優先】**

動画（5秒 / 720×1280 / 9:16）の終盤に表示される2行目のテロップが、日本語として成立していない文字列になっています。

```
実際に表示されている文字：
「全員品限定  ※腓をあるのがら会城場はごご願いくだます。」
```

意図されていたのは「※定員○名限定」「※お一人参加も歓迎です」のような注記だと思われますが、生成の過程で文字が崩れたまま残っています。この状態で配信すると、ブランドの信頼を落とすだけでなく、広告審査でも引っかかる可能性があります。

対応：**そのテロップ行を削除するか、下記に差し替えてください。**

```
定員30名 / お一人参加・ワイン初心者歓迎
```

なお「限定」という語を使う場合は、実際に定員を設けていることが前提です（景品表示法）。定員30名は事実なので「定員30名」と書くのは問題ありません。

**（B）静止画①の日本語が不自然**

- 静止画①：「ワイン不慣れな方も、これから**は**親しみたい方も。」
- 静止画②：「ワイン不慣れな方も、これから親しみたい方も。」

②が正しい表現です。①の「これからは」を「これから」に直してください。広告文の細部の粗さは、そのまま「この会、大丈夫かな」という不安につながります。

### 3-2. 判断が必要なもの

**（C）生成画像を使うことの是非**

3点とも生成画像で、写っている空間は実際の会場（六本木一丁目「経営者の部室」）ではありません。運用マニュアル10-3には、私たち自身のルールとして次の記載があります。

> やってはいけない：生成画像を「当日の様子」として出すこと。世界観の演出には使ってよいですが、実際の会場・実際の参加者に見えるものを生成で作らないでください。参加した人が「写真と違う」と感じた時点で信頼を失います。

今回の素材は「実際の会場に見える」画づくりになっているため、このルールに抵触します。とはいえ8/31まで4週間、いまから撮影に行く余裕がない可能性も高いので、現実的な選択肢を3つ挙げます。

| 案 | 内容 | 工数 | 推奨度 |
|----|------|------|-------|
| 1 | 画像下部に小さく「※画像はイメージです」を入れて使う | 10分 | **推奨** |
| 2 | 会場に行って引きの写真を2〜3枚撮り、静止画①を差し替える | 半日 | 余裕があれば最善 |
| 3 | 会場が写らない画（グラス・ボトル・注ぐ手元のクローズアップ）に差し替える | 1〜2時間 | 次点 |

案1で当面走り、案2の写真が撮れ次第A/Bテストの4本目として投入するのが、時間対効果としては一番良いと考えています。

### 3-3. 追加で作ると効くもの

現状の3点は「タイトル＋日時＋金額」だけで、**場所と申込理由が入っていません**。以下を追記した版を1本作ると、地域ターゲティングとの相性が上がります。

- 「六本木一丁目駅すぐ」（場所の明示。マニュアル4-2の"どこでやってるの？"という不安を潰す）
- 「お一人参加歓迎 / ワイン初心者歓迎」（同じく"ぼっちで浮きそう"を潰す）

また、Instagramのフィード面では **4:5（1080×1350）** が最も面積を取ります。現状の静止画は9:16（ストーリーズ/リール向け）なので、**4:5版も書き出しておく**と配置の自動最適化が活きます。9:16のままでもフィードには配信されますが、上下がトリミングされてタイトルや金額が切れる恐れがあります。

**セーフゾーンの注意：** 9:16素材をストーリーズ/リールに配信すると、上14%・下20%にUI（プロフィール名、CTAボタン）が重なります。現在の素材は日時・金額が下端に寄っているため、**下から250px以内には文字を置かない**よう修正してください。ここが隠れると、広告として最も伝えたい情報が消えます。

## 4. ターゲット設定

運用マニュアル4-2のペルソナをそのまま広告の設定値に落としたものです。

### 4-1. 設定値（そのまま入力してください）

| 項目 | 設定値 | 理由 |
|------|--------|------|
| 地域 | 六本木一丁目駅を中心に**半径5km** | 港区・千代田区・渋谷区・新宿区南部が入る。平日19時開始なので、都心勤務者が動ける範囲 |
| 地域の条件 | 「**この地域に住んでいる人、または最近この地域にいた人**」 | 「住んでいる人」だけにすると、都心に通勤しているだけの人が外れます。今回はここが主戦力なので必ずこの設定に |
| 年齢 | **20〜45歳** | 下限20歳は**アルコール広告の必須要件**（11章）。上限はペルソナの45歳 |
| 性別 | **すべて** | 初期は絞らない。実績が出てから判断（マニュアル4-2） |
| 言語 | 指定しない | 日本語話者は地域設定でほぼ拾えます |
| 詳細ターゲット | 4-2参照（広告セットAのみ） | |
| 配置 | **Advantage+ 配置（自動）** | 手動で絞ると単価が上がります。初回は自動が正解 |

**半径を5kmにする理由。** 3kmだと母数が小さすぎて単価（CPM）が跳ね上がり、10kmだと「わざわざ六本木まで行くほどではない」層まで含まれます。5kmは、月曜19時に六本木へ来ることが現実的な範囲のおおよその境界です。配信量が足りなければ8kmに広げます（12章の判断表参照）。

### 4-2. 詳細ターゲット（広告セットAで使う興味関心）

Metaの「詳細ターゲット設定」で以下を **OR条件（いずれかに該当）** で入れます。候補が見つからない場合は、近い名称のものを選んでください（Metaは項目名を頻繁に変更します）。

- ワイン
- ワインテイスティング
- ソムリエ
- レストラン / 食通（グルメ）
- 料理
- バー / ナイトライフ

**「ターゲットを絞り込む」（AND条件）は使わないでください。** 予算3万円の規模で条件を重ねると、配信対象が数万人まで縮んで単価が跳ね上がります。

**「詳細ターゲット設定を拡大（Advantage+ オーディエンス）」は広告セットAではオフ、Bではオン**にします。この差がそのままA/Bテストの検証項目になります（9章）。

### 4-3. リターゲティング用オーディエンス（第4週で使う）

配信開始と同時に、以下の「カスタムオーディエンス」を作っておいてください。作成した瞬間から蓄積が始まるので、**早く作るほど第4週の在庫が増えます**。

| 名前 | 作り方 | 用途 |
|------|--------|------|
| 動画25%視聴（90日） | カスタムオーディエンス → 動画 → 「動画の25%以上を再生した人」 | 興味は示したが申し込んでいない層 |
| IG接触（90日） | カスタムオーディエンス → Instagramアカウント → 「アカウントに反応したすべての人」 | プロフィールを見た・保存した人 |
| フォーム開封・未送信 | カスタムオーディエンス → リード獲得フォーム → 「フォームを開いたが送信しなかった人」 | **最も濃い層。ここが一番安く取れます** |

第4週（8/24〜8/30）は、この3つを合わせたオーディエンスに「締切」訴求を打ちます。ここのCPAは通常、新規配信の1/2〜1/3になります。

## 5. 予算と目標数値

### 5-1. 予算配分

総額 **30,000円**、配信期間 8/6（木）〜8/30（日）の25日間。

| 期間 | フェーズ | 日予算 | 日数 | 小計 |
|------|---------|-------|------|------|
| 8/6〜8/12 | 第1週：クリエイティブ検証 | 1,400円（700円×2セット） | 7日 | 9,800円 |
| 8/13〜8/23 | 第2〜3週：勝ちパターンに集中 | 1,300円 | 11日 | 14,300円 |
| 8/24〜8/30 | 第4週：リターゲ＋締切訴求 | 800円 | 7日 | 5,600円 |
| | | | **合計** | **29,700円** |

**キャンペーン全体の上限（通算予算）を30,000円で設定しておくこと。** 日予算だけだと、止め忘れたときに上限なく消化されます。広告マネージャのキャンペーン設定で「キャンペーンの支出限度額」を30,000円に入れてください。これが初心者にとって最大の保険です。

### 5-2. 目標数値と、そこに至る計算

3万円で何が起きるかの見積もりです。数字は東京都心・日本語・夜のイベント系の一般的な相場を前提にしています。

```
広告費 30,000円
  ÷ CPM 1,500円（1,000回表示あたりの費用）
  = 表示回数 約20,000回

  × CTR 1.2%（クリック率）
  = クリック 約240回（クリック単価 約125円）

  × フォーム送信率 15%
  = リード 約36件（リード単価 約830円）

  × 申込・来場率 25%
  = 参加者 約9名（CPA 約3,300円）
```

| KPI | 目標 | 判断ライン |
|-----|------|-----------|
| CPM | 1,500円以下 | 2,500円を超えたらターゲットが狭すぎる |
| CTR | 1.0%以上 | 0.7%未満のクリエイティブは止める |
| リード単価（CPL） | 1,000円以下 | 1,500円を超えたらフォームを見直す |
| リード数 | 30〜40件 | |
| 広告経由の申込 | **10名** | 最重要 |
| CPA | 3,000円以下 | 上限5,000円（LTV考慮時） |

**この数字に届かなくても失敗ではありません。** 広告アカウントを新規に作った直後は、Metaが「誰に出せばいいか」を学習していないため、最初の3〜5日は単価が高く出ます。判断は第1週の終わり（8/12）にまとめて行ってください。

### 5-3. 採算の考え方

会費7,000円に対して参加者1名あたりの粗利を3,000円と仮定すると、CPAが3,000円を超えた時点で単発では赤字です。ただしマニュアル9-5にあるとおり、一度来た人は2回目以降も来る可能性があります。年2回来ると仮定すれば許容CPAは6,000円になります。

初回である今回は、**「3,000円を基準線、5,000円を許容上限、それを超えたら停止」**という3段構えで運用します。

## 7. 事前準備（アカウント周り）

広告を出す前に必要なものです。上から順に潰してください。合計で2〜3時間程度です。

| # | やること | 所要 | 注意点 |
|---|---------|------|--------|
| 1 | 個人のFacebookアカウント | 10分 | 広告アカウントの所有には個人アカウントが必ず必要です。実名・本人確認済みのもの |
| 2 | Facebookページ（IZAワインクラブ） | 20分 | Instagram広告を出す場合も**Facebookページは必須**です。プロフィール画像はロゴ06（正方形ゴールド） |
| 3 | Instagramをプロアカウント（ビジネス）に | 5分 | マニュアル3-2。すでに完了していればスキップ |
| 4 | InstagramとFacebookページを連携 | 10分 | Instagramアプリ → 設定 → アカウントセンター → アカウントを追加 |
| 5 | ビジネスポートフォリオ（旧ビジネスマネージャ）を作成 | 15分 | business.facebook.com から。会社名義で作ること |
| 6 | 広告アカウントを作成 | 10分 | 通貨=JPY、タイムゾーン=Asia/Tokyo。**あとから変更できません** |
| 7 | 支払い方法を登録 | 10分 | 法人クレジットカード推奨。デビットカードは弾かれることがあります |
| 8 | リード広告の利用規約に同意 | 5分 | Facebookページ設定 → リード獲得 → 利用規約に同意。**これを忘れるとフォームが作れません** |

## 9. A/Bテストの設計と読み方

### 9-1. 3週間で3つのことを順に検証する

一度に複数を変えると、何が効いたのか永遠に分かりません。**1週間に1変数**です。

| 週 | 検証する変数 | 方法 | 固定するもの |
|----|------------|------|-------------|
| 第1週<br>8/7〜8/12 | **クリエイティブ**（画像2案＋動画1案）<br>＋**オーディエンス**（興味関心 vs おまかせ） | 広告セットを2つ並走、各セットに3広告 | 広告文・予算・配置 |
| 第2週<br>8/13〜8/19 | **広告文**（訴求軸3案） | 勝ちセット1つに絞り、広告文違いを3本 | クリエイティブ・オーディエンス |
| 第3〜4週<br>8/20〜8/30 | **リターゲ vs 新規** | 勝ち組み合わせ＋リターゲセットを追加 | クリエイティブ・広告文 |

第1週だけ2変数（クリエイティブとオーディエンス）を同時に見ていますが、これは**広告セット単位とその中の広告単位で階層が分かれている**ため、混ざりません。オーディエンスの差は広告セットA/Bの比較で、クリエイティブの差は各セット内の3広告の比較で読めます。

### 9-2. Metaの「A/Bテスト」機能を今回オフにする理由

広告マネージャには公式のA/Bテスト機能があり、オーディエンスを重複なく分割して厳密に比較できます。統計的にはこちらが正しいのですが、今回は使いません。

- 予算3万円では、どちらの結果も「統計的に有意」にはなりません。厳密さにコストを払う意味が薄い
- テスト終了まで負けている側にも配信し続けるため、限られた予算が無駄になる
- 期間中に設定を触れないため、8/12の判断で機動的に絞り込めない

**代わりにやること：** 広告セットA・Bを同額の日予算で並走させ（8-3の設定）、7日後に数字を比べます。厳密なA/Bテストではありませんが、判断材料としては十分です。オーディエンスの重複は多少ありますが、この規模では誤差の範囲です。

### 9-3. 8/12レビューでの読み方

広告マネージャの列を「パフォーマンス」→「カスタム列」に変更し、**表示回数 / クリック / CTR / CPM / リード / リード単価** を並べてください。

**オーディエンス（AとB）の判定：**

| 状況 | 判断 |
|------|------|
| リード単価が明確に安いほうがある（差が20%以上） | 安いほうに一本化する |
| ほぼ同じ（差が20%未満） | **Bのおまかせ**を残す。母数が広く、後半に伸びしろがあるため |
| 両方ともリード0件 | オーディエンスの問題ではありません。クリエイティブか広告文か送客先を疑ってください（12章） |

**クリエイティブ（3本）の判定：**

| 状況 | 判断 |
|------|------|
| 1本に配信が集中している | それが勝ちです。Metaの判断を信じて他をオフに |
| CTRが0.7%未満の広告がある | オフにする |
| 動画のCTRが静止画より低い | 動画をオフ。ただし「動画25%視聴」オーディエンスの蓄積には貢献しているので、リターゲ用の資産としては価値があります |

**判断の原則：** 数字が僅差のときは、悩まずに「配信量が多いほう」を選んでください。Metaは自動で成果の出ているほうに寄せるので、配信量そのものが投票結果です。

### 9-4. 第2週：広告文のテスト

勝ち広告セット1つの中に、**同じクリエイティブで広告文だけ違う3本**を入れます。

| 広告名 | 訴求軸 | 狙い |
|--------|-------|------|
| `txt_A_不安解消` | 「詳しくなくて大丈夫です」 | マニュアル4-2の"場違いかも"を潰す |
| `txt_B_珍しさ` | 「フランスでもイタリアでもない」 | マニュアル4-1の差別化軸 |
| `txt_C_場面` | 「月曜の夜、六本木で」 | 時間と場所の具体性 |

文面は10章にあります。

### 9-5. 記録の残し方

テスト結果は必ず1枚のシートに残してください。**次回の広告はこの記録がスタート地点になります。** 記録がないと、毎回ゼロから同じテストをやり直すことになります。


## 11. お酒の広告の審査対策

### 11-1. 必ず守る設定

| 項目 | 設定 | 根拠 |
|------|------|------|
| **年齢の下限を20歳に** | 広告セットの年齢を「20〜45」に | Metaのアルコールポリシーは国ごとに最低年齢を定めており、日本は20歳。**これを外すと即審査落ちします** |
| 配信国を日本に限定 | 地域設定が日本国内のみになっていることを確認 | 国によってアルコール広告が全面禁止です |
| クリエイティブに年齢注記 | 広告文に「※20歳以上の方が対象です」 | 必須ではありませんが、審査を通りやすくします |

**「特別な広告カテゴリ」には該当しません。** 特別な広告カテゴリは「信用」「雇用」「住宅」「社会問題・選挙・政治」の4つで、アルコールは含まれません。ここを「該当あり」にしてしまうと詳細ターゲティングが制限され、配信効率が大きく落ちます。**「該当なし」で正しいです。**

### 11-2. クリエイティブで避けること

Metaのアルコールポリシーで問題になりやすいのは以下です。

- 未成年に見える人物が写っている（今回の素材は問題ありません）
- 泥酔・イッキ・大量飲酒を想起させる描写
- 飲酒と運転・機械操作・危険な行為の組み合わせ
- 飲酒が成功や社会的地位、性的魅力をもたらすという示唆
- アルコール度数の強さを売りにする表現

今回の素材は乾杯・グラスを傾ける程度の描写なので、通常は問題ありません。ただし**「口をつけて飲んでいる」カットは国によって厳しく見られる**ため、審査に落ちた場合は乾杯シーン（口をつけていない）中心の版に差し替えてください。動画であれば冒頭の乾杯カットがそれにあたります。

### 11-3. 審査に落ちたときの手順

1. 広告マネージャで拒否理由を確認する（広告名の横に表示されます）
2. 理由が「アルコール」関連なら、**年齢設定が20歳以上になっているかをまず確認**（原因の大半がこれです）
3. クリエイティブが原因なら、11-2に沿って差し替える
4. 理由に納得できない場合は「再審査をリクエスト」を押す。誤判定は珍しくなく、再審査で通ることがよくあります
5. **同じ広告で再審査を3回以上繰り返さない。** アカウント自体に制限がかかることがあります。2回落ちたら別の素材に切り替えてください

**保険として、静止画①②と動画の3本を同時に入稿しておくこと**をおすすめします。1本落ちても配信が止まりません。

## 12. 日々の運用ルールと判断表

### 12-1. 初心者が最も失敗する3つ

1. **配信開始から3日間は絶対に触らない。** Metaは配信開始後、最適な配信先を探す「学習期間」に入ります。ここで予算やターゲットを変えると学習がリセットされ、それまでの費用が無駄になります。数字が悪くても3日は我慢してください。
2. **予算変更は1日1回・20%以内。** 700円 → 840円はOK、700円 → 2,000円は学習リセットです。増額は数日かけて段階的に。
3. **広告のON/OFFを頻繁にしない。** 1つオフにするたびに、その広告セットの学習がやり直しになる場合があります。判断は週1回のレビューでまとめて行ってください。

### 12-2. 毎日3分のチェック

見るのは3つの数字だけです。広告マネージャのアプリでも確認できます。

- **消化金額**（想定どおりに使えているか）
- **CTR**（クリエイティブが刺さっているか）
- **リード数**（成果が出ているか）

スプレッドシートに毎日転記してください。列は13章のとおりです。

### 12-3. 症状別の判断表

| 症状 | 原因 | 対処 |
|------|------|------|
| 配信量がほぼゼロ | 審査落ち / 支払い方法エラー / 日予算が低すぎる | まず審査ステータスと支払い方法を確認 |
| CPMが2,500円を超える | オーディエンスが狭すぎる | 半径を5km→8kmに広げる。または広告セットBに寄せる |
| CTRが0.7%未満 | クリエイティブか広告文が刺さっていない | クリエイティブを差し替える。ここが最も効きます |
| CTRは1%超だがリードが少ない | フォームで離脱している | フォームの質問を減らす（3問まで）。見出しと広告文の内容が食い違っていないか確認 |
| リードは来るが申込にならない | LINE誘導かフォロー体制の問題 | 完了画面のLINEボタン、LINEのあいさつ文、返信の速さ（マニュアル8-3） |
| 数日で急に成果が落ちた | フリークエンシー（同じ人への表示回数）が上がりすぎ | 「フリークエンシー」列を確認。2.5を超えたらクリエイティブを差し替える |
| リード単価が3日連続で1,500円超 | 構成の問題 | 一度止めて、9-3の読み方でどこが詰まっているか特定してから再開 |

### 12-4. 撤退ライン

以下に該当したら、その時点で残予算を止めてください。惰性で消化するのが一番もったいない使い方です。

- 8/17時点でリードが5件未満（配信の仕組み自体が機能していない）
- リード単価が2,000円を3日連続で超えている
- 累計消化が25,000円を超え、かつ申込が3名未満

止めた場合は、残予算をリターゲティング（4-3）とストーリーズでのオーガニック告知に回してください。

### 13-1. どこで何を見るか
