## 2. Square 決済リンクの作成

Facebookイベントページを作ってから、そのURLを埋めるためにこちらを作ります。**順番は FBイベント → Square → FBイベントにURLを貼る**です。

### 2-1. 手順

1. Squareダッシュボード → **オンラインチェックアウト** → **支払いリンク**
2. **「商品やサービスを販売する」** を選択（「支払いを受け取る」ではありません。数量制限と在庫管理が使えるのはこちらです）
3. 下記の設定値を入力
4. 作成後に発行されるURLを、FBイベントのチケットURLと説明文の2か所に貼る

### 2-2. 設定値

| 項目 | 設定値 |
|------|--------|
| 商品名 | `IZAワイン会 参加費｜2026年8月31日（月）19:00-20:30 六本木一丁目` |
| 説明 | `ワイン数種・軽食つき／定員30名／20歳以上の方が対象です。当日のキャンセルは返金いたしかねます。` |
| 金額 | **7,000円**（税込。要確定） |
| 数量の指定 | **お客様が数量を選択できる** をON（お連れ様の分をまとめて購入できるようにするため） |
| 在庫数 | **30**（売り切れたら自動で受付停止になります） |
| 配送 | なし（デジタル／サービス扱い） |

### 2-3. 収集する情報（ここが重要です）

購入時に集める項目を必ず設定してください。**あとから聞き直すことはできません。**

| 項目 | 必須 | 理由 |
|------|------|------|
| 氏名 | 必須 | 受付名簿 |
| メールアドレス | 必須 | リマインド送信 |
| 電話番号 | 必須 | 当日の緊急連絡 |
| **性別** | 必須 | **男女比20:10の管理に必須。** Squareは自動取得しません。聞かないと比率管理も広告の予算再配分もできません（ガイド8-1と同じ理由） |
| ご参加人数の内訳 | 任意 | 「お一人／お連れ様あり」。次回の「一人参加◯割」という訴求のための実測データになります（リサーチノート2章） |
| どこで知りましたか | 必須 | **チャネル別の効果測定はこれだけが頼りです。** 選択肢：`Instagram広告` / `Facebook広告` / `Instagramの投稿` / `Peatix` / `知人の紹介` / `その他` |

### 2-4. 購入後のメッセージ


> **LINEの導線をここに必ず入れてください。** Squareで決済が完結すると、そのままでは連絡先がSquareの中にしか残りません。マニュアル9-3で決めた「LINEに貯める」が働かなくなります。**この会の資産は友だち数であって、1回の参加者数ではありません。**

### 2-5. 手数料

Squareのオンライン決済（支払いリンク）は**3.6%**、月額費用なしです。

```
7,000円 × 3.6% = 252円/件
30件すべて売れた場合 = 7,560円
```

Peatix（4.9% + 99円/枚 → 30件で13,260円）より安く、決済ページのブランドも自社側に置けます。一方でPeatix側にある**「探している人に見つけてもらえる」集客力はSquareにはありません。** 両方使う前提で4章を書いています。

| **A：Metaインスタントフォーム** | 広告 → Meta内フォーム → 完了画面でSquareとLINE | Squareの3.6%のみ | **完全に取れる**。リード数がMetaに返り、配信が自動最適化される |
| **B：FBイベント＋Square** | 広告 → FBイベントページ → Square | Squareの3.6%のみ | **ほぼ取れない**。リンククリックまで |
| **C：Peatix** | 広告 or 自然流入 → Peatix | 4.9% + 99円/枚 | 取れない。Peatix側の販売数で突合 |

### 4-2. 推奨：Aを主軸、Bを併走、Cは掲載だけ先に

**広告の着地先はA（インスタントフォーム）を主軸にしてください。** 理由は手数料ではなく計測です。

BとCはMetaに成果が返らないため、**配信の自動最適化が効きません。** 予算3万円という規模では、Metaに「誰が反応したか」を教えられるかどうかが結果を大きく分けます。BやCに全額を流すと、Metaは何も学習しないまま24日間を終えます。

そのうえで：

- **B（FBイベント＋Square）は無料で作れるので必ず作ります。** 広告の着地先としてではなく、**オーガニックの受け皿・知人への共有先**として機能します。A1さんの拡散、知人への声かけ、Instagramのプロフィールリンク——これらの行き先がBです
- **C（Peatix）は掲載だけ先に出します。** 「ワイン会を探している人」に見つけてもらう枠であって、広告を流す先ではありません（リサーチノート3章）
- **着地先のABテストは第2週に。** 8/13以降、S1の予算の一部（1日200円程度）だけをBに流し、CVR差を見ます。第1週から分けると、どちらも学習が進みません

### 4-3. 手数料の「二重取り」について

MTGで出た違和感——「広告費を払ってPTXを宣伝し、さらに手数料を取られる」——は正確な指摘です。**だからこそ、広告費を使う先はSquare（3.6%）に閉じます。** Peatixは広告費をかけずに置いておく無料の窓口として使い、そこから来た人の分だけ手数料を払う、という切り分けにしています。
