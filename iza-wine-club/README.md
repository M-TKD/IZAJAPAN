## 1. 基本方針 — なぜ1アカウントに集約するのか

**ブランド名：IZA WINE CLUB（仮名）**

| 媒体 | アカウント数 | 中身の分け方 |
|------|------------|------------|
| Peatix | **1グループ** | イベントごとにタイトル冒頭の【　】タグで区別 |
| LINE公式 | **1アカウント** | 友だち追加後の回答をもとに**タグ**で区別し、配信を出し分け |
| Instagram | **1アカウント** | 投稿・ハイライト・カテゴリーで区別 |
| Facebook | **1ページ** | 投稿・イベントページで区別 |

### この方針が正しい理由

1. **フォロワーが分散しない。** 企画ごとにアカウントを分けると、1つあたりのフォロワーが少ないまま増えません。Peatixは特に、**過去の参加者がフォロワーとして貯まり、次回イベントを公開した瞬間に自動で通知が飛ぶ**仕組みです。この資産を6分割すると、通知の効き目も6分の1になります
2. **横の移動が起きる。** 初心者向けに来た人が半年後にワインラバー向けへ、経営者ワイン会の参加者がグルメ会へ、という移動は同一アカウント内でしか起きません。分けた瞬間に、その人はもう一度あなたを見つけ直さなければならなくなります
3. **運用工数が6分の1で済む。** 現状の体制は髙橋＋秘書の2名です。6アカウント×4媒体＝24アカウントの運用は物理的に不可能です

### この方針の弱点（承知したうえで進める）

**「誰向けの会か」が伝わりにくくなります。** 婚活ワイン会の告知が経営者ワイン会の参加者に届くと、ノイズになります。これを埋めるのが**2章のシリーズタグ**と**4章のLINEタグ**です。この2つがセットで初めて、1アカウント集約が成立します。**タグ運用を省略すると、この方針は単に「雑多なアカウント」になります。**

## 2. シリーズ設計（6企画）

すべてのイベント名は次の形式で統一します。

```
【シリーズタグ】イベント名｜開催日(曜日)会場エリア
```

例：`【初心者向け】上質だけど、やさしい。気軽に楽しむハンガリーワイン会｜8/31(月)六本木`

| # | シリーズタグ | 対象 | 位置づけ | 参考会費 |
|---|------------|------|---------|---------|
| 1 | **【初心者向け】** | ワインに詳しくない人、少し苦手な人 | **入口。** ここから他シリーズへ送る。当面の主力 | 8,000円 |
| 2 | 【経営者限定】 | 経営者・事業主 | 既存のClass-E（経営者交流ワイン会）を継承 | 要設定（従来Class-Eの価格帯） |
| 3 | 【婚活】 | 独身・出会いを求める人 | 男女比の管理が必須。**運用難度が最も高い**（8章参照） | 要設定 |
| 4 | 【グルメ】 | 食との組み合わせに関心がある人 | ペアリング主体。料理側の設計が必要 | 要設定 |
| 5 | 【講座】 | 学びたい人 | ハンガリーワイン会兼講座。**リピート率が最も高くなる想定** | 要設定 |
| 6 | 【ワインラバー向け】 | すでにワインが好きな人 | 【初心者向け】の卒業先。単価を上げられる | 要設定（初心者向けより高め） |

### シリーズ間の設計思想

**【初心者向け】が入口、【講座】と【ワインラバー向け】が受け皿です。**

一度参加した人が「次は何に行けばいいか」が分かる状態を作ってください。8/31当日に**次回シリーズの案内を必ず配る**のが、この設計を機能させる最短の方法です。

一方で、**6シリーズを同時に立ち上げないでください。** 現在の体制で並行運用できるのは2〜3シリーズです。推奨する順序は次のとおりです。

1. 【初心者向け】（8/31・実施中）
2. 【経営者限定】（Class-Eの資産があるため立ち上げコストが低い）
3. 【講座】（リピートを作る）
4. 以降は反応を見て

**【婚活】は最後に回すことを推奨します。** 理由は8章に書きました。

## 3. Peatix

### 3-1. 既存アカウントの流用について

髙橋の方針は**既存アカウント（`https://peatix.com/user/28785710/dashboard`）を改修して活用**です。これは妥当です。過去の参加者・フォロワーが残っているなら、新規作成はその資産を捨てることになります。

ただし、**8/6のMTGでは「PTX・こくちーずのアカウントは個人名義ではなく事業用に新規作成」と決めていました**（PR #11 ローンチキット 0章 決定8）。方針が変わったので、新規作成の代わりに**既存アカウントを事業用に作り替える**必要があります。具体的には次の3点です。

| # | やること | 理由 |
|---|---------|------|
| 1 | **主催者（グループ）名を「IZA WINE CLUB」に変更** | 参加者に表示されるのは主催者名です。個人名のままだと「誰が主催の会か」が伝わらず、8,000円を振り込む相手として信頼されません |
| 2 | **ログイン用メールアドレスを会社管理のアドレスに変更** | 個人のGmailに紐づいたままだと、担当交代・退職時にアカウントごと失われます。売上と参加者リストが個人アカウントに乗っている状態は避けてください |
| 3 | **売上の受取口座をIZA株式会社名義に設定** | 個人口座に入金されると法人の売上計上が煩雑になります。今回は銀行振込のためPeatix決済を使わない可能性もありますが、設定だけは先に済ませてください |

> **法人名義への変更は、参加者から見えるすべての面（主催者名・支払明細・領収書）に影響します。** 過去イベントの表示名も変わる可能性があるため、変更前に現在の設定をスクリーンショットで残しておいてください。

### 3-3. イベント公開時の共通ルール

- タイトルは2章の形式（【タグ】名前｜日付・エリア）を必ず守る
- **カテゴリーは公開より前に申請する。** Peatixのカテゴリーは主催者が申請してPeatix側が設定する方式で、即時には反映されません。カテゴリーが付くまでPeatix内の検索・一覧に出ないため、**公開当日に申請したのでは間に合いません**
- **カバー画像は2:1の横長**（1440×720px推奨。正確な仕様は作成画面の表示に従う）。文字は中央60%に収める。制作の見本 → [`peatix-cover.html`](../events/2026-08-31-hungary-wine/peatix-cover.html)、ルール → [イベント要項4-2-2](../events/2026-08-31-hungary-wine/README.md#4-2-2-カバー画像)
- **申込者への質問（アンケート）を必ず設定する。** 「どこで知ったか」「お一人での参加か」の2問だけでも、次回の告知文の強さが変わります（[イベント要項4-2-1 ⑤](../events/2026-08-31-hungary-wine/README.md#4-2-1-入力項目チェックリスト画面の順)）
- **決済手数料は主催者負担にする。** 参加者負担にすると表示価格が告知した会費を超えます
- **公開ページに銀行口座番号を書かない**（[イベント要項1章](../events/2026-08-31-hungary-wine/README.md#1-確定要項この表が正)の注意）
- 説明文の末尾に必ず**公式LINEの友だち追加リンク**を置く（Peatixで見つけた人をLINEに移す。これが資産化の本体）
- 過去イベントは削除せず残す。**開催実績の件数そのものが信頼材料**になります

### 3-4. 手数料

| 支払方法 | 手数料 |
|---------|-------|
| Peatix決済（クレジットカード等） | 4.9% ＋ 99円/枚 |
| 当日現金払い・無料（0円）チケット | **0円** |

30名×7,000円をすべてPeatix決済で販売した場合：`210,000円 × 4.9% ＋ 99円 × 30枚 ＝ 13,260円`。

**「手数料の二重取り」への違和感（MTG決定7）への回答。** 銀行振込で受ける限り、Peatixに支払うのは掲載料ではなく決済手数料だけです。無料チケットで申込のみ受ければ0円で使えます。ただし0円設定は**ドタキャン率が明確に上がる**ため、金銭的コストとキャンセルリスクのトレードオフだと考えてください。8/31回で有料設定を試し、次回に比較するのが妥当です。

## 4. LINE公式アカウント

**LINEが本体です。** Peatix・Instagram・Facebook・広告は、すべて「LINEに人を集めるための入口」だと考えてください。理由は、LINEだけが**こちらから届けられる**チャネルだからです。

### 4-1. 友だち追加後のフロー

```
友だち追加
  ↓
あいさつメッセージ（自動）
  ↓
「興味のある会をお選びください（複数可）」← 選択式
  ↓
返信を受信 → 秘書が手動でタグ付け
  ↓
タグに応じたイベント案内を配信
```

あいさつメッセージ（案）：

```
ご登録ありがとうございます。
IZA WINE CLUB です。

ハンガリーワインを気軽に楽しむ会を、東京で開いています。
ワインに詳しくない方も、少し苦手に感じている方も歓迎です。

はじめに、ご興味のある会をお教えください。
下記から当てはまるものを、いくつでもお送りください。
（例：「1と5」のように番号でお送りいただければ大丈夫です）

1. ワインに詳しくなくても楽しめる会
2. 経営者・事業主の方の交流会
3. 出会いのある会
4. 料理とのペアリングを楽しむ会
5. ハンガリーワインを学べる講座
6. ワイン好きの方向けの、少し踏み込んだ会

いただいた内容に合わせて、会のご案内をお送りします。

--------------------
直近の開催
8月31日（月）19:00 東京・六本木
上質だけど、やさしい。気軽に楽しむハンガリーワイン会
会費 8,000円（このLINEにご登録の方は7,000円）

ご参加をご希望の方は「8月31日参加希望」とお送りください。
--------------------
```

> **選択肢に【婚活】と書かないこと。** 「3. 出会いのある会」のように婉曲に書きます。婚活と明示すると、そう思われたくない人が選ばなくなり、実態より少ない数字が返ってきます。

### 4-2. タグ設計

| タグ名 | 付与条件 | 用途 |
|-------|---------|------|
| `初心者` | 選択肢1を選んだ | 【初心者向け】の案内 |
| `経営者` | 選択肢2を選んだ | 【経営者限定】の案内 |
| `婚活` | 選択肢3を選んだ | 【婚活】の案内 |
| `グルメ` | 選択肢4を選んだ | 【グルメ】の案内 |
| `講座` | 選択肢5を選んだ | 【講座】の案内 |
| `ワインラバー` | 選択肢6を選んだ | 【ワインラバー向け】の案内 |
| `参加者_2026-08-31` | 8/31に実参加した | 参加実績。**最も価値が高いタグ** |
| `未入金_2026-08-31` | 申込済・入金待ち | リマインド配信用。入金後に外す |
| `無反応` | 追加後2週間、何も返信がない | 別の切り口で再アプローチ |

**回開催ごとに `参加者_YYYY-MM-DD` タグを必ず付けてください。** 「過去に一度でも来たことがある人」は、他のどのセグメントより申込率が高くなります。次回の告知は、まずこの層だけに先行配信するのが定石です（先行案内は特別感も生みます）。

### 4-3. 手動運用から自動化へ

髙橋の方針どおり、**当初は手動でタグ管理**します。切り替えの目安は下記です。

| 友だち数 | 運用方法 |
|---------|---------|
| 〜200人 | **手動タグ付け。** 返信を読んで秘書が付ける。相手ごとの文脈が分かる利点もある |
| 200〜1,000人 | LINE公式の**リッチメニュー＋自動応答**でタグを自動付与。無料枠内で可能 |
| 1,000人〜 | 外部CRM（LステップやEC Force等）の導入を検討。**月額が発生するので、それに見合う配信数があるかで判断** |

**手動でやりきれなくなる前に切り替えてください。** タグ付けが2週間滞ると、その間の登録者はセグメント配信の対象から漏れます。

### 4-4. 配信の頻度

| 種別 | 頻度 | 対象 |
|------|------|------|
| イベント告知（新規公開時） | 1回 | 該当タグのみ |
| 締切リマインド | 1〜2回 | 該当タグのうち未申込者 |
| 未入金リマインド | 1回（期限2日前） | `未入金_` タグ |
| 読み物（ハンガリーワインの話など） | 月1〜2回 | 全員 |

> **無料プランのメッセージ数上限に注意。** LINE公式の無料プランは月200通です。友だち200人に月1回配信しただけで上限に達します。**セグメント配信が必須になるのは、この制約のためでもあります。** 全員配信を繰り返すと、告知したい相手に届かなくなります。

## 6. アカウント権限の付与（masashi523@gmail.com）

**運用を回すには、秘書側（masashi523@gmail.com）に各アカウントの管理権限が必要です。** パスワードを共有するのではなく、**媒体の権限機能を使って正式に追加**してください。パスワード共有は、2段階認証で詰まる・退職時に全パスワードを変える必要がある・誰が何をしたか追えない、の3点で必ず問題になります。

| 媒体 | 権限の種別 | 手順 |
|------|-----------|------|
| **Peatix** | グループの共同管理者 | グループ管理画面 → メンバー → 招待 → `masashi523@gmail.com` を「管理者」で招待 |
| **LINE公式** | 運用担当者 | LINE Official Account Manager → 設定 → 権限管理 → メンバーを追加。**権限は「運用担当者」**（「管理者」は髙橋のみ。運用担当者は請求・退会の操作ができないため、事故を防げます） |
| **Instagram** | Metaビジネスマネージャー経由 | ビジネスマネージャー → ユーザー → 追加 → `masashi523@gmail.com` → 資産（Instagramアカウント）に「コンテンツの管理」権限を割り当て |
| **Facebookページ** | ページの編集者 | 同じくビジネスマネージャーから「編集者」権限を割り当て。**「管理者」は髙橋のみに留める** |
| **Meta広告アカウント** | 広告管理者 | ビジネスマネージャー → 広告アカウント → ユーザーを追加。支払い方法の編集権限は付けない |
| **Googleドライブ / スプレッドシート** | 編集者 | 該当フォルダを共有 → 編集者。**「リンクを知っている全員」にはしない** |

### 権限を分ける原則

**髙橋＝管理者（オーナー）、秘書＝運用担当者。** この境界を守ってください。

## 8. 注意すべきリスク

### 8-1. 【婚活】シリーズを最後に回すべき理由

3つの理由から、最も運用難度が高いシリーズです。

1. **Meta広告が出せなくなる可能性。** 出会い・マッチングを訴求する広告は審査が厳しく、アカウント単位でペナルティを受けることがあります。1アカウント集約している以上、**婚活シリーズの1本が原因で、他5シリーズの広告まで止まる**リスクを負います
2. **男女比の管理が必須。** 集客の難易度が跳ね上がります。他シリーズは多少偏っても成立しますが、婚活は偏った瞬間に成立しません
3. **ブランドの位置づけが揺れる。** 「ハンガリーワインを日常の選択肢にする」という核（マニュアル4-1）と、婚活イベントの距離が最も遠いのがこのシリーズです。他のシリーズが育つ前に出すと、外から見たときに「婚活イベント屋」に見える危険があります

**やらないほうがよい、という話ではありません。** 順番の問題です。【初心者向け】と【講座】でブランドが立ってからのほうが、婚活シリーズ自体も成立しやすくなります。

### 8-2. 1アカウント集約で壊れやすいのは「タグ運用」

**この方針の成否は、タグ運用が続くかどうかだけで決まります。** タグが付いていない登録者には、結局全員配信しかできず、それはLINEの無料枠を食い潰します（4-4）。

秘書の作業として、**「LINEの返信を読んでタグを付ける」を毎日の固定業務にしてください。** 溜めると必ず破綻します。
