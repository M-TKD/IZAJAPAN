## 2. イベント名について

**「初級者向け」「初心者向け」という名称は使いません。**

正式名称：

```
上質だけど、やさしい。気軽に楽しむハンガリーワイン会
```

この名前が選ばれた理由（髙橋の意図）は3点です。運用中に名前を縮めたり言い換えたりするときも、この3点を壊さないでください。

1. **「初心者」と呼ばない。** 呼んだ瞬間に「自分は下」という位置づけが生まれ、不安を取り除くどころか強めてしまう
2. **甘口から楽しんでよい、と公式に肯定する。** 辛口・渋味から入る必要はない（マニュアル4-1の「甘口から入ってOK」方針と一致）
3. **ハンガリーワインを日常の選択肢にする**という事業の核を、名前の段階で背負わせる

### 「初心者」という語をどこで使ってよいか

名前と本文では使いませんが、**検索キーワードとしては使います**。両者は役割が違います。

| 場所 | 「初心者」を | 理由 |
|------|------------|------|
| イベント名・本文・広告文 | **使わない** | 参加者への呼びかけ。ここで使うと不安を強める |
| Peatixのタイトル冒頭タグ【　】 | **使う**（【初心者向け】） | シリーズの識別子。かつPeatix内で実際に「ワイン会 初心者」で検索される |
| ハッシュタグ・検索キーワード | **使う** | 検索窓に打ち込まれる語なので、外すと見つけてもらえない |

> 【初心者向け】というタグ表記が気になる場合は【初心者歓迎】に置換可能です。呼びかけとして自然になる一方、検索での一致は少し弱まります。**現時点では髙橋の指定どおり【初心者向け】で進めます。**

## 4. 媒体別の告知文

### 4-1. 会費の見せ方（全媒体共通のルール）

二段階価格は、**LINE登録を増やすための仕組み**です。したがって書き方が結果を左右します。

| 書き方 | 判定 |
|--------|------|
| 「8,000円（公式LINE登録で7,000円）」 | **これを使う。** 登録すると1,000円得をする、が一目で伝わる |
| 「7,000円〜8,000円」 | 使わない。どちらか分からず、問い合わせが増える |
| 「7,000円」 | 使わない。登録の動機が消え、通常価格の人から取りこぼす |

LINE登録が申込導線そのものなので、**1,000円は割引ではなく「導線への通行料の免除」**だと考えてください。全員に登録してもらうのが正しい状態です。

### 広告予算について（要判断）

広告ガイドは**30,000円 / 24日間**の設計でしたが、配信可能期間が**8/15〜8/24の10日間**に縮みました。そのまま30,000円を10日に詰めると日予算が3,000円/日となり、学習期間（Metaが最適化のために必要とする期間）を確保できないままイベント日を迎えます。

推奨は次のどちらかです。

- **A案（推奨）：予算を20,000円に減らし、女性セットに集中。** 期間が短いときにセグメントを増やすと、どれも学習が終わりません。今回は「女性・25〜40歳・港区/千代田区/中央区/渋谷区」の1セットに絞り、男性はツテとオーガニックで確保する
- **B案：30,000円のまま2セット。** データは多く取れますが、8/31の集客としては効率が落ちます。「次回のための学習データを買う」と割り切る場合のみ

**A案を推奨します。** 今回の広告はもともと単発テストであり、締切までの日数が半分以下になった以上、テストの幅より1セットあたりの配信量を優先すべきです。

1. 「8月31日参加希望」を受信したら、**24時間以内に**返信する
2. 返信内容：申込を受け付けた旨 ＋ 会費（LINE登録済みなので7,000円）＋ **振込先** ＋ 振込期限8/24 ＋ 「0831」を名前の前に付ける依頼
