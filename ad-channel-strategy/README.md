## 議題2｜申込導線とMeta広告の設定（15分）

### 申込導線をどうするか ★議論ポイント

現ページ：https://peatix.com/event/5131090

**3案あります。**

| | 手数料（30名時） | 世界観 | 離脱 | 制作の手間 |
|---|---|---|---|---|
| **A. Peatixで完結**（現状） | 491円/枚 ＝ **約14,700円** | △ テンプレの制約あり | **最小**（広告から1クリック） | **ゼロ** |
| B. 自社LP → Square決済 | 約288円/枚 ＝ **約8,600円** | ◎ 自由 | LP→決済で1段増える | LP制作が必要 |
| C. Peatix掲載 → 自社決済へ誘導 | ほぼ0円 | ○ | **最大**（2段） | 規約の確認が必要 |

**推奨：A（Peatixで完結）＋ ツテ・LINEにはSquareリンク。** 理由は3つです。

- **手数料の差は約6,000円**。LPを作る工数と、1段増えることによる離脱リスクに見合いません
- **Cは、Peatixを使う意味を自分で消してしまいます。** Peatixの価値は「探している人がその場で買えること」で、外に飛ばすと最も確度の高い層が1段落ちます。上位掲載に3,000円払って外部へ送るのは、なおさら噛み合いません（**Peatixの規約上どこまで許容されるかも要確認**）
- Bは**次回以降の選択肢**として持っておきます。月1回の定例にするなら自社LPを1枚持つ価値はあり（Meta Pixelが置ける・世界観を作れる）、`class-e-lp` をテンプレートとして流用できます

```
Meta広告（IG/FB面）  →  Peatixのイベントページ  →  その場で購入・完了
ツテ・LINE・直接案内  →  Squareの決済リンク
```

> **ただし「どんな人たちで、どんな会なのか分かりづらい」は、ページの置き場所を変えても解決しません。**
>
> これは**中身（写真と文章）の問題**です。自社LPを作っても、載せる素材が同じなら同じことが起きます。8/12で確認したとおり会場写真は存在せず、使えるのは過去開催の実写のみ。**まずPeatixページの中身で解決を試みて、それでも足りなければ次回LPを検討する**、という順序を提案します。
>
> 「どんな会か」に直接効くのは次の4つです。
> - **過去開催の写真を3〜5枚**（「過去の開催の様子」と明記。ガイド3-2）
> - **当日の流れ**（19:00受付 → … → 20:30終了）
> - **参加者の属性を1行**（「20代後半〜30代の方が中心」など、事実の範囲で）
> - **主催者が誰か**（IZA株式会社／顔の見える1〜2行）
>
> あわせて、**Peatixページから Instagram にリンクを張る**のが有効です。写真と過去のレポートで雰囲気を伝えるのは、まさに議題3で Instagram に割り当てた役割（信用・記録）そのものです。Peatixのテンプレートでは作れない部分を Instagram に肩代わりさせられます。

## 議題3｜LINE・Instagram・Facebook の役割分担（15分）★未決

いただいた方針（LINE＝初心者、Facebook＝経営者、その間をステップアップ）を整理すると、こうなります。

| | 誰向け | 役割 | 今回やること |
|---|---|---|---|
| **LINE公式** | **初心者・ライト層** | **入口。参加者を溜める** | 今回の参加者を友だちにする |
| **Facebook** | **経営者** | **ステップアップ先。既存のページを温存** | 初心者向けの発信はしない |
| **Instagram** | 初心者・共通 | 見に来られたときの信用・記録（ブログ的） | 週1〜2投稿。今回の集客には効かない |

```
Meta広告 / Peatix  →  8/31 参加  →  LINE（初心者コミュニティ）
                                        ↓ 一部がステップアップ
                                     Facebook（経営者コミュニティ）
```

**ここで1つ判断が要ります。Meta広告を出すにはFacebookページが必須です。**

既存の経営者向けページで出すと、**初心者向けワイン会の広告が経営者向けの名義で表示されます**。

- **推奨：「いざワインクラブ」のページを新規作成する**（20分）。広告に出る名前は初心者に見える名前であるべきで、既存の経営者ページは経営者コミュニティ用に温存できます
- 既存ページで出す案：作成の手間はゼロですが、名義がターゲットとズレます

**決めること**
- [ ] 上の役割分担でよいか
- [ ] Meta広告用に「いざワインクラブ」FBページを新規作成するか
- [ ] Instagramは「いざワインクラブ」1アカウントに集約でよいか（8/12案のまま）
- [ ] 投稿の担当（制作・投稿＝秘書／最終判断＝高橋 の既定でよいか）
