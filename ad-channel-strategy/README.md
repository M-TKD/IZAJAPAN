## 1. 結論

**両方やります。ただし「両方に広告費を出す」という意味ではありません。**

| | やること | 費用 |
|---|---------|------|
| **Peatix** | **イベントページを掲載する（掲載自体は無料）**。売れたときだけ手数料 | **¥0**（＋売れた分だけ 4.9%＋99円/枚） |
| **Peatix** | 上位掲載（有料オプション）を10日間 | 約 **¥3,000**（1日300円〜） |
| **Meta** | 女性ターゲット1セットに集中して少額配信 | 約 **¥7,000** |
| LINE広告 | **やりません**（新規アカウントが開設できないため。4章） | — |
| Yahoo!検索広告 | **やりません**（14日では立ち上がらない） | — |
| | **合計** | **約 ¥10,000** |

**なぜこの結論になるのか、最も重要な一点だけ先に書きます。**

Peatixの掲載は**出稿ではなく出品**です。掲載しておくだけなら費用は1円もかからず、チケットが売れたときだけ 4.9%＋99円 を払います。会費7,000円なら**1名あたり約442円**。

一方Meta広告は、申込が0名でも予算を使い切ります。Meta広告ガイド5-4が置いた目標CPA（申込1件あたりの費用）は**基準線3,000円・上限5,000円**です。

```
Peatix経由の1名   ： 約442円（しかも売れなければ0円）
Meta広告経由の1名 ： 3,000円が基準線、5,000円で撤退
```

**約7倍の差があり、しかもPeatix側は前払いリスクがゼロです。** この構造を知ったうえで「Peatixに載せない」という判断はできません。まず載せる。広告費をどこに置くかは、その次の話です。

> **8/12の「一旦PTXなしでMetaを中心に」という判断を、覆す提案になります。**
>
> 8/12時点では、Peatixも「オークション形式で予算次第、ただし母数はMetaより少ない」という前提で議論されていました。**この前提が事実と違います。** Peatixの集客サービスは入札ではなく**固定価格の枠売り**で、そもそも掲載自体は無料です。当時の情報からすれば妥当な判断でしたが、前提が変わったので結論も変わります。
>
> ただし「**広告費の主力はMeta**」という部分は維持します。8/12の議論の核だった「探していない人にも想起させられるのはMetaだけ」という指摘は、そのとおりだからです。

## 2. 「MetaかPeatixか」は、そもそも比較になっていない

同じ「広告」という言葉で呼んでいますが、**買っているものが違います。**

| | Meta広告 | Peatix |
|---|---------|--------|
| 何をする道具か | **需要創出**。ワイン会を探していない人の前に割り込む | **需要獲得**。すでにイベントを探している人に見つけてもらう |
| 相手の状態 | 何も探していない（スクロール中） | 「今週末なにかないか」と検索中 |
| 課金の形 | 入札（オークション）。表示された時点で課金 | 掲載は無料。**売れたときだけ**手数料 |
| 立ち上がり | 学習期間3〜5日。すぐには効かない | **即日**。学習期間の概念がない |
| 上限 | 予算を積めば伸びる（ほぼ青天井） | **母数が上限**。探している人の数以上には売れない |
| 成果がどこに残るか | Meta側（次回はまたゼロから入札） | Peatix側（購入者リストは残るが自社資産ではない） |
| 比率・人数の制御 | 広告セットの分割で「間接的に」寄せる | **チケット種別と枚数上限で直接コントロールできる** |

**つまり、択一の関係ではありません。** Metaは「知らない人に知らせる」ための道具で、Peatixは「探している人を取りこぼさない」ための受け皿です。片方だけだと、それぞれ次の失敗をします。

- **Metaだけ**：わざわざ「ワイン会」を検索している、いちばん確度の高い層を丸ごと取り逃す
- **Peatixだけ**：探している人の母数（東京・平日夜・ワイン）を超えられず、そこで頭打ちになる

**予算1万円で両方に「広告費」を割るのは分散のしすぎです。** そうならないのは、Peatix側の主力が有料広告ではなく**無料掲載**だからです。無料掲載＋少額の上位掲載で受け皿を作り、広告費の本体はMetaに置く。これが1万円という制約下で唯一成立する形です。

## 3. 汎用：チャネルを決める5つの問い

**次回以降、イベントごとにこの5問を上から順に埋めてください。** 3問目まででだいたい構成が決まります。

### 問1｜開催まで何日あるか

これが最初に効きます。**入札型の広告（Meta / LINEヤフー / Yahoo）は、配信開始から3〜5日を「学習期間」に食われます。** 期間が短いほど、学習期間の比率が上がって効率が落ちます。

| 開催まで | 主力にできるもの | 主力にできないもの |
|---------|----------------|------------------|
| 30日以上 | Meta（本来の設計が使える） | — |
| 14〜30日 | Meta（ただし学習期間を織り込む）／ Peatix掲載 | 新規アカウントが必要な媒体 |
| **7〜14日** | **Peatix掲載・固定枠 ／ ツテ ／ 既存のLINE・メール** | **Meta単独では主力にならない。補助** |
| 7日未満 | ツテ ／ 既存の保有リスト ／ Peatix上位掲載・紹介メール | 入札型広告すべて |

### 問2｜広告予算はいくらか

**3万円未満なら、チャネルを分散させてはいけません。** どれも学習が回らないまま終わります。

| 予算 | 構成 |
|------|------|
| 〜1万円 | **1チャネルに集中**。加えて無料枠（Peatix掲載・オーガニック投稿）を総動員 |
| 1〜3万円 | 主力1つ＋保険1つ。**7:3** で割る |
| 3〜10万円 | 主力1つ＋保険1つ＋リターゲティング。A/Bテストが意味を持ち始める |
| 10万円〜 | 複数チャネルの同時運用が成立する |

> **Metaの学習期間について、正直に書いておきます。**
>
> Metaの広告セットが最適化を終える（学習期間を抜ける）目安は**週50コンバージョン**です。今回の規模（1日500〜1,000円、リード単価700〜1,400円）では**週5件前後**にしかならず、**学習期間は最後まで抜けません**。
>
> これは予算3万円でも同じです。つまりこの規模でのMeta広告は、「最適化された配信」ではなく**「そこそこ狙いを定めたリーチの買い付け」**だと理解してください。過度な期待も、逆に「設定が悪いのでは」という疑いも不要です。

### 問3｜その人は、もう探しているか

| 相手の状態 | 使うチャネル | 特徴 |
|-----------|------------|------|
| **探している** | Peatix、こくちーず、Yahoo!/Google検索広告 | CVRが高い。ただし母数に天井がある |
| **探していない** | Meta（FB/IG）、Instagramオーガニック | 母数は大きい。CVRは低い |
| **すでにこちらを知っている** | LINE公式、メール、リターゲティング | **最も安い。最優先で使う** |

**「すでに知っている人」から順に使い切ってください。** 一番安いのはここです。今回それが使えないのは、LINE公式アカウントに友だちがまだ貯まっていないからにすぎません（5-4）。

### 問4｜成果はどこに溜まるか

| チャネル | 申込者の情報 | 次回への持ち越し |
|---------|------------|----------------|
| LINE公式 / 自社フォーム | **自社に残る** | **そのまま次回の集客に使える** |
| Meta（リード獲得フォーム） | 自社に落とせる（CSVで取得） | カスタムオーディエンスとして資産化できる |
| Peatix | **Peatix側に残る** | 主催者としてフォロワーは付くが、直接連絡の自由度は低い |

**Peatixの弱点はここです。** 申込がPeatix内で完結するので、8/12で確認した「LINEに貯めて次に繋ぐ」という方針には乗りません。緩和策は5-3に書きます。

### 問5｜外したとき、いくら失うか

| 課金の形 | 例 | 初回・不確実なときの適性 |
|---------|---|----------------------|
| **成果報酬**（売れたら払う） | Peatix掲載（4.9%＋99円） | **最優先。ゼロリスク** |
| 少額固定（日割り） | Peatix上位掲載（1日300円〜）、Meta日予算 | 次点。いつでも止められる |
| 大口固定（前払い） | Peatixイベント紹介メール（8,800円〜） | **勝ちパターンが見えるまで使わない** |

**初回は成果報酬 → 少額固定 → 大口固定 の順に開けてください。** 大口固定を先に開けるのは、当たりの分かっていない台に全額入れるのと同じです。

### 4-2. Peatixの費用感を、具体的な金額で

会費7,000円・30名で満席になった場合の比較です。

```
■ Peatixで30名売れた場合
  手数料 = 7,000円 × 4.9% × 30枚 + 99円 × 30枚
        = 10,290円 + 2,970円
        = 13,260円   → 1名あたり 442円

■ Meta広告で30名集めた場合（基準CPA 3,000円）
        = 90,000円   → 1名あたり 3,000円
```

**ただし、この比較はフェアではありません。** Peatixで30名売れるのは「Peatixで探している人が30名いた場合」の話で、その母数があるかは分かりません。**フェアなのは「同じ1名を取るなら、Peatix経由のほうが7分の1で済む」という点だけです。**

だからこそ、**Peatixは"母数の続く限り"使い切って、足りない分をMetaで埋める**という順番になります。逆はありません。

| 問 | 答え | 帰結 |

### 5-2. 予算配分

| チャネル | 内容 | 期間 | 金額 |
|---------|------|------|------|
| Peatix 掲載 | イベントページ公開 | 8/18〜8/31 | **¥0**（売れた分のみ 4.9%＋99円/枚） |
| Peatix 上位掲載 | カテゴリー／関連イベント上位 | 8/20〜8/29（10日） | **約 ¥3,000** |
| **Meta広告** | **女性セット1本のみ**（下記） | 8/20〜8/29（10日） | **¥7,000**（1日700円） |
| | | **合計** | **約 ¥10,000** |

**Metaを1セットに絞る理由。** Meta広告ガイドは男性・女性の2セット構成でしたが、これは総予算3万円が前提です。**1万円を2セットに割ると、どちらも1日350円になり、両方とも配信が細って何も読めなくなります。**

絞るなら女性です。理由はガイド5-3がすでに出しています。

- 男性20名は、**ツテで12〜14名**を担う想定。広告がなくても積み上がる
- 女性10名は、ツテで3〜5名。**残り5〜7名を広告で取るしかない**
- 女性の獲得単価は男性の2〜4倍。**放っておくと最も埋まらないのが女性枠**

**ボトルネックは女性です。薄い予算は、ボトルネックにだけ当てます。**

これはガイドの「女性ファースト」という方針そのままで、予算が3分の1になったぶん、**方針を薄く2箇所に伸ばすのではなく、片方を捨てて濃度を保つ**という判断です。

**男性側の広告はゼロにします。** 男性はツテとPeatixに任せます（Peatixは性別を絞れないので、結果的に男性もここから入ります）。

### 5-3. Peatixを使うことの代償と、その打ち手

**代償を3つ、はっきり書いておきます。**

| 代償 | 中身 | 打ち手 |
|------|------|--------|
| **①導線がLINEに乗らない** | 申込がPeatix内で完結し、LINE友だちが増えない。8/12で確認した「LINEに貯めて恋活・グルメ・経営者向けに繋ぐ」という設計に乗らない | **チケット説明欄と購入後メッセージにLINE友だち追加を必ず入れる。** 「当日の流れと会場詳細をLINEでご案内します」と書けば、実務上の必要としてほぼ全員が登録します |
| **②参加者の質を選べない** | 誰でも買えます。Meta広告ガイド10-1の「広告文で自己選択してもらう」というフィルターが、Peatixでは効きにくい | **イベント説明文を、広告文と同じトンマナで書く。**「静かに」「落ち着いて話せる」「30名ほどの」「20:30には終わります」を入れる。**「ワイワイ」「飲み放題」は書かない**（ガイド10-5） |
| **③男女比を制御できない** | 単一チケットだと、先に売れたほうに偏ります | 下記 |

**③について：Peatixは男女別チケットを作れば比率を確実に守れます。ただし推奨しません。**

Peatixはチケット種別ごとに枚数上限を設定できるため、「男性チケット20枚／女性チケット10枚」とすれば比率は**確実に**守れます。Metaの広告セット分割より強力です。

それでも今回は**単一チケットを推奨**します。**男女別の枚数がイベントページに公開されると、この会が「男女の出会いの場」として読まれるからです。** これはMeta広告ガイド10-5の警告（男女比は書かない／「出会い」ではなく「交流」）と同じ問題で、Peatixのページでも同じことが起きます。

**代わりに、受付側で管理します**（ガイド12-5と同じ運用）。男性が20名に達したら、それ以降のPeatixの在庫を絞る（または販売を一時停止する）ことで対応できます。**女性が不足した場合の最終手段としてのみ、「女性優先枠」を後から追加する**という順序にしてください。
