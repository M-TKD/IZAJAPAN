# Facebookページ 自動配信(fb-autopost)

IZAワイン会のFacebookページに、ワイン会の告知やハンガリーワインのトピックスを
半自動で配信する仕組みです。Google Apps Script(GAS)で動きます。

## 全体の流れ

```
トピックストック(シート)
   │  週1回 generateDrafts (Claude APIで投稿文を自動生成)
   ▼
投稿カレンダー(シート) … ステータス「下書き」
   │  人がレビューして「予約」に変更  ← 品質担保のため必ず人が確認
   ▼
1時間ごと processScheduledPosts
   │  予定時刻を過ぎた「予約」行を Facebook Graph API で投稿
   ▼
Facebookページ … ステータス「投稿済み」+ 投稿IDを記録
```

完全自動(レビューなし)にもできますが、酒類を扱うページのため
生成文は必ず人が確認してから「予約」にする運用を推奨します。

## セットアップ

### 1. スプレッドシート

新規スプレッドシートを作成し、IDを `Code.gs` の `SPREADSHEET_ID` に設定。
シートは初回実行時に自動作成されます。

**投稿カレンダー** シート:

| 投稿日 | 時刻 | カテゴリ | 本文 | 画像URL | リンクURL | ステータス | 投稿ID/エラー | 投稿日時 |
|---|---|---|---|---|---|---|---|---|
| 2026/07/13 | 19:00 | ワイン会告知 | (本文) | | https://... | 予約 | | |

- ステータス: `下書き` → `予約` → `投稿済み` / `エラー`
- 画像URLがあれば写真投稿(/photos)、なければテキスト+リンク投稿(/feed)
- 画像URLは公開されている直リンクである必要があります(Googleドライブの共有リンクは不可。
  一度Facebookにアップした画像やLPの画像URLなどを使う)

**トピックストック** シート(下書き自動生成のネタ帳):

| カテゴリ | トピック/ネタ | 使用済み |
|---|---|---|
| ハンガリーワイン豆知識 | トカイは「王のワイン、ワインの王」 | |
| ワイン会告知 | 7月の初心者向けワイン会(7,000円) | |

### 2. Facebook側の準備

1. [Meta for Developers](https://developers.facebook.com/) でアプリを作成(タイプ: ビジネス)
2. アプリに **pages_manage_posts** / **pages_read_engagement** 権限を追加
3. ページアクセストークンを取得:
   - 簡易: グラフAPIエクスプローラで自分のユーザートークン(上記権限付き)を取得
     → `/me/accounts` でページトークンを取得
   - 推奨: ビジネスマネージャの **システムユーザー** でトークンを発行すると無期限になる
4. 自社ページ専用(アプリの管理者・開発者のみが使う)であれば、アプリを公開申請せず
   開発モードのままで投稿できます
5. `FB_PAGE_ID` と `FB_PAGE_ACCESS_TOKEN` をスクリプト プロパティに登録

### 3. Claude API(下書き自動生成を使う場合)

1. [Claude Console](https://platform.claude.com/) でAPIキーを発行
2. スクリプト プロパティ `ANTHROPIC_API_KEY` に登録
3. モデルは既定で `claude-opus-4-8`(品質重視)。
   コストを抑えたい場合は `Code.gs` の `CLAUDE_MODEL` を `claude-haiku-4-5` に変更
   (1投稿あたりのコストは既定モデルでも数円程度、Haikuなら1円未満の目安)

### 4. トリガー設定

GASエディタの「トリガー」から2本設定:

| 関数 | 種類 | 頻度 |
|---|---|---|
| `processScheduledPosts` | 時間主導型 | 1時間ごと |
| `generateDrafts` | 週主導型 | 毎週月曜 7〜8時 |

### 5. 動作確認

- `testFacebookConnection` を実行 → ログにページ名が出ればFacebook連携OK
- `testGenerateOneDraft` を実行 → ログに投稿文が出ればClaude連携OK
- カレンダーに過去時刻の「予約」行を1件入れて `processScheduledPosts` を手動実行
  → ページに投稿されればフロー全体OK

## 運用メモ

- **投稿頻度の目安**: 週3回(月・水・金 19:00)。generateDrafts が翌週の月水金に自動割り当て
- **カテゴリ例**: ワイン会告知 / ハンガリーワイン豆知識(品種・産地) /
  ペアリングTips / イベントレポート / 参加者の声
- **告知投稿**: 生成文の [日時] [場所] [価格] [申込URL] は担当者が確定情報に置き換えてから予約にする
- **エラー時**: ステータスが「エラー」になり NOTIFY_EMAILS へメール通知。
  トークン期限切れ(Graph API 190エラー)が最も多いので、その場合はトークンを再発行
- **Instagram連携**: 同じGraph APIでInstagramビジネスアカウントにも投稿可能
  (`/{ig-user-id}/media` → `/media_publish` の2段階)。需要があれば拡張する
- **ノーコード代替**: 仕組みを作る前の暫定運用は Meta Business Suite の予約投稿
  (無料・手動)でも代用可能
