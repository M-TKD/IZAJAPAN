# ワイン会 実施前後レポート（Excel）

1開催＝1シートで「実施前の計画」と「実施後の実績」を並べて記録し、全開催をサマリーで一覧するフォーマットです。

- ファイル: `ワイン会レポート.xlsx`（Googleスプレッドシートに変換しても動作）
- 生成スクリプト: `build_report.py`（`pip install openpyxl` → `python3 wine-event-report/build_report.py`）

## シート構成

| シート | 内容 |
|--------|------|
| 使い方 | 記入ルール・自動集計の定義・運用上の注意 |
| サマリー | 開催日・曜日・会場・定員・申込数・参加者（計画/実績、男女、新規/リピーター）・充足率・売上・費用・粗利・広告費・満足度・ステータス。上部に累計KPIカード |
| 20260525_ClassE / 20260831_Beginner | 既存2回分。リポジトリ内資料で確認できた計画値のみ入力済み（実績は空欄） |
| テンプレート | 新しい回はこのシートをコピーして使う |
| 記入例 | 架空データによる書き方の見本（サマリー集計対象外） |

## 各回シートの項目

1. 基本情報 ＋ 実施前チェックリスト（LINE告知3週間前/1週間前/前日 など）
2. 計画 vs 実績（申込・参加・男女・新規/リピーター・キャンセル・充足率・LINE登録・満足度・次回意向・写真同意・1名あたり粗利）
3. 集客チャネル別（知ったきっかけ別の申込/参加/男女）
4. 収支（会費・物販／ワイン仕入・フード・会場・広告・決済手数料など）
5. 広告実績（広告セット別の予算・消化額・リード・CPL・CPA）
6. 提供ワイン（銘柄・産地・タイプ・仕入単価・本数・反応）
7. 当日の流れ
8. 振り返り
9. 参加者リスト（40名分・プルダウン入力）

## 注意

- 参加者リストを記入したファイルは個人情報を含むため、このリポジトリにはコミットしない。閲覧権限を絞ったGoogleドライブで管理する（Instagram運用マニュアル 2章・3-1）。
- 男女別の目標・実績は内部管理用。告知・広告には出さない（同 4-1）。
