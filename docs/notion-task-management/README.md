## 30秒サマリー

- **何を解決する?** 「案件が多すぎてToDoリストでは管理しきれない」「緊急なことばかりに追われ、重要だが緊急でないことができない」状態を、Notion 1か所への棚卸しと週次レビューで脱却する。
- **どう作る?** タスクDB1つを中心に、**6つの事業ラベル**（ワイン輸入・在庫／ワイン会運営／ガジェット／クリニック／M&A／バックオフィス）と **カンバン（未着手・進行中・確認待ち・完了）** で管理。期限・担当・関連書類を1枚のカードに集約し、「誰がボールを持っているか」を可視化する。
- **どう使う?** 週1〜2時間の定例で全タスクを棚卸し → 「緊急×重要」で今週やる第2領域タスクを選ぶ → 「今週やること」ビューで日々消化。
- **段階的に:** まずタスク棚卸し（Phase1）→ 進捗管理と秘書への委任（Phase2）→ 自動化・AI連携（Phase3）。

## 事業ラベル（6分類）

| ラベル | 対象業務 |
|---|---|
| 🍷 ワイン輸入・在庫 | ワイナリー折衝・FedEx集荷申請・インボイス・食品輸入届・通関・出荷・在庫本数管理・発注判断 |
| 🥂 ワイン会運営 | 日程/会場・集客/告知・参加者管理・入金・備品手配・当日運営 |
| 📱 ガジェット | 中国からの仕入れ・Makuake等クラウドファンディング・販売・発送 |
| 🏥 クリニック事業 | クリニック関連事業の各種タスク |
| 🤝 M&A案件 | 案件ソーシング・情報整理・各案件の進行管理 |
| 🏢 バックオフィス | 経理・採用（秘書）・社内整備・その他横断業務 |
