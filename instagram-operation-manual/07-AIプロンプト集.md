# 07. AIプロンプト集（投稿文・画像・動画台本）

ChatGPT / Claude / Gemini などのAIを使って、**運用担当者が迷わず投稿を量産する**ためのプロンプト集です。
`【　】` の部分を差し替えて使ってください。

> **使う前に必ず**：`01`のトンマナ・`02`のデザイン・`03`のシリーズを踏まえて生成します。
> AIの出力は**そのまま使わず必ず人がチェック**（事実確認・トンマナ・法令 → `01`のコンプラ、`08`のチェックリスト）。

---

## 🧩 0. 共通の“前提プロンプト”（最初に貼る土台）

まずこれをAIに読ませてから、各タスクのプロンプトを続けると精度が上がります。

```
あなたはワイン初心者向けのハンガリーワイン会「IZA」のSNS運用担当者です。
以下の前提を必ず守って回答してください。

# ブランド前提
- 事業：ワイン初心者に向けたハンガリーワイン会（東京）
- ターゲット：28〜45歳、ワインに詳しくないが上質な体験・交流を求める層。「詳しくないと浮くのでは」という不安を持つ
- 提供価値：知識より“体験”。「初めてでも安心」「上質だけどやさしい」
- 差別化：フランス/イタリアではなくハンガリーワイン（トカイ貴腐ワイン、フルミント等）

# トーン&マナー
- やさしく対等に（先生ぶらない・マウントしない）
- です・ます調。専門用語は使ったら必ず一言で解説
- 煽り・激安・大量集客の表現は使わない
- 絵文字は控えめに品よく（🍷🇭🇺✨を基調、1投稿2〜4個）
- お酒の投稿として：泥酔/イッキを想起させない、健康効果を断定しない、20歳以上向け
※（トンマナが確定したらここに追記する）

理解したら「OK」とだけ返し、次の指示を待ってください。
```

## ✍️ 1. フィード用キャプション生成

```
上記のブランド前提に沿って、Instagramフィード投稿のキャプションを作ってください。

# この投稿の設計（03の思考テンプレ）
- 柱：【①教育／②世界観／③信頼／④行動 のどれか】
- シリーズ：【例：ワイン初心者ノート】
- テーマ：【例：ワインの「渋味」ってなに?】
- ターゲットの不安/欲求：【例：味の表現が分からず不安】
- ゴール：【保存／フォロー／プロフィール誘導／申込 のどれか】

# 出力してほしいもの
1. 1枚目に載せる「フック」を3案（各15文字前後、続きを読みたくなるもの）
2. キャプション本文（250〜400字、改行で読みやすく、最後にゴールに応じたCTAを1つ）
3. 締めの定型フッター案（アカウントの一言）
4. ハッシュタグ案15個（大・中・小をバランス良く。地域=東京/渋谷も含める）

やさしく、初心者が「わかった!」となる言葉で。専門用語には必ず補足を。
```

## 🖼 2. カルーセル（複数枚）の構成＆各ページ文言

```
上記ブランド前提に沿って、保存されやすい教育カルーセル（全【7】枚）を設計してください。

# テーマ：【例：ワイン初心者が最初に覚える3つのこと】

# 出力
各ページごとに以下を表形式で：
- ページ番号
- 役割（表紙/解説/まとめ/CTA）
- 画像に載せる見出し（短く・大きく1メッセージ）
- 画像に載せる補足文（あれば1〜2行）
- 制作メモ（どんなビジュアルが合うか）

1枚目は3秒で止まるフック、最後は「保存」または「プロフィールから申込」で締めてください。
文字は詰め込みすぎず、1枚1メッセージで。
```

## 🎨 3. 画像生成プロンプト（Gemini / Nano Banana 等）

> 💡 このリポジトリには画像生成ワークフローのスキル（`gemini-image-gen`）があります。noteサムネ/OGP/SNS画像などを量産できます。担当者はそれを使ってもOK。

### 3-1. 投稿用ビジュアル（背景・世界観画像）
```
Instagram post image, 4:5 vertical (1080x1350).
Subject: 【a single glass of Hungarian white wine on a marble table, soft evening light】
Mood: elegant, warm, inviting, premium but approachable — for a wine event for beginners.
Color palette: deep navy background, champagne gold accents, ivory. Avoid neon/pop colors.
Composition: leave clear negative space at the 【top】 for Japanese headline text.
Style: refined lifestyle photography, shallow depth of field, no text, no watermark, no人物の顔.
```
> ⚠️ 生成画像は「文字なし」で作り、**文字はCanva等でブランドフォント（→ `02`）で載せる**と統一感が出ます。

### 3-2. 料理・ペアリング画像
```
Instagram post image, 4:5. A Hungarian wine paired with 【a simple cheese and fruit plate】.
Warm cozy atmosphere, natural light, top-down or 45-degree angle.
Palette: ivory/gold/navy accents. Photorealistic, appetizing, premium, no text, no watermark.
Negative space on 【the bottom third】 for caption text.
```

### 3-3. リール表紙 / サムネ
```
Vertical 9:16 thumbnail for an Instagram Reel about 【how to enjoy a wine event as a beginner】.
Eye-catching, elegant, deep navy + gold. Space at center for a short Japanese hook text.
Photorealistic wine scene, no text, no watermark.
```

> **画像生成の共通コツ**：`no text, no watermark, 顔を大きく写さない` を毎回入れる／`4:5` `9:16` などアスペクト比を指定／ブランド色（navy・gold・ivory）を明記。

## 🎬 4. リール台本（短尺動画）

```
上記ブランド前提に沿って、15〜30秒のInstagramリール台本を作ってください。

# テーマ：【例：ワイン会って実際どんな感じ?（初心者の不安解消）】
# ゴール：【新規リーチ／保存／申込 のどれか】

# 出力（表形式）
- 秒数（0-2秒, 2-5秒…）
- 画面（何を映すか。会場/グラス/注ぐ瞬間 等）
- テロップ（画面に出す短い文字）
- ナレ/補足

冒頭2秒で「お、なにこれ?」と思わせるフックから始めてください。
最後にCTA（フォロー or プロフィールから申込）を入れてください。
おすすめのトレンドに乗りやすい構成（結論先出し・テンポ）で。
```

```

テーマ「【投稿テーマ】」に合うハッシュタグを18個提案してください。

条件：
- 大（10万投稿以上）・中（1万〜）・小/地域（〜1万、東京/渋谷など）を混ぜる
- ワイン初心者・ワイン会・交流イベント系を含める
- ブランドタグ「#IZAワイン会」を必ず1つ含める（※確定タグは後で差し替え）
- 各タグに (大/中/小) の目安ラベルを付けて
```

## 🧠 8. 「ネタ出し」ブレスト

```
ワイン初心者向けハンガリーワイン会のInstagramで、
「保存されやすい教育投稿」のネタを20個、初心者のよくある疑問ベースで出してください。
各ネタに、想定フック（1枚目コピー）を1つ添えて。
専門的すぎず、"知ってると当日ちょっと得する"レベルで。
```

## ⚠️ AI利用の注意（必ず守る）

- **事実確認**：ワインの産地・品種・数値などAIは間違えることがある。**公開前に裏取り**
- **トンマナ**：出力が硬い/砕けすぎたら `0番の前提` を調整して再生成
- **コンプラ**：お酒表現・健康効果・未成年（→ `01`）を必ずチェック
- **丸コピ禁止**：他社そっくりの表現になっていないか確認。ブランドの言葉に直す
- **画像の権利**：生成画像でも、実在ロゴ/人物/商標が紛れ込んでいないか確認
