## ✅ 1. 投稿前チェックリスト（毎回）

**デザイン（→ `02`）**
- [ ] フォントはブランド指定で統一されているか
- [ ] 色はパレット内か（色を足しすぎていないか）
- [ ] ロゴが所定位置に入っているか
- [ ] 文字は端に寄りすぎず、スマホで読めるサイズか
- [ ] 9枚グリッドに並べたとき世界観が崩れないか

**内容（→ `01` `03`）**
- [ ] 4本柱のどれに当たるか明確か
- [ ] 1枚目に「止まる」フックがあるか
- [ ] 専門用語に補足があるか（初心者目線）
- [ ] ゴール（保存/フォロー/誘導/申込）に沿ったCTAがあるか

**文章（→ `07`）**
- [ ] 誤字脱字なし
- [ ] トンマナが合っているか
- [ ] ハッシュタグは10〜20個・大中小のバランス・ブランドタグ入り

**コンプラ（→ `01` `05`）**
- [ ] 泥酔/イッキ/健康断定の表現なし
- [ ] 20歳未満を想起させる表現・未成年の写り込みなし
- [ ] 参加者の写真は掲載許可済み
- [ ] 価格/日程など要確認情報は責任者チェック済み

**導線（→ `06`）**
- [ ] プロフィール/ストーリーのリンクは正しいか（UTM付きか）
