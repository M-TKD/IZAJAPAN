# IZA ワイン会 Instagram 運用マニュアル

ワイン初心者に向けたハンガリーワイン会の集客・ブランディングを目的とした、Instagram 公式アカウントの運用マニュアルです。

このマニュアルの位置づけ：特定の担当者（秘書など）に限定せず、誰が引き継いでも同じ品質で運用できることを目的にしています。以降、運用する人を「運用担当者」と表記します。迷ったら「そのアクションが、集客（参加者を増やす）とブランディング（世界観を守る）に貢献するか」で判断してください。この2つが全ての目的です。

## 1. このアカウントのゴール

1. 集客 … 投稿を見た人を「ワイン会に参加したい」に変える
2. ブランディング … 「ハンガリーワイン × 初心者にやさしい × 上質な体験」の世界観を一貫して届ける
3. 資産化 … 投稿・フォロワー・データを蓄積し、広告出稿でも効く土台をつくる

読む順番の目安：

- 今日から投稿する人 … 3章 → 7章 → 8章 → 11章
- 世界観・デザインを整える人 … 4章 → 5章 → 6章
- 成果を測る／広告を検討する人（COO・責任者） … 9章
- AIで制作を効率化したい人 … 10章

## 2. 運用の絶対ルール

1. 世界観を崩さない … フォント・カラー・トーンは5章のガイドラインに必ず従う
2. 勝手に判断しない領域を決める … 価格・日程・返金・クレーム対応は運用担当者が単独回答せず、必ず責任者に確認（8章）
3. 数値を毎月残す … 感覚ではなくデータで振り返る（9章・11章）
4. アカウント情報を安全に扱う … ID/PW はこのリポジトリに直接書かない（3章）

## 4. ターゲットとコンセプト

「誰に・何を・どんなトーンで届けるか」を定義します。ここがブレると、投稿・デザイン・広告の全てがブレます。運用の憲法にあたる章です。

### 4-1. コンセプト（一言で）

「ワインは初めて。でも、ちょっと背伸びした特別な時間を。」ハンガリーワインという通好みの切り口で、初心者でも気後れしない上質な社交体験を提供するワイン会。

- 提供価値：知識ではなく体験。「詳しくなくても楽しめた」「また来たい」を作る
- 差別化：フランス・イタリアではなくハンガリーワイン（トカイ貴腐ワイン等、物語性が強い）
- トーン：高級すぎず、カジュアルすぎず。「上質だけど、やさしい」

### 4-2. 推奨ターゲット（ペルソナ案）

COO・主催の観点からの推奨案です。実際の参加者データが出たら見直してください。

メインターゲット：「背伸びしたい体験志向層」

- 年齢：28〜45歳
- 属性：都内在勤の会社員／専門職／小規模事業主。可処分所得はそこそこある
- 性別：どちらも歓迎だが、初期は女性〜男女ミックスが集まりやすい設計が有効
- 心理：
  - ワインに興味はあるが「詳しくないから場違いかも」と不安
  - おしゃれで学びのある体験・質の良い出会い／交流を求めている
  - SNS映えより「本物・少人数・丁寧」を好む
- 来ない理由（＝潰すべき不安）：「敷居が高そう」「ぼっちで浮きそう」「マナーが分からない」「高そう」

サブターゲット：

- カップル／友人同士：デート・記念日・女子会の選択肢として
- 経営者・交流志向層：既存の Class-E（経営者交流ワイン会）へのアップセル導線としても機能

ターゲットへの示唆（投稿に落とすとき）：初心者の不安を先回りで潰す投稿が刺さります。

- 「知識ゼロでOK」「一人参加可」「ドレスコードなし／スマートカジュアル」を繰り返し伝える
- 専門用語は使ったら必ず一言で解説する
- 「失敗しない」「恥をかかない」を保証するトーン

### 4-3. ブランドの言葉づかい（Voice & Tone）

| こういうトーンで | こうは言わない |
|---|---|
| やさしく、対等に（先生ぶらない） | 上から目線・マウント |
| 「〜してみませんか」と誘う | 「〜すべき」と押しつける |
| 難しい言葉は噛み砕く | ソムリエ用語の乱用 |
| 少人数・丁寧・本物を強調 | 大量集客・激安・煽り |
| ポジティブ・上品な高揚感 | 不安を過度に煽る売り込み |

### 4-4. トーン&マナー詳細（後で記載・確定用の枠）

現時点で未確定のため、決まり次第ここを埋めてください。全投稿・全AIプロンプトがこの設定を参照します。

| 項目 | 決定内容（後で記載） |
|------|--------------------|
| 一人称 | 例：私たち / IZA |
| 語尾・敬体 | 例：です・ます調で統一 |
| 絵文字の使用 | 例：使わない／控えめに、などの方針 |
| 感嘆符（！）の量 | 例：多用しない |
| 使ってよいハッシュタグの世界観 | 後で記載 |
| NGワード・NG表現 | 例：「酔う」を強調しない、断定的な健康効果 |
| 呼びかけ（参加者の呼称） | 例：皆さま |

### 4-5. コンプライアンス上の注意（お酒の投稿）

- 20歳未満の飲酒を想起させる表現・未成年の登場はNG。「20歳以上」を明記する場面を用意
- 「飲みすぎ・泥酔・イッキ」を促す表現はブランド毀損。避ける
- 健康・医療効果の断定（「体に良い」等）は避ける
- 写真に写る参加者は必ず本人の許可を取ってから掲載（当日の同意フローは8章）

## 5. ブランド・デザインガイドライン

「フィードを見た瞬間に IZA だと分かる」状態を作るための統一ルールです。デザインの一貫性は、素人っぽさを消し、信頼＝集客に直結します。投稿を作る前に必ず参照してください。

基本方針：ここに書かれたルールは推奨の叩き台（既存LPと同じ世界観で揃えた案）です。最終決定は各項目の「後で記載」欄で確定してください。一度決めたら気分で変えないのが鉄則です。

### 5-1. カラーパレット

推奨案（既存LP「Class-E」と統一）：

| 役割 | 色 | HEX | 使い方 |
|------|----|----|--------|
| ベース（背景・濃色） | ディープネイビー | #0A0A0F / #1A1A2E | 背景・引き締め |
| アクセント（主役） | シャンパンゴールド | #C9B890 | 見出し・囲み・ロゴ・上質感の演出 |
| 差し色 | ワインレッド | #CE2939 | ここぞの強調（申込・重要語）※使いすぎ注意 |
| 文字（明色） | オフホワイト | #E8E8E8 / #FFFFFF | 濃背景上の本文 |
| 補助（自然・余白） | アイボリー | #F5F1E6（提案） | 明るい投稿の背景 |

使用ルール：

- 1投稿あたり主役色は1つ＋アクセント1つまで。色を足しすぎない
- ゴールドは「線・囲み・小さな面」で効かせる（ベタ塗りで多用しない＝安っぽくなる）
- ワインレッドは申込・限定・残席など、行動してほしい所だけ

ブランドカラー最終決定（後で記載）：

| 役割 | 確定HEX |
|------|---------|
| ベース | 後で記載 |
| アクセント | 後で記載 |
| 差し色 | 後で記載 |

### 5-2. フォント（統一する）

フォントは絶対に統一。これだけで「プロっぽさ」が段違いになります。既存LPと同じ思想＝明朝で品、ゴシックで可読。

推奨案：

| 用途 | フォント | 理由 |
|------|---------|------|
| 見出し（日本語） | Noto Serif JP（游明朝でも可） | 上質・大人の落ち着き |
| 本文・補足（日本語） | Noto Sans JP（游ゴシック可） | 読みやすい |
| 英字の装飾 | Cinzel | ロゴ的・高級感（ワインラベル風） |

フォントのルール：

- 1枚の画像で使う書体は最大2種類（見出し用＋本文用）
- 極端に細い／太いウェイトを混ぜない。ウェイトは2〜3段階まで
- 手書き風・ポップ体・過度な装飾フォントは使わない（世界観を壊す）

使用フォント最終決定（後で記載）：

| 用途 | 確定フォント |
|------|-------------|
| 見出し | 後で記載 |
| 本文 | 後で記載 |
| 英字 | 後で記載 |

### 5-3. ロゴ・透かしの扱い

- ロゴは class-e-lp/images/iza-logo.png（白抜き版）を基準に使用
- 配置は毎回同じ位置（推奨：右下 or 下中央に小さく）
- ロゴの上に文字を重ねない／勝手に色を変えない／縦横比を崩さない
- 保管場所（3-5）に「Instagram用ロゴ（余白付き・白／金の2版）」を用意しておく

### 5-4. 構図・レイアウトの型（テンプレ化）

毎回ゼロから作らない。下記の型に沿えば誰でも同じ品質になります。

共通ルール：

- サイズ：フィードは 1080×1350px（縦4:5）を基本（フィード占有が大きく有利）
- 余白（マージン）：上下左右に安全マージンを必ず確保（文字を端に寄せない）
- 文字量：1枚に詰め込みすぎない。1枚1メッセージ
- 可読性：濃背景×明文字 or 明背景×濃文字で必ずコントラストを確保

表紙（1枚目）の型 ※止まってもらうための最重要枚：

```
上部：小見出し（カテゴリ or シリーズ名）… ゴールドの細字
中央：大見出し（結論・ベネフィット）… 明朝で大きく
      例）ワイン初心者が最初に覚えるのはこの3つだけ
下部：補足1行 ＋ IZAロゴ
```

2枚目以降（解説）の型：

- 上部：ページ番号 or 見出し（固定位置）
- 中央：要点1つ＋短い説明
- 下部：ロゴ（固定位置）
- 背景・文字位置を全ページで固定するとシリーズ感が出る

ラスト（行動喚起）の型：

- 「保存してね」「次回開催は◯月」「プロフィールから申込」
- 保存・フォロー・プロフィール誘導のどれかを必ず入れる

### 5-5. フィード全体の見え方設計

プロフィールを開いたときの9枚グリッドの印象でフォローされるか決まります。

- 市松（チェッカー）配置：濃い表紙と明るい表紙を交互に並べると整って見える
- または列で世界観を分ける（例：左列＝知識／中列＝ワイン紹介／右列＝当日の雰囲気）
- 投稿前に「今の9枚に並べたらどう見えるか」を確認する

### 5-6. 制作時の「やってはいけない」

- 毎回フォント・色が違う
- 文字が小さすぎる／端ギリギリ（スマホで読めない）
- 無料素材の「いかにも」な写真を多用（世界観が薄まる）
- 情報を1枚に詰め込みすぎる
- 解像度の低い画像・引き伸ばした画像

### 5-7. テンプレート運用（推奨ツール）

- Canva でブランドキット（色・フォント・ロゴ登録）を作り、テンプレを複製して中身だけ差し替える運用が最速
- テンプレは最低これだけ用意：表紙／解説（複数）／ワイン紹介／イベント告知／参加者の声／ストーリー用
- テンプレの保管場所は 3-5 に記載

## 6. コンテンツ設計とシリーズ

「何を投稿すればいいか分からない」を無くすための章です。投稿の型（シリーズ）をあらかじめ決めておけば、運用担当者は中身を差し替えるだけで回せます。

### 6-1. コンテンツの4本柱（投稿は必ずどれかに属する）

集客は「知ってもらう→信じてもらう→行動してもらう」の順で進みます。投稿もこの流れを意識してバランスを取ります。

| 柱 | 目的 | 全体比率の目安 | 例 |
|----|------|--------------|----|
| 教育（初心者知識） | 発見・保存されてリーチを広げる | 40% | ワインの選び方、用語、マナー |
| 世界観（ブランド） | ハンガリーワイン／会場／雰囲気で憧れを作る | 25% | 会場、グラス、産地の物語 |
| 信頼（社会的証明） | 「行っても大丈夫」の不安を消す | 20% | 参加者の声、当日レポ、主催者紹介 |
| 行動（集客CTA） | 申込・問い合わせに直接つなげる | 15% | 次回開催告知、残席、締切 |

迷ったら「教育」を厚めに。保存・シェアされてフォロワー外へ届きやすく、広告なしでも伸びる土台になります。

### 6-2. シリーズ企画（看板コーナーを持つ）

毎回バラバラの投稿ではなく、繰り返す連載を持つとファンが付き、制作も楽になります。各シリーズに固定のデザインテンプレ（5章）とハッシュタグを用意してください。

教育系：

1. 『ワイン初心者ノート』 … 用語・選び方・保存など基礎を1テーマずつ（保存狙いの主力）
2. 『失敗しないワインのマナー』 … 乾杯・グラスの持ち方・注文の仕方など不安解消
3. 『ハンガリーワイン入門』 … トカイ（貴腐ワイン）、フルミント等を初心者向けに

世界観系：

4. 『今夜の一杯』 … 1本のワインを美しい写真＋一言ストーリーで
5. 『会場のいちにち』 … The Place ラウンジ等、当日の空気感
6. 『ペアリングのすすめ』 … このワインにはこの料理、を気軽に

信頼系：

7. 『参加者の声』 … 感想を1枚で（特に「初参加でも安心だった」系）
8. 『ワイン会レポート』 … 開催後の様子ダイジェスト
9. 『主催者／ソムリエ紹介』 … 人柄が見えると申込が増える

行動系：

10. 『次回開催のお知らせ』 … 日程・残席・申込導線を明確に
11. 『よくある質問』 … 一人参加／持ち物／ドレスコード／価格感

運用のコツ：曜日にシリーズを割り当てる（例：月＝初心者ノート／木＝今夜の一杯／日＝告知）。「何を出すか」を毎回考えずに済みます。

### 6-3. 投稿フォーマット別の使い分け

| フォーマット | 得意なこと | このアカウントでの使い道 |
|-------------|-----------|------------------------|
| カルーセル（複数枚） | 保存・じっくり読ませる | 教育系の主力。「ノート」「入門」系 |
| リール（短尺動画） | 新規リーチ・発見 | 会場の雰囲気、注ぐ瞬間、テイスティング、Before/After |
| 単写真 | 世界観・美しさ | 『今夜の一杯』 |
| ストーリーズ | 日常接触・親近感・告知 | 舞台裏、質問箱、カウントダウン、残席速報（8章） |
| ハイライト | 常設の入口 | はじめての方へ／次回開催／参加者の声／FAQ |

リールは新規獲得の要。週1本は入れる。冒頭2秒で「お、なにこれ」と思わせる画（美しい注ぎ・グラスの反射・会場）で始める。

### 6-4. ネタの引き出し（ネタ切れ防止リスト）

ワインの説明（初心者向けにやさしく）：

- ハンガリーワインって何がすごいの？（トカイ＝「王のワイン、ワインの王」）
- 貴腐ワインってなに？なぜ甘い？
- 赤・白・ロゼ・スパークリング・甘口の違いをざっくり
- フルミント／ハールシュレヴェリューなど品種を1つずつ
- ラベルの読み方／産地の場所（地図つき）
- 「渋味」「酸味」「ボディ」って何？を体感ベースで

ワイン会の楽しみ方：

- 一人参加でも楽しめる理由／当日の流れ
- 何を着ていけばいい？（ドレスコードの不安解消）
- 乾杯〜テイスティングの作法（気楽に）
- ワイン会で使える一言フレーズ集
- 交流のきっかけの作り方

Tips（保存されやすい）：

- コンビニ／スーパーで買える「ハズさない」一本
- 開けたワインの保存方法
- グラスがなくても楽しむ方法
- 二日酔いを避ける飲み方（※医療的断定はしない）
- 手土産に喜ばれるワインの選び方

季節・行事フック：

- 季節（新緑・夏の白・秋の熟成・冬の甘口）
- 記念日・デート・女子会・忘年会シーズン
- ハンガリーの祝祭・収穫期の話題

### 6-5. 1投稿を作るときの思考テンプレ

投稿を作る前に、この5つを埋めてから制作に入ると外しません。

```
1. 柱：教育 / 世界観 / 信頼 / 行動 のどれ？
2. シリーズ：どのコーナー？
3. ターゲットの不安/欲求：この投稿はどの不安を消す／欲求を満たす？
4. 1枚目のフック：3秒で止める言葉は？
5. ゴール：保存 / フォロー / プロフィール誘導 / 申込 のどれ？
```

この5項目はそのまま10章「AIプロンプト集」の入力に使えます。

## 7. 投稿カレンダーと運用フロー

「いつ・何を・どうやって投稿するか」のルーティンを定義します。ルーティン化＝属人化を防ぎ、誰が担当しても回る状態を作ります。

### 7-1. 投稿頻度の目安（立ち上げ期）

無理のない継続が最優先。「毎日投稿するが質が落ちる」より「週2〜3でも質を保つ」を選ぶ。

| フォーマット | 頻度の目安 | 補足 |
|-------------|-----------|------|
| フィード（カルーセル／写真） | 週2〜3回 | 教育系を軸に |
| リール | 週1回 | 新規リーチの主力 |
| ストーリーズ | 週3〜5回（できれば毎日） | 短くてOK。接触回数が大事 |
| ハイライト更新 | 随時 | 告知・FAQは常に最新に |

曜日割り当て（推奨テンプレ・調整可）：

| 曜日 | 内容 | シリーズ例 |
|------|------|-----------|
| 月 | 教育 | 『ワイン初心者ノート』 |
| 水 | リール | 会場／テイスティングの雰囲気 |
| 木 | 世界観 | 『今夜の一杯』 |
| 土 or 日 | 信頼／行動 | 『参加者の声』『次回開催のお知らせ』 |
| 毎日 | ストーリーズ | 舞台裏・質問箱・カウントダウン |

投稿時間の目安：

- ターゲットがスマホを見る時間＝平日 12時前後 / 19〜22時、週末 午前〜昼が無難
- 実データ（インサイトの「フォロワーのアクティブ時間」）が出たら、そこに合わせて最適化（9章）

### 7-2. 週次ルーティン（1週間の回し方）

```
[週の初め：企画・制作日（例：月曜にまとめて）]
 1. 今週の投稿テーマを決める（曜日割り当てに沿う）
 2. AIプロンプト集（10章）でキャプション下書きを生成
 3. Canvaテンプレ（5章）で画像を制作 / 画像生成AIを利用
 4. 投稿前チェックリスト（11章）で確認
 5. 予約投稿ツールに1週間分をセット

[毎日：反応対応（1日1〜2回、各10〜15分）]
 6. コメント・DMに返信（8章のテンプレ活用）
 7. ストーリーズを1つ投稿
 8. 関連アカウント／ハッシュタグで「いいね／コメント」回り（8章）

[週の終わり：軽い振り返り]
 9. 今週の数値をメモ（伸びた投稿／伸びなかった投稿）
```

「制作はまとめて／反応は毎日」が鉄則。制作を毎日やろうとすると続きません。

### 7-3. 月次ルーティン

```
[月初]
 - 今月のテーマ・キャンペーン・告知を決める（イベント日程と連動）
 - 月間カレンダーを作成（下の雛形）

[月中]
 - 週次ルーティンを回す
 - 開催前は告知・カウントダウンを強化

[月末]
 - KPIレポート作成（9章 / 11章 の雛形）
 - 上位／下位投稿を分析 → 翌月の方針に反映
 - 責任者・COOに共有
```

月間カレンダー雛形（スプレッドシート推奨）：

| 日付 | 曜日 | フォーマット | 柱 | シリーズ/テーマ | 1枚目コピー | 制作状況 | 予約済 | 実績（保存/リーチ） |
|------|------|-------------|----|--------------|-----------|---------|-------|-----------------|
| 例 5/4 | 月 | カルーセル | 教育 | 初心者ノート#3 | 「渋味って何?」 | 完成 | 済 | — |

### 7-4. 投稿の実作業手順（フィード投稿）

1. 下書き準備：キャプション（10章）＋画像（5章）＋ハッシュタグを用意
2. チェック：投稿前チェックリスト（11章）を通す
3. 投稿 / 予約：
   - 手動：Instagramアプリ →「＋」→ 画像選択 → キャプション貼り付け → シェア
   - 予約：Meta Business Suite（無料）or 予約ツールで日時指定
4. 投稿後：
   - 誤字・リンク・タグの表示を確認
   - 最初の30〜60分はコメントに素早く反応（初速がリーチを伸ばす）
   - ストーリーズで「新しい投稿しました」とリポスト

キャプションの基本構造：

```
[フック1行：続きを読みたくなる問いや結論]
 例）ワイン、何を頼めばいいか分からない…そんな時はコレ。

[本文：やさしく解説。改行で読みやすく]

[CTA：保存・フォロー・プロフィール誘導のどれか]
 例）迷ったとき用に保存してね／次回のワイン会はプロフィールから

[定型フッター：アカウントの一言＋ハッシュタグ]
```

### 7-5. ハッシュタグ運用

- 1投稿あたり 10〜20個を目安（多ければ良いわけではない）
- 大・中・小を混ぜる：
  - 大（10万〜）：#ワイン #ワイン好きと繋がりたい
  - 中（1万〜）：#ハンガリーワイン #ワイン会 #ワイン初心者
  - 小（〜1万）：#東京ワイン会 #渋谷ワイン など地域・ニッチ
- ブランドタグを固定で1つ（例：#IZAワイン会 ※後で確定）→ UGC（参加者の投稿）を集約
- タグのセットを2〜3種類作って使い回し＆定期見直し
- 実際のタグ確定リストは11章のテンプレに保存

同じタグの完全コピペを毎回使うと露出が落ちる説あり。セットを複数用意して回すのが無難。

## 8. エンゲージメント運用（コメント・DM・ストーリー）

投稿は「出して終わり」ではありません。反応への対応こそがフォロワーとの関係＝申込率を左右します。この章は運用担当者が毎日使う実務テンプレです。

### 8-1. まず最初に：運用担当者が単独で判断しない領域

以下は必ず責任者に確認してから回答します（勝手に答えない）。誰が担当でも安全に運用するための線引きです。

- 価格・割引・返金・キャンセルポリシー
- 開催日程・定員・残席の最終確定情報
- クレーム・トラブル・体調／アルコールに関する相談
- 提携・取材・コラボ・広告の依頼
- 個人情報の取り扱いに関わること

定型で返してよい範囲は下記テンプレの通り。それ以外は「確認してご連絡します」で一旦受ける。

### 8-2. コメント対応

- 基本、全コメントに返信（初期はこれが効く）。返信は速いほど良い
- 絵文字1つだけの返信で終わらせず、一言添えると会話が続く
- 質問コメントは丁寧に答える＋「DMでも受付中です」へ誘導
- ネガティブ／批判：感情的に反応しない。事実確認が必要なものは責任者へエスカレーション

返信テンプレ例：

| シーン | 返信例 |
|--------|--------|
| 褒めコメント | 「ありがとうございます。そう言っていただけて嬉しいです」 |
| 「参加してみたい」 | 「ぜひ。次回の開催はプロフィールのリンクから見られます。ご不明点はお気軽にDMを」 |
| 「一人でも大丈夫?」 | 「もちろんです。お一人参加の方がとても多いので、ご安心を」 |
| 質問（答えられる範囲） | 「良いご質問です。◯◯です。詳しくは近日投稿しますね」 |
| 価格／日程など要確認 | 「お問い合わせありがとうございます。確認してDMにてご案内します」 |

### 8-3. DM対応

DMは見込み客との1対1。ここで申込が決まります。丁寧かつスピーディに。

対応の基本：

- 初回反応はできるだけ早く（数時間以内が理想）
- テンプレをベースにしつつ、相手の言葉に合わせて一言パーソナライズ
- ゴールは「次のアクション（申込ページ／日程案内／質問解消）」を必ず提示

DMテンプレ例（後でトンマナに合わせて調整、4章）：

初回問い合わせへの返信：

```
はじめまして、IZAワイン会です。
ご連絡ありがとうございます。

◯◯についてですね。
（回答）

次回の開催は【◯月◯日】を予定しています。
ご興味があれば、こちらから詳細・お申込みいただけます。
（リンク）

その他ご不明な点があれば、なんでもお気軽にどうぞ。
```

「初めてで不安」への返信：

```
ご不安な点、とてもよく分かります。
参加者の多くがワイン初心者・お一人参加なので、
「詳しくないと浮くのでは…」という心配はいりません。

当日はスタッフが丁寧にご案内しますので、
手ぶらの気持ちでお越しくださいね。
```

よく来る質問はテンプレ化して11章に蓄積。担当が変わっても同じ品質で返せます。

### 8-4. ストーリーズ活用（毎日の接触）

ストーリーズは「更新している感」と親近感を出す最重要ツール。完璧でなくてOK、頻度が命。

ネタリスト：

- 舞台裏（ワインの仕入れ、会場準備、当日の朝）
- 質問箱スタンプ「ワインの疑問、答えます」→ 集まった質問を投稿ネタに
- アンケートスタンプ「赤 vs 白、どっち派?」（参加ハードルが低い）
- カウントダウンスタンプ（開催まであと◯日）
- 新規フィード投稿のリポスト（見逃し防止）
- 参加者の声・当日の様子（掲載許可を取ってから）
- 「残席わずか」などの行動喚起

ストーリーズ活用のコツ：

- リンクスタンプで申込ページへ直接誘導（プロアカウントで利用可）
- スタンプ（質問・アンケート・クイズ）を毎回1つ入れると反応率が上がる
- 反応（返信・スタンプ）にはできるだけリアクションを返す

### 8-5. 能動的アプローチ（待ちの運用にしない）

フォロワーが少ない立ち上げ期は、こちらから見つけてもらいに行く動きが必要です。

- 関連ハッシュタグ（#ワイン好きと繋がりたい #東京グルメ 等）の投稿に丁寧にいいね／コメント
- ワイン・グルメ・お出かけ系アカウントと自然な交流
- 参加者が投稿してくれたらリポスト＆お礼（UGCを育てる）
- スパム的な大量フォロー／コメントはNG（ブランド毀損・アカウント制限リスク）

やってはいけない：

- 自動化ツールでの大量いいね／フォロー／DM（規約違反・凍結リスク）
- 無関係なアカウントへの営業DMの一斉送信
- フォロー＆アンフォローの繰り返し

### 8-6. 参加者の写真・声の掲載フロー（重要）

1. 当日または事前に掲載許可を得る（口頭＋できれば書面／フォームで記録）
2. 顔出しNGの人が写り込んでいないか確認
3. 掲載時はネガティブに使わない・加工で誤解を生まない
4. 「掲載をやめてほしい」と言われたら速やかに削除

## 9. KPIと分析・広告出稿

「頑張った／頑張ってない」ではなく数字で運用するための章です。運用担当者は数値の記録・報告を、COO／責任者は意思決定を担います。

### 9-1. KPIの全体像（3階層で考える）

集客は「見られる → 反応される → 申し込まれる」の階層で進みます。上から順に改善します。

| 階層 | 指標（KPI） | 何を意味するか | 主な打ち手 |
|------|-----------|--------------|-----------|
| 認知 | フォロワー数 / リーチ / プロフィールアクセス | どれだけの人に届いたか | リール・教育投稿・広告 |
| 関心 | エンゲージメント（保存・いいね・コメント・シェア） | どれだけ刺さったか | コンテンツの質・フック |
| 行動 | 参加者数（集客）/ 申込数 / リンククリック / DM数 | どれだけ商売に繋がったか | CTA・導線・オファー |

最重要は参加者数（集客）。フォロワーが増えても参加者が増えなければ意味がありません。ただし行動を増やすには認知・関心が土台になります。

### 9-2. 各KPIの定義と目標（目標値は後で確定）

| KPI | 定義 | 見る場所 | 月次目標（後で記載） |
|-----|------|---------|-------------------|
| フォロワー数 | 純増数 | プロフィール／インサイト | 後で記載 |
| リーチ | 投稿を見たユニーク数 | インサイト | 後で記載 |
| プロフィールアクセス | プロフ閲覧数 | インサイト | 後で記載 |
| エンゲージメント率 | (いいね+保存+コメント+シェア)÷リーチ | 手計算／ツール | 後で記載 |
| 保存数 | 保存されたか | 各投稿インサイト | 教育投稿の主KPI |
| リンククリック | プロフ／ストーリーのリンク | インサイト／UTM | 後で記載 |
| DM問い合わせ数 | 申込関連DM件数 | 手動カウント | 後で記載 |
| 申込・参加者数 | 実際の申込／来場 | LP／フォーム／受付 | 後で記載（最重要） |

保存は初心者向け教育アカウントの生命線。「あとで読み返したい」＝価値がある証拠で、発見面での露出も伸びます。

### 9-3. 「Instagram → 申込」の導線をどう測るか

申込のゴールをどこに置くかを先に決めます（後で確定、12章の未確定リスト）。

- 候補：LP（class-e-lp）のフォーム / 専用申込フォーム / LINE公式 / リンク集ツール
- どれにするにせよ、計測できる状態にする

UTMパラメータで流入を可視化（推奨）：プロフィール／ストーリーのリンクに印を付けて、GA4で「Instagram経由の申込」を測ります。

```
https://m-tkd.github.io/IZAJAPAN/class-e-lp/?utm_source=instagram&utm_medium=social&utm_campaign=profile_link
```

- utm_source=instagram … 流入元
- utm_medium=social … 種別
- utm_campaign=... … 施策名（profile_link / story_0525 / reel_tokaji 等）

LP側には既に GA4測定ID と Meta Pixel の差し込み枠があります（class-e-lp/index.html の [GA4_MEASUREMENT_ID] [META_PIXEL_ID]）。ここを設定すると、広告の効果測定まで一気通貫でつながります。

### 9-4. 分析ルーティン（何を・いつ見るか）

| タイミング | 見るもの | アクション |
|-----------|---------|-----------|
| 投稿翌日 | その投稿の保存／リーチ／シェア | 伸びた型をメモ |
| 毎週 | 上位・下位投稿、フォロワー増減 | 来週の内容に反映 |
| 毎月 | 全KPI、導線（申込数）、アクティブ時間 | レポート作成→COOへ（11章雛形） |

「伸びる型」を見つける方法：

- 保存が多い投稿 → 教育テーマとして横展開（続編・関連を作る）
- リーチが多いリール → フォーマットを真似て量産
- プロフィールアクセス→リンククリックが低い → プロフィール文／導線を改善

### 9-5. 広告出稿（COO向け・立ち上げの考え方）

オーガニック（無料投稿）で勝ちパターンが見えてから広告を足すのが最も費用対効果が高いです。実行判断・予算はCOO／責任者。運用担当者は入稿と数値管理を担当。

ステップ：

1. 土台を作る：プロアカウント＋Facebookページ連携＋Meta PixelをLPに設置（既存枠を有効化）
2. 勝ち投稿を広告化：反応の良かった投稿を「投稿を宣伝」で少額からテスト（例：1日数百〜千円）
3. 本命キャンペーン：Meta広告マネージャで目的別に配信
   - 認知／リーチ目的：新規フォロワー・ブランド認知
   - トラフィック／リード目的：LP誘導・申込（＝集客に直結、まずここ）
4. ターゲティング案（ペルソナ4-2と連動）
   - 地域：会場周辺（例：東京都／渋谷から一定範囲）
   - 年齢：28〜45
   - 興味関心：ワイン、レストラン、習い事、デート／交流イベント 等
