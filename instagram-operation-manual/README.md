# IZA ワイン会 Instagram 運用マニュアル

ワイン初心者に向けた **ハンガリーワイン会** の集客・ブランディングを目的とした、Instagram 公式アカウントの運用マニュアルです。

> **このマニュアルの位置づけ**
> 特定の担当者（秘書など）に限定せず、**誰が引き継いでも同じ品質で運用できる**ことを目的にしています。以降、運用する人を「**運用担当者**」と表記します。
> 迷ったら「そのアクションが *集客（参加者を増やす）* と *ブランディング（世界観を守る）* に貢献するか？」で判断してください。この2つが全ての目的です。

---

## 🎯 このアカウントのゴール（3行サマリー）

1. **集客** — 投稿を見た人を「ワイン会に参加したい」に変える
2. **ブランディング** — 「ハンガリーワイン × 初心者にやさしい × 上質な体験」の世界観を一貫して届ける
3. **資産化** — 投稿・フォロワー・データを蓄積し、広告出稿でも効く土台をつくる

## 🚦 まず読む順番

- **今日から投稿する人** → `00` → `04` → `05` → `08`
- **世界観・デザインを整える人** → `01` → `02` → `03`
- **成果を測る／広告を検討する人（COO・責任者）** → `06`
- **AIで制作を効率化したい人** → `07`

---

## ⚠️ 運用の絶対ルール（最初に合意しておくこと）

1. **世界観を崩さない** — フォント・カラー・トーンは `02` のガイドラインに必ず従う
2. **勝手に判断しない領域を決める** — 価格・日程・返金・クレーム対応は運用担当者が単独回答せず、必ず責任者に確認（→ `05`）
3. **数値を毎月残す** — 感覚ではなくデータで振り返る（→ `06` `08`）
4. **アカウント情報を安全に扱う** — ID/PW はこのリポジトリに直接書かない（→ `00`）
