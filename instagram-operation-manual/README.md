## 1. このアカウントのゴール

1. 集客（最優先） … 投稿を見た人を「ワイン会に参加したい」に変える。最重要KPIは参加者数（9章）
2. ブランディング … 「ハンガリーワイン × 初心者にやさしい × 上質な体験」の世界観を一貫して届ける
3. 資産化 … 投稿・フォロワー・データを蓄積し、広告出稿でも効く土台をつくる

優先順位：迷ったら集客（参加者数）を優先する。ただし世界観を壊してまで集客に走らない（激安訴求・煽り・大量フォローなどはブランディングを毀損し、長期的に集客も落とす）。

そしてこの3つの先に、事業としての最終目的があります。

**ハンガリーワインを気軽に飲む風習を、日本につくること。**（詳細は4-1）

ワイン会の集客は、そのための手段です。この視点があると「なぜワイン会の告知以外も投稿するのか」が腑に落ちます。会に来られない人にハンガリーワインを1本買ってもらうことにも、事業上の価値があるからです。

### 1-1. 運用体制（役割分担）

| 役割 | 担当 | 主な業務 |
|------|------|---------|
| 責任者（企画・最終判断） | 高橋 | コンテンツ企画・テーマ決定、価格/日程等の最終確認、KPIレビュー、広告判断 |
| 運用担当者（制作・投稿） | 秘書 | 写真撮影・画像制作、投稿・予約投稿、コメント/DMの一次対応、数値の記録 |

- 本マニュアルの「責任者」＝高橋、「運用担当者」＝秘書と読み替える
- 運用担当者が単独で判断しない領域は8章の通り（価格・日程・返金・クレーム等）

読む順番の目安：

- 今日から投稿する人（秘書） … 3章 → 7章 → 8章 → 11章
- 世界観・デザインを整える人 … 4章 → 5章 → 6章
- 成果を測る／広告を検討する人（高橋） … 9章
- AIで制作を効率化したい人 … 10章

## 2. 運用の絶対ルール

1. 世界観を崩さない … フォント・カラー・トーンは5章のガイドラインに必ず従う
2. 勝手に判断しない領域を守る … 価格・日程・返金・クレーム対応は運用担当者（秘書）が単独回答せず、必ず責任者（高橋）に確認（8-1）
   - ※「7,000円前後」「六本木一丁目」「月1回開催」までは秘書が回答してよい
3. 投稿前チェックリストを必ず通す … 公開前に11章のチェックリスト（デザイン・内容・コンプラ・導線）を確認する
4. 反応してくれた人は必ずLINEに渡す … 申込のゴールはLINE公式。Instagram上で完結させない（9-3）
5. 数値を毎月残す … 感覚ではなくデータで振り返る（9章・11章）
6. アカウント情報を安全に扱う … ID/PW はこのマニュアルや共有ドキュメントに直接書かず、保管場所へのリンクだけ残す（3章）

## 4. ターゲットとコンセプト

「誰に・何を・どんなトーンで届けるか」を定義します。ここがブレると、投稿・デザイン・広告の全てがブレます。運用の憲法にあたる章です。

### 4-1. コンセプト（一言で）

**「ハンガリーワインを、あなたの普段の一本に。」**

知られざるハンガリーワインを、初心者でも気後れせず楽しめる形で届け、日常的に飲まれる習慣をつくるワイン会。

**この事業が本当に目指していること：**

単発のイベント集客ではなく、**ハンガリーワインを気軽に飲む風習を日本につくること**が最終的な目的です。

「ワインをカジュアルに」だけでは足りません。それはすでに他の輸入元や小売がやっていることで、私たちがやる意味がないからです。私たちが根付かせたいのは「ハンガリーワインという選択肢」そのものです。

**なぜこの区別が重要か：**

日本でワインといえばフランス・イタリア・チリが定番で、ハンガリーワインは「知らない」「見たことがない」というのが実情です。つまり障壁が二重にあります。

1. ワイン自体への心理的ハードル（「詳しくないと恥をかく」「特別な日のもの」）
2. ハンガリーワインの認知ゼロ（そもそも選択肢に入っていない）

この2つを同時に外すのがこのアカウントの仕事です。1つ目だけを外しても、その人はフランスワインを買います。

**投稿の作り方への落とし込み：**

- ワイン会の告知だけを繰り返すアカウントにしない。日常の中でハンガリーワインを楽しむ提案を発信の軸に置く
- 「平日の夜に、トカイを一杯」「この料理にはケークフランコシュ」といった、具体的な銘柄・品種を伴う日常のシーンを描く。「ワインを飲もう」という一般論では意味がない
- 買える場所・買い方を繰り返し伝える。気に入っても手に入らなければ習慣にはなりません。ここは他のワインアカウントと決定的に違う、私たちが必ずやるべきこと
- 会に来られない人にも価値がある発信をする。結果として、その人たちがいつか参加者になり、周囲に薦めてくれる
- ワイン会は「入口」であって「ゴール」ではない。会で気に入った1本を、家でも開けてもらうところまでが提供価値

つまり、「特別な体験」と「日常への定着」の両方を同時に届けるのがこのアカウントの役割です。会そのものは背伸びした特別な時間、しかしそこで伝えるのは「ハンガリーワインって、実はもっと気軽でいい」というメッセージ、という組み立てです。

**判断に迷ったときの基準：** その投稿は「ハンガリーワインを1本買ってみよう」と思わせるか？　単に「ワインっていいな」で終わる投稿は、私たちが出す意味が薄いと考えてください。

**イベントの基本スペック（投稿の前提。全担当者が把握しておく）：**

| 項目 | 内容 |
|------|------|
| 開催地 | 東京・六本木一丁目駅近くのシェアラウンジ「経営者の部室」 |
| 開催頻度 | 現状は月1回（会場の予約枠のため）。今後は開催回数を増やしていく予定 |
| 会費 | 7,000円前後（※確定金額・変更は責任者に確認。8-1） |
| 対象 | ワイン初心者。お一人参加歓迎・20歳以上 |
| 定員 | 30名前後 |

**開催回数を増やす前提で運用する：** 告知投稿のテンプレートやハイライトは「毎月◯日開催」と固定せず、回数が増えても作り直さなくて済む書き方にしておいてください（例：「次回の開催はプロフィールのリンクから」）。頻度が上がったときにLINE配信の間隔も見直します（9-3）。

**「7,000円前後」という価格帯が投稿トーンを決めます。** 高級ワイン会（1〜2万円）ではなく、「ちょっといい体験」として月1回通える価格。過度に高級を演出すると価格とのギャップで敬遠され、逆に安さを前面に出すと世界観が崩れます。「この価格でこの体験ができるのか」と感じてもらうのが目標です。

**旧コンセプト「ワインは初めて。でも、ちょっと背伸びした特別な時間を。」との関係：** この言葉はワイン会そのものを説明するコピーとして引き続き有効です。会は特別な体験であってよい。ただしアカウント全体の使命はその先にあり、「特別な時間」で終わらせず、ハンガリーワインを日常に持ち帰ってもらうところまでを担います。

- 提供価値：知識ではなく体験。「詳しくなくても楽しめた」「また来たい」を作る
- 差別化：フランス・イタリアではなくハンガリーワイン（トカイ貴腐ワイン等、物語性が強い）
- トーン：高級すぎず、カジュアルすぎず。「上質だけど、やさしい」
- 長期的なゴール：ハンガリーワインを「知らないもの」から「普段の一本」に変えること
- 親しみやすい入口テーマ：「通好み」に寄せすぎず、初心者が手に取りやすいテーマも積極的に扱う
  - 貴腐ワイン（トカイ）… 「世界三大貴腐ワイン」「デザートのように甘い」という分かりやすい魅力
  - マスカット系品種 … 「マスカットの香り」など、日本人に馴染みのある言葉で語れる飲みやすいワイン
  - 「甘口から入ってOK」を公式に肯定し、入口のハードルを下げる

### 4-2. 推奨ターゲット（ペルソナ案）

主催の観点からの推奨案です。実際の参加者データが出たら見直してください。

メインターゲット：「背伸びしたい体験志向層」

- 年齢：28〜45歳
- 属性：都内在勤の会社員／専門職／小規模事業主。可処分所得はそこそこある
- 性別：どちらも歓迎だが、初期は女性〜男女ミックスが集まりやすい設計が有効
- 心理：
  - ワインに興味はあるが「詳しくないから場違いかも」と不安
  - おしゃれで学びのある体験・質の良い交流を求めている
  - SNS映えより「本物・少人数・丁寧」を好む
- 地域：六本木一丁目が会場のため、都心部（港区・千代田区・渋谷区）勤務・在住者が中心。広告の地域設定もここを起点にする（9-5）
- 来ない理由（＝潰すべき不安）：「敷居が高そう」「ぼっちで浮きそう」「マナーが分からない」「高そう」
  - ※「高そう」への回答は会費7,000円前後を早い段階で明示すること。価格を隠すと敷居が高い印象を強めてしまいます

サブターゲット：

- カップル／友人同士：デート・記念日・女子会の選択肢として
- 経営者・交流志向層：既存の Class-E（経営者交流ワイン会）へのアップセル導線としても機能

ターゲットへの示唆（投稿に落とすとき）：初心者の不安を先回りで潰す投稿が刺さります。

- 「知識ゼロでOK」「一人参加可」「ドレスコードなし／スマートカジュアル」を繰り返し伝える
- 専門用語は使ったら必ず一言で解説する
- 「失敗しない」「恥をかかない」を保証するトーン

### 4-3. ブランドの言葉づかい（Voice & Tone）

| こういうトーンで | こうは言わない |
|---|---|
| やさしく、対等に（先生ぶらない） | 上から目線・マウント |
| 「〜してみませんか」と誘う | 「〜すべき」と押しつける |
| 難しい言葉は噛み砕く | ソムリエ用語の乱用 |
| 少人数・丁寧・本物を強調 | 大量集客・激安・煽り |
| ポジティブ・上品な高揚感 | 不安を過度に煽る売り込み |

### 4-4. トーン&マナー詳細（確定）

全投稿・全AIプロンプトがこの設定を参照します。

| 項目 | 決定内容 |
|------|---------|
| 一人称 | 私たち |
| 語尾・敬体 | です・ます調で統一 |
| 絵文字の使用 | 控えめに使う：1投稿2〜3個まで。ワイングラス・葡萄など世界観に合うもののみ。連打・顔文字の多用はしない |
| 感嘆符（！）の量 | 多用しない：1投稿1〜2個まで。「！！」の連続は使わない |

| NGワード・NG表現 | 「酔う・酔える」を売りにしない／断定的な健康効果／「激安・爆安・タダ」／「出会い」を前面に出す表現（「交流」と言い換える） |
| 呼びかけ（参加者の呼称） | 皆さま（DMなど1対1では「◯◯さま」） |

### 4-5. コンプライアンス上の注意（お酒の投稿）

- 20歳未満の飲酒を想起させる表現・未成年の登場はNG。「20歳以上」を明記する場面を用意
- 「飲みすぎ・泥酔・イッキ」を促す表現はブランド毀損。避ける
- 健康・医療効果の断定（「体に良い」等）は避ける
- 写真に写る参加者は必ず本人の許可を取ってから掲載（当日の同意フローは8章）

## 5. ブランド・デザインガイドライン

「フィードを見た瞬間に IZA だと分かる」状態を作るための統一ルールです。デザインの一貫性は、素人っぽさを消し、信頼＝集客に直結します。投稿を作る前に必ず参照してください。

基本方針：カラー（5-1）とフォント（5-2）は確定済みです。一度決めたら気分で変えないのが鉄則。制作前に必ずここを開いてから始めてください。

Instagramの投稿テンプレート（Canva）：https://canva.link/iza-wine

適用例：[sample-post.html](./sample-post.html) ／ [samples/](./samples/)（カルーセル5枚の実例）

### 5-1. カラーパレット（確定）

コンセプト：ハンガリー国旗の赤・白・緑と、トカイ貴腐ワインの琥珀色を土台にする。「赤 × 白」でワインそのものも連想させる。

| 役割 | 色 | HEX | 使い方 |
|------|----|----|--------|
| ベース（濃色背景） | ボルドー | `#5A1425` | 濃色投稿の背景。フィードの主役 |
| ベース（明色背景） | ウォームホワイト | `#FAF6F2` | 明色投稿の背景。赤と交互に並べる |
| アクセント（主役） | 貴腐ゴールド（トカイ） | `#D4A24E` | 見出し・囲み線・ロゴ・上質感の演出 |
| 差し色（CTA） | 国旗レッド | `#CD2A3E` | 申込・締切・残席など行動してほしい所だけ（明色背景で使用） |
| 補助 | 国旗グリーン | `#436F4D` | 「受付中」バッジ、ハンガリー紹介系のワンポイントのみ（少量） |
| 文字（濃色背景上） | ウォームホワイト | `#FAF6F2` | 本文 |
| 文字（明色背景上） | ダークブラウン | `#2A1418` | 本文（真っ黒は使わない） |

使用ルール：

- 1投稿あたり「背景1色 + アクセント1色」まで。色を足しすぎない
- ゴールドは「線・囲み・小さな面」で効かせる（ベタ塗りで多用しない＝安っぽくなる）
- 国旗レッド `#CD2A3E` は明色背景の上でのみ使う。ボルドー背景の上に置くと沈んで見えない
- 緑は1投稿につき1箇所まで。使いすぎるとクリスマス配色になる
- 濃色背景上のCTAは、ゴールドの塗り＋ボルドーの文字で作る（例：金地に「次回開催のご案内」）

フィードの並べ方：ボルドー背景と白背景を市松に交互配置すると、9枚グリッドが整って見える（5-5参照）。

Canvaの「ブランドキット」にこの5色を登録してから制作を始めてください（5-7）。

### 5-2. フォント（確定）

フォントは絶対に統一。これだけで「プロっぽさ」が段違いになります。既存LPと同じ思想＝明朝で品、ゴシックで可読。

| 用途 | 確定フォント | 理由 |
|------|-------------|------|
| 見出し（日本語） | Noto Serif JP | 上質・大人の落ち着き |
| 本文・補足（日本語） | Noto Sans JP | 読みやすい |
| 英字の装飾 | Cinzel | ロゴ的・高級感（ワインラベル風） |

フォントのルール：

- 1枚の画像で使う書体は最大2種類（見出し用＋本文用）
- 極端に細い／太いウェイトを混ぜない。ウェイトは2〜3段階まで
- 手書き風・ポップ体・過度な装飾フォントは使わない（世界観を壊す）

3書体ともCanvaで無料で使えます。ブランドキットに登録しておくと、テンプレ複製時に自動で適用されます。

### 5-3. ロゴ（制作済み）

ワイン会専用ロゴ「IZA WINE CLUB」を制作しました。ワインラベル風の文字ロゴで、上下の細い罫線で挟む構成です。書体は Didot（高コントラストの明朝系欧文）を使用しています。

保管場所：SNS運用/ロゴ/（SVG・PNGの両方）。Googleドライブにも同じものを置いてください（3-5）

8つの版があります。用途で選んでください。

| ファイル | 形 | 用途 |
|---------|----|------|
| 01_横組_ゴールド_透過 | 横長 | ボルドー背景の投稿に重ねる（最も使う） |
| 02_横組_ボルドー_透過 | 横長 | ウォームホワイト背景の投稿に重ねる |
| 03_横組_白_透過 | 横長 | 写真の上に重ねる（背景が暗い場合） |
| 04_横組_ゴールド_ボルドー背景 | 横長 | 単体で使う場合。名刺・資料の隅など |
| 05_横組_ボルドー_白背景 | 横長 | 同上（明るい面） |
| 06_正方形_ゴールド_ボルドー背景 | 正方形 | Instagramのプロフィール画像（推奨） |
| 07_正方形_ボルドー_白背景 | 正方形 | プロフィール画像の明るい版 |
| 08_正方形_ゴールド_透過 | 正方形 | 任意の背景に重ねる |

正方形版には HUNGARIAN WINE と TOKYO を入れてあります。プロフィール画像は小さく表示されるので、何のアカウントかが一目で伝わるようにするためです。

使うときのルール：

- 投稿への配置は毎回同じ位置（推奨：下中央に小さく）
- ロゴの上に文字を重ねない／勝手に色を変えない／縦横比を崩さない
- 背景に対してコントラストが取れる版を選ぶ（暗い背景にボルドー版は使わない）
- 拡大・縮小はSVGを使うと画質が劣化しません。Canvaに取り込むならSVGを推奨

編集したい場合：SVGファイルをCanvaやIllustratorで開けば、文字や罫線を調整できます。書体をブランド指定の Cinzel（5-2）に差し替えることも可能です。ただし一度確定したら変更しないのが鉄則です（5章の基本方針）。

### 5-4. 構図・レイアウトの型（テンプレ化）

毎回ゼロから作らない。下記の型に沿えば誰でも同じ品質になります。

共通ルール：

- サイズ：フィードは 1080×1350px（縦4:5）を基本（フィード占有が大きく有利）
- 余白（マージン）：上下左右に安全マージンを必ず確保（文字を端に寄せない）
- 文字量：1枚に詰め込みすぎない。1枚1メッセージ
- 可読性：濃背景×明文字 or 明背景×濃文字で必ずコントラストを確保

表紙（1枚目）の型 ※止まってもらうための最重要枚：

```
上部：小見出し（カテゴリ or シリーズ名）… ゴールドの細字
中央：大見出し（結論・ベネフィット）… 明朝で大きく
      例）ワイン初心者が最初に覚えるのはこの3つだけ
下部：補足1行 ＋ IZAロゴ
```

2枚目以降（解説）の型：

- 上部：ページ番号 or 見出し（固定位置）
- 中央：要点1つ＋短い説明
- 下部：ロゴ（固定位置）
- 背景・文字位置を全ページで固定するとシリーズ感が出る

ラスト（行動喚起）の型：

- 「保存してね」「次回開催は◯月」「プロフィールから申込」
- 保存・フォロー・プロフィール誘導のどれかを必ず入れる

### 5-5. フィード全体の見え方設計

プロフィールを開いたときの9枚グリッドの印象でフォローされるか決まります。

- 市松（チェッカー）配置を基本とする：ボルドー背景（`#5A1425`）の表紙と、ウォームホワイト背景（`#FAF6F2`）の表紙を交互に並べる。赤と白が互い違いに並ぶことで、ハンガリー国旗とワインの世界観がグリッド全体で伝わる
- 迷ったら「前回が赤なら今回は白」で決める
- 投稿前に「今の9枚に並べたらどう見えるか」を確認する（Instagramの下書き or Canvaで9枚並べて確認）

### 5-6. 制作時の「やってはいけない」

- 毎回フォント・色が違う
- 文字が小さすぎる／端ギリギリ（スマホで読めない）
- 無料素材の「いかにも」な写真を多用（世界観が薄まる）
- 情報を1枚に詰め込みすぎる
- 解像度の低い画像・引き伸ばした画像

### 5-7. テンプレート運用（推奨ツール）

- Canva でブランドキット（色・フォント・ロゴ登録）を作り、テンプレを複製して中身だけ差し替える運用が最速
- テンプレは最低これだけ用意：表紙／解説（複数）／ワイン紹介／イベント告知／参加者の声／ストーリー用
- テンプレの保管場所は 3-5 に記載

## 6. コンテンツ設計とシリーズ

「何を投稿すればいいか分からない」を無くすための章です。投稿の型（シリーズ）をあらかじめ決めておけば、運用担当者は中身を差し替えるだけで回せます。

### 6-1. コンテンツの5本柱（投稿は必ずどれかに属する）

集客は「知ってもらう→信じてもらう→行動してもらう」の順で進みます。投稿もこの流れを意識してバランスを取ります。

| 柱 | 目的 | 全体比率の目安 | 例 |
|----|------|--------------|----|
| ハンガリー（差別化） | 他にないアカウントだと認識させる | 30% | 産地、ワイナリー、品種、雑学、料理 |
| 教育（初心者知識） | 発見・保存されてリーチを広げる | 25% | ワインの選び方、用語、マナー |
| 世界観（ブランド） | 会場／雰囲気で憧れを作る | 15% | 会場、グラス、今夜の一杯 |
| 信頼（社会的証明） | 「行っても大丈夫」の不安を消す | 15% | 参加者の声、当日レポ、主催者紹介 |
| 行動（集客CTA） | 申込・問い合わせに直接つなげる | 15% | 次回開催告知、残席、締切 |

この配分の意図：

- **ハンガリーを最大の柱に据えます。** 「初心者向けワイン会」は他にもありますが、ハンガリーを深く語れるアカウントはほぼ存在しません。ここがフォローし続ける理由になり、広告に頼らず伸びる土台になります
- ただし教育（25%）を切らさないこと。ハンガリーの話だけだと「詳しい人向け」に見え、初心者が離れます。両方を交互に出すのが正解です
- 信頼（15%）は開催後に集中して出します。月1回開催なので、開催直後の3日間にまとめて投下するのが効率的です（7-3）

迷ったら「ハンガリー × 初心者目線」。この2つが重なる投稿がこのアカウントの本命です（例：「トカイの貴腐ワインが、実はワイン初心者に一番おすすめな理由」）。

### 6-2. シリーズ企画（看板コーナーを持つ）

毎回バラバラの投稿ではなく、繰り返す連載を持つとファンが付き、制作も楽になります。各シリーズに固定のデザインテンプレ（5章）を用意してください。

方針：このアカウントはハンガリーを軸に据えます。「初心者向けのワイン会」を名乗るアカウントは他にもありますが、ハンガリーを深く語れるアカウントはほぼありません。そこが最大の差別化であり、フォローし続ける理由になります。

ただし、ハンガリーの話に寄せすぎると「詳しい人向け」に見えてしまいます。ハンガリーの話をするときも、必ず初心者の目線で語る（専門用語には一言解説、難しい歴史は逸話として短く）ことを守ってください。

**① ハンガリー系（このアカウントの主軸）**

1. 『ハンガリーワイン入門』 … トカイ（貴腐ワイン）、フルミント、ケークフランコシュ等を初心者向けに1つずつ
2. 『ハンガリーワインの産地を巡る』 … トカイ／エゲル／ヴィラーニ／バラトン湖畔など、産地ごとに地図＋特徴＋代表的な味わい
3. 『ワイナリーを訪ねて』 … 実際に取り扱う生産者を1軒ずつ紹介。人・畑・造りの物語
4. 『ハンガリー小話』 … 雑学・歴史の逸話を1テーマ1枚で軽く（重い通史にしない）
5. 『ハンガリーの食卓』 … グヤーシュ等の料理紹介と、合わせたいワイン

**② 教育系（初心者の不安を消す）**

6. 『ワイン初心者ノート』 … 用語・選び方・保存など基礎を1テーマずつ（保存狙いの主力）
7. 『失敗しないワインのマナー』 … 乾杯・グラスの持ち方・注文の仕方など不安解消
8. 『家でもハンガリーワインを』 … 買える場所・家での楽しみ方・合わせる料理。「ハンガリーワインを気軽に飲む風習をつくる」（4-1）を直接担う枠。ここを切らさないこと

**③ 世界観系**

9. 『今夜の一杯』 … 1本のワインを美しい写真＋一言ストーリーで
10. 『六本木の夜に』 … 会場（六本木一丁目「経営者の部室」）の空気感・当日の設え・街の雰囲気

**④ 信頼系**

11. 『参加者の声』 … 感想を1枚で（特に「初参加でも安心だった」系）
12. 『ワイン会レポート』 … 開催後の様子ダイジェスト
13. 『主催者／ソムリエ紹介』 … 人柄が見えると申込が増える

**⑤ 行動系**

14. 『次回開催のお知らせ』 … 日程・残席・申込導線を明確に
15. 『よくある質問』 … 一人参加／持ち物／ドレスコード／価格感

運用のコツ：曜日にシリーズを割り当てる（具体的な割り当ては7-1の表）。「何を出すか」を毎回考えずに済みます。

ハンガリー系を扱うときの注意：産地名・生産者名・品種名はAIが誤りやすい領域です。必ず裏取りしてください（10-9）。特に取り扱いのある生産者を紹介する場合は、仕入れ担当に確認を取ること。

### 6-3. 投稿フォーマット別の使い分け

| フォーマット | 得意なこと | このアカウントでの使い道 |
|-------------|-----------|------------------------|
| カルーセル（複数枚） | 保存・じっくり読ませる | 教育系の主力。「ノート」「入門」系 |
| リール（短尺動画） | 新規リーチ・発見 | 会場の雰囲気、注ぐ瞬間、テイスティング、Before/After |
| 単写真 | 世界観・美しさ | 『今夜の一杯』 |
| ストーリーズ | 日常接触・親近感・告知 | 舞台裏、質問箱、カウントダウン、残席速報（8章） |
| ハイライト | 常設の入口 | はじめての方へ／次回開催／参加者の声／FAQ |

リールは新規獲得の要。週1本は入れる。冒頭2秒で「お、なにこれ」と思わせる画（美しい注ぎ・グラスの反射・会場）で始める。

### 6-4. ネタの引き出し（ネタ切れ防止リスト）

**ハンガリー（主軸・30%）**

ワインそのもの：

- ハンガリーワインって何がすごいの？（トカイ＝「王のワイン、ワインの王」と称された話）
- 貴腐ワインってなに？なぜ甘い？（カビが作る奇跡、という切り口）
- なぜ初心者にハンガリーワインが向いているのか（看板になる1本。最初に作る）
- フルミント／ハールシュレヴェリュー／ケークフランコシュなど品種を1つずつ
- ハンガリーワインが日本で手に入りにくい理由

産地：

- ハンガリーのワイン産地マップ（全体像を1枚で）
- トカイ … 貴腐ワインの故郷。世界遺産の畑
- エゲル … 「牡牛の血」の産地。赤の名産地
- ヴィラーニ … 南部の温暖な赤ワイン産地
- バラトン湖畔 … 湖が育てる白ワイン

ワイナリー・造り手：

- 取り扱い生産者を1軒ずつ紹介（人・畑・こだわり）
- 家族経営のワイナリーの話
- ハンガリーワインの造りの特徴（オーク樽・地下セラーなど）

歴史・雑学（重くせず、逸話として1枚で）：

- ハンガリーワインが一度途絶えかけた話とその復活
- ヨーロッパの王侯貴族に愛された話
- ハンガリー語の発音の面白さ（品種名の読み方）
- ハンガリーの乾杯の作法・習慣

料理：

- グヤーシュ（ハンガリーの代表料理）とワインの相性
- パプリカを使った料理と赤ワイン
- 家で作れるハンガリー風のおつまみ

**ワインの説明（初心者向けにやさしく）**

- 赤・白・ロゼ・スパークリング・甘口の違いをざっくり
- ラベルの読み方
- 「渋味」「酸味」「ボディ」って何？を体感ベースで
- 甘口から入って何が悪いの？という話

**ワイン会の楽しみ方**

- 一人参加でも楽しめる理由／当日の流れ
- 会費7,000円で何が飲める？（内訳を見せると納得感が出る）
- 会場までの行き方（六本木一丁目駅からの道のり）
- 何を着ていけばいい？（ドレスコードの不安解消）
- 乾杯〜テイスティングの作法（気楽に）
- ワイン会で使える一言フレーズ集
- 交流のきっかけの作り方

**Tips（保存されやすい／「ハンガリーワインを日常に」枠）**

- ハンガリーワインはどこで買える？（最重要。気に入っても買えなければ習慣にならない）
- 初めての1本に選ぶならこれ（価格帯別に3本）
- 平日の夜に開けるならこの品種
- この料理にはこのハンガリーワイン（和食・コンビニ惣菜など身近なもので）
- コンビニ／スーパーで買える「ハズさない」一本
- 開けたワインの保存方法
- グラスがなくても楽しむ方法
- 二日酔いを避ける飲み方（※医療的断定はしない）
- 手土産に喜ばれるワインの選び方

**季節・行事フック**

- 季節（新緑・夏の白・秋の熟成・冬の甘口）
- 記念日・デート・女子会・忘年会シーズン
- ハンガリーの祝祭・収穫期の話題

### 6-5. 1投稿を作るときの思考テンプレ

投稿を作る前に、この5つを埋めてから制作に入ると外しません。

```
1. 柱：ハンガリー / 教育 / 世界観 / 信頼 / 行動 のどれ？
2. シリーズ：どのコーナー？
3. ターゲットの不安/欲求：この投稿はどの不安を消す／欲求を満たす？
4. 1枚目のフック：3秒で止める言葉は？
5. ゴール：保存 / フォロー / LINE登録 / 申込 のどれ？
```

そして最後に、この1問を通してください。

> この投稿は「ハンガリーワインを1本買ってみよう」または「この会に行ってみよう」と思わせるか？

どちらにも当てはまらず、「ワインっていいな」で終わる投稿は、私たちが出す意味が薄い投稿です（4-1）。テーマを変えるか、切り口をハンガリーに寄せてください。

この5項目はそのまま10章「AIプロンプト集」の入力に使えます。

## 7. 投稿カレンダーと運用フロー（仮案）

「いつ・何を・どうやって投稿するか」のルーティンを定義します。ルーティン化＝属人化を防ぎ、誰が担当しても回る状態を作ります。

### 7-1. 投稿頻度（立ち上げ期・ほぼ毎日ペース）

立ち上げ期は接触回数を稼いで一気に土台を作ります。フィードはほぼ毎日のペースで回します。

| フォーマット | 頻度 | 補足 |
|-------------|------|------|
| フィード（カルーセル／写真） | 週5〜6回 | 教育系を軸に。日曜は休みでOK |
| うちリール | 週2回 | 上記フィードのうち2本をリールにする。新規リーチの主力 |
| ストーリーズ | 毎日 | 短くてOK。接触回数が大事 |
| ハイライト更新 | 随時 | 告知・FAQは常に最新に |

毎日出すための鉄則：質を落とさず量を出すには、まとめ制作（週1日で1週間分）とテンプレの使い回しが必須です（7-2）。1本ずつその日に作ろうとすると必ず破綻します。

それでもきつくなったら、削る順番は「フィード → リール → ストーリーズ」ではなく「フィードを減らしてストーリーズは死守」。毎日の接触が切れるのが一番痛いためです。

曜日割り当て（推奨テンプレ・調整可）：

| 曜日 | 形式 | 柱 | シリーズ例 |
|------|------|----|-----------|

開催が月1回であることを踏まえた月内の配分：

会場の予約枠の都合で開催は月1回です。告知を毎週打つと「またか」と飽きられるので、月内でメリハリをつけます。

| 時期 | 重点 |
|------|------|
| 開催の3〜4週間前 | 教育・世界観中心。告知は1本（日程解禁） |

| 開催の1週間前〜前日 | 残席速報・カウントダウン（主にストーリーズ）。締切を明示 |
| 開催直後（3日以内） | レポート・当日の様子。次回への申込が一番動くタイミング |

- ターゲットがスマホを見る時間＝平日 12時前後 / 19〜22時、週末 午前〜昼が無難
- 六本木勤務層を狙うなら平日は 21時前後が最有力（帰宅後）
- 実データ（インサイトの「フォロワーのアクティブ時間」）が出たら、そこに合わせて最適化（9章）

ストーリーズだけは当日ネタでOK：仕入れ・準備・移動中など、その日の断片を1つ出せば十分です。作り込まないこと。

### 7-4. 投稿の実作業手順（フィード投稿）

1. 下書き準備：キャプション（10章）＋画像（5章）＋ハッシュタグを用意
2. チェック：投稿前チェックリスト（11章）を通す
3. 投稿 / 予約：
   - 手動：Instagramアプリ →「＋」→ 画像選択 → キャプション貼り付け → シェア
   - 予約：Meta Business Suite（無料）or 予約ツールで日時指定
4. 投稿後：
   - 誤字・リンク・タグの表示を確認
   - 最初の30〜60分はコメントに素早く反応（初速がリーチを伸ばす）
   - ストーリーズで「新しい投稿しました」とリポスト

キャプションの基本構造：

```
[フック1行：続きを読みたくなる問いや結論]
 例）ワイン、何を頼めばいいか分からない…そんな時はコレ。

[本文：やさしく解説。改行で読みやすく]

[CTA：保存・フォロー・プロフィール誘導のどれか]
 例）迷ったとき用に保存してね／次回のワイン会はプロフィールから

[定型フッター：アカウントの一言＋ハッシュタグ]
```

### 7-5. ハッシュタグ運用

**結論から：ハッシュタグはリーチ拡大の手段としては、もう期待できません。「たくさん付ける」運用はやめて構いません。** 労力はキャプションの書き方に回してください。

なぜか：

Instagram側の説明として、ハッシュタグを増やしてもリーチは伸びないという趣旨の発言が公式に出ており、ハッシュタグをフォローする機能も廃止されています。現在の発見面は、ハッシュタグではなく投稿そのものの反応（保存・シェア・視聴完了）と、キャプション内のキーワードで決まる仕組みに移っています。

では何をするか：

- キャプションの冒頭に、検索されそうな言葉を自然に入れる（ハッシュタグより効きます）
  - 例：「六本木のワイン会」「ワイン初心者」「ハンガリーワイン」「貴腐ワイン」といった語を、文章の中で普通に使う
  - タグとして並べるのではなく、読んで意味が通る文の中に含めるのがポイント
- ハッシュタグは3〜5個まで。付けるのは次の目的に絞る
  - **ブランドタグ #IZAワインクラブ（必須）** … 参加者の投稿（UGC）を集める受け皿。ここだけは明確に価値があります
  - 内容を端的に示すタグを2〜4個（例：#ハンガリーワイン #ワイン初心者 #六本木ワイン会）
- リーチが欲しいときはリールを作る。タグを増やすより確実です（6-3）

やらなくてよくなったこと：

- 10〜20個のタグを毎回付ける
- 大・中・小のボリュームを計算して混ぜる
- タグのセットを複数作って使い回す（同じタグの連投を避けるため、という運用）

ただし完全にゼロにはしない理由は、ブランドタグでUGCを集約するためと、投稿内容を示す最低限の手がかりとして残すためです。11-4に3〜5個の基本セットを置いてあります。

なお、この分野は仕様変更が頻繁です。半年に1度は「今のInstagramで何が効くか」を確認し、必要ならこの節を書き換えてください。

## 8. エンゲージメント運用（コメント・DM・ストーリー）

投稿は「出して終わり」ではありません。反応への対応こそがフォロワーとの関係＝申込率を左右します。この章は秘書が毎日使う実務テンプレです。

この章のゴールは1つ：**反応してくれた人を LINE公式アカウント に連れて行くこと**（9-3）。Instagram上で完結させようとせず、必ずLINEへ渡してください。InstagramのDMは流れて消えますが、LINEに入れば次回以降も告知が届きます。

### 8-1. まず最初に：秘書が単独で判断しない領域

以下は必ず高橋に確認してから回答します（勝手に答えない）。誰が担当でも安全に運用するための線引きです。

- 価格・割引・返金・キャンセルポリシー（※「7,000円前後」という案内までは秘書が回答してよい。値引き・特別対応は不可）
- 開催日程・定員・残席の最終確定情報（※「定員30名前後」「現状は月1回開催」「次回は◯月頃」までは可）
- クレーム・トラブル・体調／アルコールに関する相談
- 提携・取材・コラボ・広告の依頼
- 個人情報の取り扱いに関わること
- 参加者の実名・属性に関する質問（「どんな人が来ますか」への回答は属性の傾向まで。個人が特定される話はしない）

秘書が単独で回答してよい範囲（即答OK）：

- 「一人でも参加できますか」「初心者でも大丈夫ですか」
- 「場所はどこですか」（六本木一丁目駅すぐ、詳細住所は申込後）
- 「会費はいくらですか」（7,000円前後、確定額は回ごとに案内）
- 「どんなワインが飲めますか」（ハンガリーワイン中心、銘柄は回ごと）
- 投稿内容に関するワインの一般的な質問

上記以外は「確認してご連絡します」で一旦受け、高橋に確認してから返す。**待たせても構わないので、誤った情報を先に出さないこと。** 特に価格と日程の誤案内は、後から訂正するとブランドの信頼を大きく損ないます。

### 8-2. コメント対応

- 基本、全コメントに返信（初期はこれが効く）。返信は速いほど良い
- 投稿後30〜60分のコメントは最優先。初速の反応がリーチを伸ばします（7-4）
- 絵文字1つだけの返信で終わらせず、一言添えると会話が続く
- 質問コメントは丁寧に答える＋「DMでも受付中です」へ誘導
- ネガティブ／批判：感情的に反応しない。事実確認が必要なものは高橋へエスカレーション

返信テンプレ例（トンマナ4-4に準拠。一人称「私たち」・呼びかけ「皆さま」）：

| シーン | 返信例 |
|--------|--------|
| 褒めコメント | 「ありがとうございます。そう言っていただけて嬉しいです」 |
| 「参加してみたい」 | 「ぜひ。次回の開催はプロフィールのリンクからご案内しています。ご不明点はお気軽にDMをどうぞ」 |
| 「一人でも大丈夫？」 | 「もちろんです。お一人参加の方がとても多いので、ご安心ください」 |
| 「ワイン詳しくないけど…」 | 「むしろ初めての方に向けた会です。難しい知識はいりませんので、ぜひ気楽にいらしてください」 |
| 「会費いくら？」 | 「7,000円前後でご案内しています。回ごとの詳細はプロフィールのリンクからご確認いただけます」 |
| 「どこでやってるの？」 | 「六本木一丁目駅から歩いてすぐの会場です。詳しい場所はお申込みの方にご案内しています」 |
| 質問（答えられる範囲） | 「良いご質問です。◯◯です。詳しくは近日投稿しますね」 |
| 日程の最終確定など要確認 | 「お問い合わせありがとうございます。確認してDMにてご案内します」 |

やってはいけない返信：「ぜひご参加ください！！」のような煽り、絵文字の連打、他の参加者の情報に触れること。

### 8-3. DM対応（担当：秘書 / 一次対応）

DMは見込み客との1対1。ここで申込が決まります。丁寧かつスピーディに。

対応の基本：

- 初回反応は当日中に（数時間以内が理想）。翌日以降になると熱が冷めます
- テンプレをベースにしつつ、相手の言葉に合わせて一言パーソナライズ
- ゴールは必ずLINE公式アカウントへの誘導。「詳細はLINEでご案内しています」で橋を渡す
- 8-1の「単独で判断しない領域」に触れたら、その場で答えず「確認してご連絡します」

DMテンプレ例（トンマナ4-4に準拠）：

初回問い合わせへの返信：

```
はじめまして、IZAワインクラブです。
ご連絡ありがとうございます。

◯◯についてですね。
（回答）

次回は【◯月】に六本木で開催を予定しています。
日程の詳細やお申込みは、LINEでご案内しています。
こちらからご登録いただけます。
（LINEリンク）

その他ご不明な点があれば、なんでもお気軽にどうぞ。
```

「初めてで不安」への返信：

```

ご参加の皆さまの多くがワイン初心者で、
お一人でいらっしゃる方がほとんどです。
「詳しくないと浮くのでは…」という心配はいりません。

当日は私たちが順番にご案内しますので、

```


よく来る質問はテンプレ化して11-5に蓄積。担当が変わっても同じ品質で返せます。新しい質問が来たら、その場で答えて終わりにせず11-5に追記するのが秘書の仕事です。

### 8-4. ストーリーズ活用（毎日1本）

ストーリーズは「更新している感」と親近感を出す最重要ツール。完璧でなくてOK、頻度が命。7-1のとおり毎日1本を出します。

これだけは守る：フィード投稿を減らすことになっても、ストーリーズだけは切らさない。毎日の接触が途切れると、フォロワーの中でアカウントの存在が薄れます。作り込まず、その日の断片を1枚出せば十分です。

曜日に迷わないためのネタ割り（目安）：

| 内容 | 頻度 | 例 |
|------|------|----|
| 舞台裏 | 週2〜3 | ワインの仕入れ、会場の準備、当日の朝 |
| フィード投稿のリポスト | 投稿日ごと | 「新しい投稿しました」（見逃し防止） |
| スタンプで参加を促す | 週1〜2 | 質問箱「ワインの疑問、答えます」／アンケート「赤 vs 白、どっち派？」 |
| 開催前の告知 | 開催2週間前〜 | カウントダウンスタンプ、残席速報 |
| 開催後 | 開催直後 | 当日の様子（掲載許可を取ってから。8-6） |

ストーリーズ活用のコツ：

- リンクスタンプでLINE公式へ直接誘導（プロアカウントで利用可）。プロフィールに戻らせるより離脱が少ない
- スタンプ（質問・アンケート・クイズ）を週1〜2回入れると反応率が上がる。アンケートは「赤 vs 白」のように2択で、考えなくても押せるものにする
- 反応（返信・スタンプ）にはできるだけリアクションを返す。ここから雑談が始まり、申込につながることが多い
- 質問箱に集まった質問は、そのままフィード投稿のネタになる（6-4のネタ切れ防止にも効く）

### 8-5. 能動的アプローチ（待ちの運用にしない）

フォロワーが少ない立ち上げ期は、こちらから見つけてもらいに行く動きが必要です。1日10〜15分を目安に。

回るべきハッシュタグ（会場が六本木なので地域タグが効きます）：

- 地域：#六本木 #六本木グルメ #麻布十番 #東京カフェ巡り
- 興味：#ワイン好きと繋がりたい #ワイン初心者 #大人の習い事 #ワインのある暮らし
- 行動：#東京イベント #社会人サークル

やること：

- 上記タグの新着投稿に丁寧にいいね／一言コメント（定型文のコピペではなく、投稿内容に触れる）
- ワイン・グルメ・お出かけ系アカウントと自然な交流
- 参加者が投稿してくれたらリポスト＆お礼（UGCを育てる）
- 会場周辺（六本木・麻布）の飲食店やイベント系アカウントと関係を作る

やってはいけない（アカウント凍結・ブランド毀損のリスク）：

- 自動化ツールでの大量いいね／フォロー／DM（規約違反）
- 無関係なアカウントへの営業DMの一斉送信
- フォロー＆アンフォローの繰り返し
- 「ぜひ参加してください」といった、こちらから売り込むコメント。あくまで先に相手へ関心を示すのが順番です

### 8-6. 参加者の写真・声の掲載フロー（重要）

**参加者の写真は最も強い集客素材ですが、同意なく載せると一発でブランドを失います。** 手順を必ず守ってください。

1. 開催冒頭で全体に一声かける：「本日、SNS掲載用に写真を撮らせていただきます。写りたくない方は遠慮なくお申し付けください」
2. 顔がはっきり写る写真は、その場で本人に個別確認する
3. 顔出しNGの人が背景に写り込んでいないか、掲載前に必ず確認する
4. 掲載時はネガティブに使わない・加工で誤解を生まない
5. 「掲載をやめてほしい」と言われたら理由を聞かずに速やかに削除する

顔出しNGの方が多い場合の撮り方（初心者向けの会では珍しくありません）：

- 手元とグラスだけを写す／後ろ姿・シルエットで雰囲気を伝える
- テーブル・ワイン・会場の設えを主役にする
- 参加者の「声」はテキストで紹介する（顔写真がなくても信頼は伝わる）

記録の残し方：誰にどこまで許可をもらったかは、開催ごとにメモを残してください。回数を重ねると必ず分からなくなります。

## 9. KPIと分析・広告出稿

「頑張った／頑張ってない」ではなく数字で運用するための章です。数値の記録は秘書、意思決定は高橋が担います。

### 9-1. KPIの全体像（4階層で考える）

集客は「見られる → 反応される → LINEに入ってもらう → 申し込まれる」の階層で進みます。上から順に改善します。

| 階層 | 指標（KPI） | 何を意味するか | 主な打ち手 |
|------|-----------|--------------|-----------|
| 認知 | フォロワー数 / リーチ / プロフィールアクセス | どれだけの人に届いたか | リール・教育投稿・広告 |
| 関心 | エンゲージメント（保存・いいね・コメント・シェア） | どれだけ刺さったか | コンテンツの質・フック |
| 移行 | LINE友だち追加数 | 見込み客として捕まえられたか | プロフィール文・ストーリーのリンク・DM誘導 |
| 行動 | 参加者数（集客）/ 申込数 | どれだけ商売に繋がったか | LINE配信・オファー |

最重要は参加者数（集客）。フォロワーが増えても参加者が増えなければ意味がありません。

**そして立ち上げ期の実質的な主戦場は「LINE友だち追加数」です。** Instagramのフォロワーは告知が届く保証がありませんが、LINEに入った人には毎回確実に届きます。開催が月1回である以上、今月申し込まなかった人を来月まで保持できるかが集客の成否を分けます。

### 9-2. 各KPIの定義と目標

逆算の起点：定員30名前後に対して、1回あたり参加者 26名以上（充足率およそ87%）。開催は現状月1回。仮にリピーター4割とすると、毎月およそ16名の新規参加者が必要です。そのうちInstagram経由で10名を目標とし、そこから逆算したのが下表です。

**開催回数が増えたら、この表の月次目標も比例して引き上げます。** 月2回開催になれば必要な新規は倍になるため、その時点で広告の投入を検討する判断材料にしてください（9-5）。

| KPI | 定義 | 見る場所 | 立ち上げ期（1〜3ヶ月） | 軌道に乗った後（4〜6ヶ月） |
|-----|------|---------|-------------------|---------------------|
| フォロワー数 | 純増数 | プロフィール／インサイト | +150〜200/月 | +300/月 |
| リーチ | 投稿を見たユニーク数 | インサイト | 5,000〜8,000/月 | 15,000/月 |
| プロフィールアクセス | プロフ閲覧数 | インサイト | 300/月 | 800/月 |
| エンゲージメント率 | (いいね+保存+コメント+シェア)÷リーチ | 手計算 | 3%以上 | 4%以上 |
| 保存数 | 保存された数 | 各投稿インサイト | 教育投稿1本あたり10件以上 | 25件以上 |
| LINE友だち追加数 | Instagram経由の新規登録 | LINE公式の管理画面 | 20〜30人/月 | 50人/月 |
| DM問い合わせ数 | 申込関連DM件数 | 手動カウント | 5件/月 | 15件/月 |
| 申込・参加者数（最重要） | 実際の申込／来場 | LINE／受付 | Instagram経由で5〜10名/月 | 15名/月 |
| 参加者総数（全チャネル） | 当日の来場者 | 受付 | 26名以上/回 | 26名以上/回 |

**1〜3ヶ月目でこの数字に届かないのは普通です。** 新規アカウントは最初の2〜3ヶ月ほとんど伸びません。「目標未達＝失敗」ではなく、「どの階層で詰まっているか」を見るための表として使ってください。たとえばリーチは出ているのにプロフィールアクセスが少なければ、問題は投稿本数ではなく1枚目のフックです。

どこが詰まっているかの読み方：

| 症状 | 詰まっている場所 | 打ち手 |
|------|----------------|--------|
| リーチが伸びない | 発見面に出ていない | リールを増やす。保存される教育投稿を厚くする |
| リーチはあるがプロフィールアクセスが少ない | 投稿がアカウントへの興味に繋がっていない | 1枚目のフック、ラストのCTAを見直す |
| プロフィールアクセスはあるがLINE登録が少ない | プロフィール文と導線が弱い | 自己紹介文・リンク先の見せ方を改善（3-3） |
| LINE登録はあるが申込が少ない | オファーか価格の伝え方 | LINE配信の内容、当日の流れの見せ方を見直す |

保存は初心者向け教育アカウントの生命線。「あとで読み返したい」＝価値がある証拠で、発見面での露出も伸びます。

### 9-3. 「Instagram → LINE → 申込」の導線（確定）

申込のゴールは **LINE公式アカウント** です。

```
Instagram（投稿・ストーリー・DM）
    ↓ プロフィールのリンク / ストーリーのリンクスタンプ / DMでの案内
LINE公式アカウント（友だち追加）
    ↓ 日程告知・申込受付
申込 → 当日参加
```

**なぜLINEなのか：** 開催が月1回のため、「興味はあるが今月は都合が合わない」人が必ず出ます。その人をInstagramのフォロワーのまま放置すると、翌月の告知が届かず失注します。LINEに入っていれば、翌月・翌々月に確実に届きます。**LINE友だちは失注ではなく在庫だと考えてください。**

LINEでやること（最低限）：

- 友だち追加時の自動あいさつ文に、会の概要・会費・会場・次回日程を入れる
- 開催の3週間前・1週間前・前日に告知を配信する
- 申込は LINEのトーク か、LINEから飛ばす申込フォームで受ける

計測方法：

- **一番簡単で確実なのは、申込時に「どこで知りましたか」を聞くこと。** UTMやピクセルの設定より先に、これを必ずやってください
- LINE公式の管理画面で「友だち追加数」の推移を月次で記録する
- Instagram側は、プロフィールの「リンククリック数」をインサイトで確認する
- 流入経路を細かく分けたい場合は、LINEの友だち追加URLを経路ごとに分ける（プロフィール用／ストーリー用など）

注意：LP（class-e-lp）には GA4とMeta Pixelの差し込み枠がありますが、LINEを申込導線にする場合、Instagram → LINEの間はGA4では追えません。広告を出す段階になったら、LINE専用のLP（Pixel設置済み）を挟む構成を検討してください（9-5）。

### 9-4. 分析ルーティン（何を・いつ見るか）

| タイミング | 担当 | 見るもの | アクション |
|-----------|------|---------|-----------|
| 投稿翌日 | 秘書 | その投稿の保存／リーチ／シェア | 伸びた型をメモ |
| 毎週（週末） | 秘書 | 上位・下位投稿、フォロワー増減 | 11-6の週次チェックに記録 → 来週の内容に反映 |
| 毎月（月末） | 秘書が作成 → 高橋 | 全KPI、LINE登録数、申込数、アクティブ時間 | 11-3のレポート作成 → 高橋に共有 |
| 開催後 | 高橋 | 参加者数・Instagram経由の割合 | 翌月の方針判断 |

「伸びる型」を見つける方法：

- 保存が多い投稿 → 教育テーマとして横展開（続編・関連を作る）
- リーチが多いリール → フォーマットを真似て量産
- プロフィールアクセス→LINE登録が低い → プロフィール文／導線を改善（3-3）
- **開催後は必ず参加者に「何を見て申し込んだか」を聞く。** インサイトの数字よりこの一言のほうが正確です

### 9-5. 広告出稿（立ち上げの考え方）

オーガニック（無料投稿）で勝ちパターンが見えてから広告を足すのが最も費用対効果が高いです。実行判断・予算は高橋。秘書は入稿と数値管理を担当。

**実務の手順書は [Meta広告 運用ガイド](../meta-ads-guide/README.md) にあります。** この節は方針、あちらは操作手順です。

始める時期の目安：オーガニックだけで「保存が伸びる投稿の型」が2〜3本見つかってから。目安は運用開始から3ヶ月後です。それより早く出すと、効かない投稿にお金を払うだけになります。

ただし、締切のある単発イベントの席を埋めるための小規模テスト（総額3万円程度・期間限定）は例外として実施します。そこで得た「どのクリエイティブ・どの層が反応するか」のデータは、本格出稿の初期値としてそのまま使えるためです。

ステップ：

1. 土台を作る：プロアカウント＋Facebookページ連携
2. 勝ち投稿を広告化：反応の良かった投稿を「投稿を宣伝」で少額からテスト（1日500〜1,000円 × 1週間 = 3,500〜7,000円で十分わかります）
3. 本命キャンペーン：Meta広告マネージャで目的別に配信
   - トラフィック／リード目的：LINE登録（＝集客に直結、まずここ）
   - 認知／リーチ目的：新規フォロワー・ブランド認知（後回しでよい）
4. ターゲティング案（ペルソナ4-2と連動）
   - 地域：六本木一丁目から半径5〜10km（港区・千代田区・渋谷区が中心）
   - 年齢：28〜45歳（※アルコール広告は下限20歳が必須）
   - 興味関心：ワイン、レストラン、習い事、デート／交流イベント 等
   - リターゲティング：プロフィール接触者・動画視聴者に再アプローチ
5. 計測：CPA（申込1件あたりコスト）で判断

採算の考え方（重要）：

会費が7,000円前後なので、広告費をかけられる上限は自ずと決まります。

- 参加者1名あたりの粗利を仮に3,000円とすると、CPAが3,000円を超えたら赤字です
- ただし、一度来た人は2回目・3回目も来る可能性があるため、初回だけで判断せず「その人が年に何回来るか」で見ます。年2回来るなら許容CPAは倍になります
- まずはCPA 2,000〜3,000円を目安に置き、実績が出たら見直してください

広告で最初に決めること：

| 項目 | 決定内容 |
|------|---------|
| 目的 | トラフィック／リード（LINE登録）から始める |
| 月間予算 | 後で記載（初期テストは月1〜2万円程度を推奨） |
| 1申込あたり許容コスト（CPA） | 後で記載（目安2,000〜3,000円） |
| 主要ターゲット地域 | 六本木一丁目から半径5〜10km |
| 開始時期 | 後で記載（オーガニック3ヶ月後を推奨） |

**お酒の広告はMetaのポリシー（年齢制限・地域制限）に注意。** 配信対象を20歳以上に限定するなど、審査要件を必ず確認してください。ここを外すと広告が却下されるだけでなく、繰り返すとアカウントに制限がかかることがあります。

### 9-6. 最低限そろえる分析環境

すぐに用意するもの：

- Instagramプロアカウント（インサイト）… 3-2
- Meta Business Suite（無料・予約投稿＋分析）
- LINE公式アカウント（友だち追加数の確認）… 9-3
- 月次レポート用Googleスプレッドシート（11-3の雛形）

広告を始める段階で用意するもの：

- Facebookページと広告アカウントの連携
- Meta Pixel（LINE前にLPを挟む構成にする場合）… LP側の `[META_PIXEL_ID]` 枠を使用
- GA4（同上、`[GA4_MEASUREMENT_ID]` 枠）

最初から全部そろえようとしなくて構いません。立ち上げ期に本当に必要なのは、インサイトとLINEの友だち追加数、そして「どこで知りましたか」の一言だけです。

### 10-9. AI利用の注意（必ず守る）

- **事実確認**：ワインの産地・品種・数値などAIは間違えることがある。公開前に裏取り。特にハンガリーワインは情報が少なく、AIが自信ありげに誤情報を出しやすい領域です。トカイの格付け、品種名の読み方、生産者名は必ず確認してください
- **価格・日程を断定させない**：AIは聞かれると具体的な数字を作ります。生成文に日程や金額が入っていたら必ず削るか、確定情報に差し替える（8-1）
- **トンマナ**：出力が硬い／砕けすぎたら10-0の前提を調整して再生成
- **コンプラ**：お酒表現・健康効果・未成年（4-5）を必ずチェック
- **丸コピ禁止**：他社そっくりの表現になっていないか確認。ブランドの言葉に直す
- **画像の権利**：生成画像でも、実在ロゴ／人物／商標が紛れ込んでいないか確認
- **生成画像を実際の会場・参加者として出さない**（10-3）
- **生成物の文字化けを目視する**：画像・動画に日本語テロップを入れさせると、崩れた文字がそのまま残ることがあります。公開前に必ず全フレームを目で読んでください
