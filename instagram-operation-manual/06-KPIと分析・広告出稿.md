# 06. KPIと分析・広告出稿

「頑張った/頑張ってない」ではなく**数字で運用する**ための章です。
運用担当者は数値の記録・報告を、COO/責任者は意思決定を担います。

---

## 🎯 1. KPIの全体像（3階層で考える）

集客は「見られる → 反応される → 申し込まれる」の階層で進みます。上から順に改善します。

| 階層 | 指標（KPI） | 何を意味するか | 主な打ち手 |
|------|-----------|--------------|-----------|
| ① 認知 | **フォロワー数** / リーチ / プロフィールアクセス | どれだけの人に届いたか | リール・教育投稿・広告 |
| ② 関心 | **エンゲージメント**（保存・いいね・コメント・シェア） | どれだけ刺さったか | コンテンツの質・フック |
| ③ 行動 | **参加者数（集客）** / 申込数 / リンククリック / DM数 | どれだけ商売に繋がったか | CTA・導線・オファー |

> 💡 **最重要は③参加者数（集客）。**フォロワーが増えても参加者が増えなければ意味がありません。ただし③を増やすには①②が土台になります。

## 🔗 3. 「Instagram → 申込」の導線をどう測るか

**申込のゴールをどこに置くか**を先に決めます（**後で確定** → `README` の未確定リスト）。

- 候補：① LP（`class-e-lp`）のフォーム ／ ② 専用申込フォーム ／ ③ LINE公式 ／ ④ リンク集ツール
- どれにするにせよ、**計測できる状態**にする：

### UTMパラメータで流入を可視化（推奨）
プロフィール/ストーリーのリンクに印を付けて、GA4で「Instagram経由の申込」を測ります。
```
https://m-tkd.github.io/IZAJAPAN/class-e-lp/?utm_source=instagram&utm_medium=social&utm_campaign=profile_link
```
- `utm_source=instagram` … 流入元
- `utm_medium=social` … 種別
- `utm_campaign=...` … 施策名（profile_link / story_0525 / reel_tokaji 等）

> LP側には既に **GA4測定ID** と **Meta Pixel** の差し込み枠があります（`class-e-lp/index.html` の `[GA4_MEASUREMENT_ID]` `[META_PIXEL_ID]`）。ここを設定すると、広告の効果測定まで一気通貫でつながります。

## 📈 4. 分析ルーティン（何を・いつ見るか）

| タイミング | 見るもの | アクション |
|-----------|---------|-----------|
| 投稿翌日 | その投稿の保存/リーチ/シェア | 伸びた型をメモ |
| 毎週 | 上位・下位投稿、フォロワー増減 | 来週の内容に反映 |
| 毎月 | 全KPI、導線（申込数）、アクティブ時間 | レポート作成→COOへ（→ `08`雛形） |

### 「伸びる型」を見つける方法
- 保存が多い投稿 → **教育テーマとして横展開**（続編・関連を作る）
- リーチが多いリール → **フォーマットを真似て量産**
- プロフィールアクセス→リンククリックが低い → **プロフィール文/導線を改善**

## 📣 5. 広告出稿（COO向け・立ち上げの考え方）

オーガニック（無料投稿）で**勝ちパターンが見えてから**広告を足すのが最も費用対効果が高いです。
※実行判断・予算はCOO/責任者。運用担当者は入稿と数値管理を担当。

### ステップ
1. **土台を作る**：プロアカウント＋Facebookページ連携＋**Meta Pixel**をLPに設置（既存枠を有効化）
2. **勝ち投稿を広告化**：反応の良かった投稿を「**投稿を宣伝**」で少額から（例：1日数百〜千円）テスト
3. **本命キャンペーン**：Meta広告マネージャで目的別に配信
   - 認知/リーチ目的：新規フォロワー・ブランド認知
   - **トラフィック/リード目的**：LP誘導・申込（＝集客に直結、まずここ）
4. **ターゲティング案**（→ ペルソナ `01` と連動）
   - 地域：会場周辺（例：東京都/渋谷から一定範囲）
   - 年齢：28〜45
   - 興味関心：ワイン、レストラン、習い事、デート/交流イベント 等
   - **リターゲティング**：LP訪問者・プロフィール接触者に再アプローチ（Pixel活用）
5. **計測**：申込までUTM＋Pixelで追い、**CPA（申込1件あたりコスト）**で判断

### 広告で最初に決めること（**後で記載**）
| 項目 | 決定内容 |
|------|---------|
| 目的 | ☐ 認知 ☐ トラフィック ☐ リード ☐ 来場 |
| 月間予算 | ＿＿＿ |
| 1申込あたり許容コスト(CPA) | ＿＿＿ |
| 主要ターゲット地域 | ＿＿＿ |
| 開始時期 | ＿＿＿ |

> ⚠️ **お酒の広告**はMetaのポリシー（年齢制限・地域制限）に注意。配信対象を20歳以上に限定するなど、審査要件を必ず確認。
