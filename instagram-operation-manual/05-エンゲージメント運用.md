# 05. エンゲージメント運用（ストーリー・コメント・DM）

投稿は「出して終わり」ではありません。**反応への対応**こそがフォロワーとの関係＝申込率を左右します。
この章は運用担当者が毎日使う実務テンプレです。

---

## ⛔ まず最初に：運用担当者が“単独で判断しない”領域

以下は必ず**責任者に確認してから**回答します（勝手に答えない）。誰が担当でも安全に運用するための線引きです。

- 価格・割引・返金・キャンセルポリシー
- 開催日程・定員・残席の**最終確定**情報
- クレーム・トラブル・体調/アルコールに関する相談
- 提携・取材・コラボ・広告の依頼
- 個人情報の取り扱いに関わること

> 定型で返してよい範囲は下記テンプレの通り。**それ以外は「確認してご連絡します」で一旦受ける。**

---

## 💬 1. コメント対応

- **基本、全コメントに返信**（初期はこれが効く）。返信は速いほど良い
- 絵文字1つだけの返信で終わらせず、**一言添える**と会話が続く
- 質問コメントは**丁寧に答える＋「DMでも受付中です」**へ誘導
- ネガティブ/批判：感情的に反応しない。事実確認が必要なものは責任者へエスカレーション

### 返信テンプレ例
| シーン | 返信例 |
|--------|--------|
| 褒めコメント | 「ありがとうございます😊 そう言っていただけて嬉しいです🍷」 |
| 「参加してみたい」 | 「ぜひ🙌 次回の開催はプロフィールのリンクから見られます。ご不明点はお気軽にDMを!」 |
| 「一人でも大丈夫?」 | 「もちろんです☺️ お一人参加の方がとても多いので、ご安心を🍷」 |
| 質問（答えられる範囲） | 「良いご質問です! 〇〇です。詳しくは近日投稿しますね📝」 |
| 価格/日程など要確認 | 「お問い合わせありがとうございます! 確認してDMにてご案内します🙏」 |

## 📩 2. DM対応

DMは**見込み客との1対1**。ここで申込が決まります。丁寧かつスピーディに。

### 対応の基本
- 初回反応は**できるだけ早く**（数時間以内が理想）
- テンプレをベースにしつつ、相手の言葉に合わせて一言パーソナライズ
- ゴールは「**次のアクション（申込ページ/日程案内/質問解消）**」を必ず提示

### DMテンプレ例（後でトンマナに合わせて調整 → `01`）
**初回問い合わせへの返信**
```
はじめまして、IZAワイン会です🍷
ご連絡ありがとうございます!

〇〇についてですね。
（回答）

次回の開催は【〇月〇日】を予定しています。
ご興味があれば、こちらから詳細・お申込みいただけます👇
（リンク）

その他ご不明な点があれば、なんでもお気軽にどうぞ😊
```

**「初めてで不安」への返信**
```
ご不安な点、とてもよく分かります☺️
参加者の多くがワイン初心者・お一人参加なので、
「詳しくないと浮くのでは…」という心配はいりません🍷

当日はスタッフが丁寧にご案内しますので、
手ぶらの気持ちでお越しくださいね。
```

> 📌 よく来る質問はテンプレ化して `08` に蓄積。担当が変わっても同じ品質で返せます。

## 📲 3. ストーリーズ活用（毎日の接触）

ストーリーズは**「更新している感」と親近感**を出す最重要ツール。完璧でなくてOK、頻度が命。

### ネタリスト
- 舞台裏（ワインの仕入れ、会場準備、当日の朝）
- 質問箱スタンプ「ワインの疑問、答えます」→ 集まった質問を投稿ネタに
- アンケートスタンプ「赤 vs 白、どっち派?」（参加ハードルが低い）
- カウントダウンスタンプ（開催まであと〇日）
- 新規フィード投稿のリポスト（見逃し防止）
- 参加者の声・当日の様子（**掲載許可を取ってから**）
- 「残席わずか」などの行動喚起

### ストーリーズ活用のコツ
- **リンクスタンプ**で申込ページへ直接誘導（プロアカウントで利用可）
- スタンプ（質問・アンケート・クイズ）を**毎回1つ**入れると反応率が上がる
- 反応（返信・スタンプ）にはできるだけリアクションを返す

## 🤝 4. 能動的アプローチ（待ちの運用にしない）

フォロワーが少ない立ち上げ期は、**こちらから見つけてもらいに行く**動きが必要です。

- 関連ハッシュタグ（`#ワイン好きと繋がりたい` `#東京グルメ` 等）の投稿に**丁寧にいいね/コメント**
- ワイン・グルメ・お出かけ系アカウントと**自然な交流**
- 参加者が投稿してくれたらリポスト＆お礼（UGCを育てる）
- ※**スパム的な大量フォロー/コメントはNG**（ブランド毀損・アカウント制限リスク）

### やってはいけない
- ❌ 自動化ツールでの大量いいね/フォロー/DM（規約違反・凍結リスク）
- ❌ 無関係なアカウントへの営業DMの一斉送信
- ❌ フォロー&アンフォローの繰り返し

---

## 🖼 5. 参加者の写真・声の掲載フロー（重要）

1. 当日または事前に**掲載許可**を得る（口頭＋できれば書面/フォームで記録）
2. 顔出しNGの人が写り込んでいないか確認
3. 掲載時はネガティブに使わない・加工で誤解を生まない
4. 「掲載をやめてほしい」と言われたら**速やかに削除**
