# 00. 引き継ぎ・アカウント情報

このファイルは「アカウントの基本情報」と「担当が変わるときの引き継ぎ手順」をまとめます。
**運用担当者が変わっても止まらない**ことが目的です。

---

## 🔐 ログイン情報（記入欄）

> **⚠️ セキュリティ注意**
> ID・パスワードは **このリポジトリ（GitHub）には絶対に書き込まないでください。** コードは第三者に見られる可能性があります。
> 実際の認証情報は、以下いずれかの **安全な場所** に保管し、このマニュアルには「保管場所へのリンク」だけを残します。
> - 推奨：パスワード管理ツール（1Password / Bitwarden など）の共有ボールト
> - 代替：会社管理の限定共有ドキュメント（閲覧権限を絞る）

| 項目 | 内容 | 保管場所 |
|------|------|---------|
| Instagram ユーザーネーム（@） | `＿＿＿＿＿＿＿＿＿＿＿`（後で記載） | — |
| ログイン用メール / 電話 | 保管場所を参照 | `（例）1Password「IZAワイン会IG」` |
| パスワード | 保管場所を参照 | `（例）1Password「IZAワイン会IG」` |
| 2段階認証（2FA）の方法 | ☐ SMS ／ ☐ 認証アプリ | バックアップコードの保管場所を明記 |
| Facebookページ連携 | ☐ あり ／ ☐ なし | — |
| Metaビジネススイート / 広告アカウント | 保管場所を参照 | — |

> **2段階認証（2FA）は必ずON。** バックアップコードを保管場所に控えておくと、担当交代時のロックアウトを防げます。

## 📇 アカウント基本設定（プロアカウント化）

Instagram は必ず **プロアカウント（ビジネス）** に切り替えます。インサイト（分析）と広告出稿に必須です。

- [ ] プロアカウント（ビジネス）に切り替え済み
- [ ] カテゴリ：「ワインバー／イベント」等
- [ ] 連絡先ボタン設定（メール・電話・道順）
- [ ] Facebookページと連携（広告に必要）

## 🧾 プロフィール（記入欄 / 推奨案つき）

プロフィールは「**3秒で誰向けの何かが分かる**」ことが最重要。

**名前欄（検索対象になるのでキーワードを入れる）**
```
（推奨案）IZA｜初心者のためのハンガリーワイン会
```

**自己紹介文（150字以内）テンプレート**
```
🍷 ワインが初めての方も安心のワイン会 @東京
🇭🇺 知られざるハンガリーワインの世界へ
✔ 難しい知識はいりません
✔ 少人数・アットホーム
👇 次回の開催・お申込みはこちら
```

- [ ] プロフィールリンク：`＿＿＿＿＿＿`（→ どこに飛ばすかは `06` で決定。LP / フォーム / LINE / リンク集ツール）
- [ ] ハイライトのカバー画像を統一（→ デザインは `02`）
  - 推奨ハイライト：`はじめての方へ` / `次回開催` / `当日の様子` / `参加者の声` / `よくある質問`

## 🔁 引き継ぎチェックリスト（担当が変わるとき）

**引き継ぐ人（旧担当）がやること**
- [ ] 直近3ヶ月の投稿予定・下書きの場所を共有
- [ ] 進行中のDM・コメント対応の状況を共有
- [ ] 月次レポート（→ `08`）の最新版を共有
- [ ] 素材（画像・ロゴ・テンプレート）の保管場所を共有
- [ ] 予約投稿ツール・分析ツールのアカウントを共有

**引き継がれる人（新担当）がやること**
- [ ] このマニュアルを `README` → `01` → `02` の順で読む
- [ ] ログイン情報の保管場所にアクセスできるか確認
- [ ] テスト投稿（ストーリー）で操作に慣れる
- [ ] 「勝手に判断しない領域」（→ `05`）を責任者と再確認
